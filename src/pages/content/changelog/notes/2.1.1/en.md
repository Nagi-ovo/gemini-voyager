### Highlights

- 🗂️ **:gemini: :aistudio: Three levels of folders**: you can now create a subfolder inside a subfolder.
- 🌉 **:chatgpt: ChatGPT Local Bridge works in the background**: the bridge opens its ChatGPT tab in the background and does everything there, so it no longer takes over your window. You can keep working in other tabs and apps.
- 🌍 **:chatgpt: Local Bridge and the Pro usage ring in every language**: model and effort selection, sending, projects and the Pro ring now work whatever language ChatGPT is set to, not only Chinese.

### Fixes

- **:gemini: Folder guides**: the nesting lines now sit under each folder's arrow and no longer cut through chat icons at 125% display scaling.
- **:gemini: Gemini hidden archived chats**: the sidebar keeps asking for older chats when Gemini drops the request, instead of getting stuck at the bottom.
- **:chatgpt: ChatGPT Local Bridge**: project lists, file lists and the latest reply are read from ChatGPT's own data, so a slow network no longer yields a partial list or an older reply. A reply ChatGPT failed to finish, or one held up by a usage limit, is reported as such instead of being returned as the answer.
- **:chatgpt: ChatGPT Local Bridge**: the Voyager CLI can ask for the latest page data with `voyager update` (CLI 0.2.0 or later), instead of waiting for the next scheduled check.
- **Icons**: Voyager's icon is redrawn so it stays sharp at every size.
