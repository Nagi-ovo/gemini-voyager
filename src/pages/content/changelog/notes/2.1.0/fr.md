### Points forts

- 🌉 **:chatgpt: Pont local ChatGPT** _(désactivé par défaut)_ : relie les programmes de votre ordinateur à ChatGPT sur le web, avec des primitives pour ouvrir une conversation, envoyer un message avec des fichiers, attendre et lire la réponse, et gérer les fichiers d'un projet. Usage de référence : [Voyager CLI](https://github.com/voyager-crew/voyager-cli), pour le terminal et les agents de code.
- ⭕ **:chatgpt: Utilisation de ChatGPT Pro cette semaine** _(désactivé par défaut)_ : un petit anneau à côté du sélecteur de modèle montre votre utilisation de GPT-6 Pro cette semaine ; survolez-le pour voir le nombre. La limite suit votre forfait, Pro Lite ou Pro. Dans Chrome et Edge.

### Corrections

- **:gemini: Conversations archivées masquées dans Gemini** : la barre latérale continue de charger les anciennes conversations même quand toute une page nouvellement chargée est rangée dans des dossiers.
- **:gemini: Gemini avec plusieurs comptes** : une adresse e-mail dans une réponse n'est plus prise pour le compte connecté, et les dossiers ne se chargent plus sous le mauvais compte.
- **:chatgpt: Notifications de réponse ChatGPT** : cliquer sur le bouton projet ou fichiers du mode Travail ne coupe plus la notification.
- **Export** : une réponse contenant un tableau n'est plus exportée sous forme du seul tableau ; les titres, paragraphes et listes autour sont conservés.
