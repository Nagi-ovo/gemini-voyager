### 주요 변경사항

- 🧩 **나만의 플러그인 만들기**: 팝업의 로컬 플러그인 카드에 바꾸고 싶은 점을 한 문장으로 적고 아무 AI 에게나 맡기면, Voyager 가 답변을 검사하고 무엇이 바뀌는지 보여 준 뒤 가져옵니다(꺼진 상태로). 코딩 에이전트가 작성할 수도 있습니다. [→ 문서](/guide/write-a-plugin)
- 📁 **:chatgpt: ChatGPT 폴더**: ChatGPT 자체 사이드바 안에서 대화를 폴더로 정리합니다. 중첩, 드래그로 순서 변경, 다중 선택, `f:` 검색, 활동 보기, 클라우드 동기화를 지원합니다.
- 🔌 **새 공식 플러그인 21 개**: :chatgpt: ChatGPT, :claude: Claude, :deepseek: DeepSeek 용으로 ChatGPT 타임라인부터 인용 답장, 초안 자동 저장, 표 복사까지 담았습니다. 모두 꺼진 상태로 시작합니다.
- 📚 **저장 보관함 페이지**: 즐겨찾기한 메시지와 하이라이트가 별도 탭에서 열리고, 팝업과 같은 필터, 검색, 카드를 씁니다.

### 새 기능

- **:chatgpt: ChatGPT 타임라인** _(기본값 꺼짐)_: Gemini, Claude 에서처럼 내 프롬프트 사이를 이동하고 즐겨찾기할 수 있습니다.
- **인용 답장** _(기본값 꺼짐)_: ChatGPT, Claude, DeepSeek 의 답변에서 텍스트를 선택해 초안에 인용합니다.
- **Ctrl/⌘+Enter 로 전송** _(기본값 꺼짐)_: ChatGPT, Claude, DeepSeek 에서 Enter 는 줄바꿈, Ctrl/⌘+Enter 는 전송입니다.
- **초안 자동 저장** _(기본값 꺼짐)_: :claude: Claude 와 :deepseek: DeepSeek 에서 보내지 않은 글을 이 기기에 보관하고 새로고침 후 되살립니다.
- **초안 글자 수** _(기본값 꺼짐)_: ChatGPT, Claude, DeepSeek 의 입력창 위에 글자, 단어, 줄 수를 실시간으로 보여 줍니다.
- **읽기 타이포그래피** _(기본값 꺼짐)_: ChatGPT, Claude, DeepSeek 답변의 글자 크기, 줄 간격, 문단 간격을 조절합니다.
- **:deepseek: DeepSeek 추가 기능** _(기본값 꺼짐)_: 표를 Markdown 이나 TSV 로 복사, 긴 코드 블록 접기, 생각 과정 복사.
- **:chatgpt: ChatGPT 추가 기능** _(기본값 꺼짐)_: ECharts 와 WaveDrom 다이어그램, 긴 메시지 접기, 내 메시지의 LaTeX.
- **리서치 팩** _(기본값 꺼짐)_: :gemini: Gemini 답변을 프롬프트, 출처와 함께 하나의 Markdown 팩으로 모아 복사하거나 내려받거나 ChatGPT 나 Claude 에서 이어 갑니다.
- **더 넓어진 클라우드 동기화**: ChatGPT 폴더가 자체적으로 동기화되고, ChatGPT, Claude, DeepSeek 의 타임라인 개요와 즐겨찾기도 이제 Google Drive 에 백업됩니다.
- **모든 타임라인을 Gemini 수준으로**: ChatGPT, Claude, DeepSeek 타임라인에도 노드, 컴팩트, 눈금 스타일과 단축키, 미리보기가 생겼고, 팝업에서 설정합니다.
- **즐겨찾기한 프롬프트는 전체 텍스트 유지**: 카드를 펼쳐 전체를 볼 수 있고, 검색도 전체를 대상으로 합니다.
- **기능 고장 알림**: :gemini: Gemini 업데이트로 Voyager 기능이 고장 나면 팝업이 알려 주고, 개인정보를 지키는 신고 링크를 제공합니다.
- **알림 디자인 통일**: 토스트와 확인 창이 브라우저 경고창 대신 겹쳐 쌓이고 테마를 따르는 하나의 디자인을 씁니다.
- **:gemini: Gemini 워터마크 스위치**: 새로 설치하면 제거 기능이 꺼진 상태로 시작합니다. 업데이트하는 경우 지금 설정이 그대로 유지됩니다.

### 수정

- **즐겨찾기 해제는 해제된 채로**: 즐겨찾기를 해제한 메시지가 클라우드 동기화 후 다시 나타나지 않습니다.
- **:chatgpt: ChatGPT 내보내기**: 긴 대화를 다시 끝까지 내보낼 수 있고, 진행률과 취소 버튼이 있으며, 코드 블록은 코드로 내보냅니다.
- **:gemini: Gemini 사이드바**: 폴더와 초안 자동 저장을 켜 둔 상태에서 이전 대화를 불러올 때 더 이상 멈추지 않습니다(#1040).
- **더 안전한 폴더**: 여러 탭을 열어도 서로의 폴더 변경을 덮어쓰지 않고, 읽기에 실패해도 폴더가 지워지지 않습니다.
- **프롬프트 라이브러리**: 여러 탭에서의 편집, 가져오기, Drive 병합 후에도 순서, 고정, 최신 편집이 유지됩니다.
- **기본 모델**: Gemini 의 낮음, 보통, 높음 생각 옵션에서도 작동합니다.
- **Markdown 내보내기**: 40 장에서 멈추지 않고 모든 이미지를 담습니다.
- **저장한 즐겨찾기 열기**: 즐겨찾기한 ChatGPT 와 DeepSeek 메시지가 각자의 사이트에서 열립니다.
- **:chatgpt: ChatGPT 테마**: Voyager 가 시스템 대신 ChatGPT 의 라이트 또는 다크 테마를 따릅니다.
- **업데이트 후**: 열려 있던 탭에 Voyager 패널이 두 번 나타나지 않습니다.
- **:aistudio: AI Studio**: 삭제한 폴더는 삭제된 채로 남고, 폴더 작업이 더 이상 페이지를 새로고침하지 않습니다.
- **Drive 복원**: 대화 분기도 함께 복원됩니다.
- **:gemini: Gemini 대화 분기**: 분기를 열어도 페이지가 다시 로드되지 않습니다.
- **응답 완료 알림**: 브라우저 권한 요청에서 허용하면 켜진 상태가 유지됩니다.
