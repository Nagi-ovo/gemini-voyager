# 欢迎登船

恭喜，你的思考能力刚刚升级了。
Voyager 不只是一个工具，它是一种工作流。下面是前 5 分钟的上手指南，帮你充分利用它。

## 1. 安装

如果还没有安装，请前往[安装指南](/guide/installation)。
安装完成后，刷新你的 Gemini 页面，变化会立刻显现。

如果你也在使用 Claude、ChatGPT 或 DeepSeek，请打开 Voyager 弹窗，进入 **插件** 区域，为该网站开启你想要的插件。浏览器第一次会请求访问该网站的权限，请同意；如果没有出现任何内容，请刷新标签页。你可以在[插件目录](/plugins)中浏览全部插件。

## 2. 时间线

开始一段对话，最好是一段较长的对话。比如问问汉字的演变历史，或者黑洞的物理原理。
看向右侧。
**那一串圆点，就是你的地图。**

- **悬停**：偷看你当时说了什么。
- **点击**：瞬间跳转过去。
- **长按**（约 0.5 秒）：给你想保留的时刻**加星**，就像给大脑加一个书签。

不必再无休止地滚动。你现在可以按思维的速度导航了。

## 3. 整理

看看左边的对话列表。注意到什么新东西了吗？
**文件夹。**

拖起一个对话，把它拖进文件夹，松手即可。
是不是很自然？这正是它的设计初衷。你可以嵌套文件夹、重命名，最终把脑子里的杂乱清空。

## 4. 提示词库

你刚写出了一条很棒的提示词，别让它消失在茫茫对话里。
点击输入框旁边的悬浮 **Voyager 球**（可以随意拖动到任何位置），打开提示词管理器。
保存它，并给它加上标签。

下次需要时，点击这个球，找到它并插入即可。
你不只是在聊天，而是在积累属于自己的知识宝库。
