# 侧边栏 Gems 列表

::: info 暂时不可用
Gemini 新版侧栏把 Gems 收进了「更多」菜单，不再显示 Gems 入口。此功能暂时不会显示，Voyager 设置面板中的开关也已置灰。
:::

Gemini 2026 改版把 Gems 折腾到了"设置 → Gems"再回到 sidebar 顶部，但它只是一个跳转入口，点一下就把你扔到 `/gems/view` 整页里。

Voyager 让 Gemini 原生的 Gems 入口"长出"一个 gems 子列表，直接在侧边栏里点开就用：置顶的排在最前，其余按最近使用排序。

## 它是怎么工作的

- **挂在原生 Gems 入口下方**：视觉上就像 Gemini 自带的 Gems 项展开了。同列缩进、同字号，不抢戏。
- **箭头按钮可折叠**：原生 Gems 入口右侧多出一个 `›` 箭头，展开时转成 `⌄`，点击切展开/收起。展开/收起状态保存在本地，并跨标签页同步。
- **最近用过的排前面**：打开任何一个 gem（你自己的，或 Google 预设的）都会把它顶到列表最上面。
- **置顶的 gem 不挪位**：置顶的 gems 始终排在最前，按你置顶的先后排列，不占滑块的数量上限。
- **零网络开销**：数据全部来自你打开的页面上 Voyager 看到的内容。不调任何 API、不轮询、不抓后台。

## 怎么用

1. 打开 Voyager 设置面板（浏览器右上角插件图标）。
2. 在 **插件** → **侧栏最近使用的 Gem** 中确认该行已开启（默认开启）。开启后，行下方会出现数量滑块，默认显示 3 个。
3. 拖到你想显示的数量（1–10）。**0 只是隐藏最近 Gems 列表**，并不会关闭这个功能；想完全关闭，请把该行的开关关掉。

想置顶自己的某个 gem：打开 `gemini.google.com/gems/view`，点它那一行的置顶按钮（**Pin to sidebar**）。再点一次取消置顶。

::: tip 首次启用
列表会边用边填：打开一个 gem，它就出现了。想看到最近没打开过的 gems，访问一次 `gemini.google.com/gems/view`，Voyager 会自动把你的 gems 列表存一份快照。
:::

## 数据何时更新

- **打开 gem**（`/gem/<id>`）时，记为刚刚用过。
- **访问 `/gems/view`** 时刷新 gems 列表快照；在这个页面上重排、改名、新建、删除 gem，都会实时同步。
- 其他页面不读取任何内容。

也就是说：如果你在别的设备上新增了 gem，Voyager 不会"魔法地"知道。回到这台机器上打开它，或访问一次 `/gems/view` 即可。

## 关于隐私

- gems 列表快照和最近使用记录**只存在本地** (`chrome.storage.local`)。
- 滑块数值和置顶 gems 的 ID 会和其他 Voyager 设置一起存在**浏览器同步存储**里，登录同一浏览器配置的其他设备也会跟着生效。名字和图标不会同步。
- 不读取也不缓存 gem 的对话内容——只是名字、描述、跳转链接和首字母。
- 关掉功能（数量调到 0），本地数据也仍然留着，再开启时无需重新加载。

## 平台

仅支持 **Google Gemini**（`gemini.google.com`）。AI Studio 的 Gems 入口结构不同，不在适用范围内。
