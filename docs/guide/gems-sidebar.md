# 侧栏中的最近 Gems

Gemini 2026 年改版后，Gems 先被收进了设置菜单，之后又悄悄在侧边栏放回了一个入口，但它只是一个链接，点击后会跳转到 `/gems/view`。

Voyager 可以让这个原生的 Gems 入口直接在侧边栏里“展开”，列出你的 Gems：置顶的 Gems 排在最前，其余按最近使用的顺序排列。

## 外观

- **挂在原生 Gems 入口下方**：缩进与 Gemini 自带的 “Gems” 文字对齐，看起来像是这个入口的子列表，而不是硬塞进来的面板。
- **箭头折叠**：Gems 入口右侧有一个小的 `›` 按钮，展开时会旋转为 `⌄`。点击即可收起或展开。展开状态保存在本地，并在各标签页之间同步。
- **最近使用优先**：打开任何一个 Gem（无论是你自己的，还是 Google 预设的）都会把它移到列表顶部。
- **置顶的 Gems 固定不动**：置顶的 Gems 始终排在最前，顺序与你置顶的先后一致，并且不计入滑块的数量上限。
- **零网络流量**：所有数据都来自你在页面上打开时 Voyager 看到的内容。没有 API 调用、没有轮询，也没有后台抓取。

## 使用方法

1. 点击工具栏中的 Voyager 扩展图标，打开弹窗。
2. 找到 **侧栏中显示的最近 Gems** 滑块，默认显示 3 个 Gems。
3. 将滑块拖到你想要的数量（1–10）。**设为 `0` 会完全隐藏该区域**，如果你不需要此功能，可以这样设置。

要置顶自己的某个 Gem，请打开 `gemini.google.com/gems/view`，然后点击该 Gem 所在行的置顶按钮（**Pin to sidebar**）。再次点击即可取消置顶。

::: tip 首次设置
列表会随着你的使用逐步填充：打开一个 Gem，它就会出现在列表中。如果想看到最近没有打开过的 Gems，请访问一次 `gemini.google.com/gems/view`，Voyager 会在那里悄悄保存一份你的 Gems 列表快照。
:::

## 列表何时更新

- **打开 Gem**（`/gem/<id>`）时，会记录它刚刚被使用。
- **访问 `/gems/view`** 时，会刷新你的 Gems 列表快照；在该页面上重新排序、重命名、新建或删除 Gem，都会立即同步。
- 不会从其他页面读取任何内容。

因此，如果你在其他设备上新建了 Gem，Voyager 不会“自动”知道。请在这台电脑上打开它，或访问一次 `/gems/view`。

## 隐私

- Gems 列表快照和最近使用记录保存在**本地浏览器存储**（`chrome.storage.local`）中。
- 滑块的数值和置顶 Gems 的 ID 会与其他 Voyager 设置一起保存在**浏览器同步存储**（`chrome.storage.sync`）中，因此在同一浏览器配置文件中登录的其他设备上也会生效。名称和图标不会被同步。
- 我们不会读取或缓存 Gem 的对话内容，只保存名称、描述、链接以及用于头像的首字母。
- 关闭该功能（数量设为 0）后，本地数据仍会保留，因此重新开启时可以立即使用。

## 平台

仅支持 Gemini（`gemini.google.com`）。AI Studio 的 Gems 入口结构不同，不在本功能的支持范围内。
