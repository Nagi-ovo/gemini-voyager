# 发送行为

::: info
**注意**：该功能在 1.3.7 及后续版本中可用。
:::

将发送快捷键改为 `Ctrl+Enter`（macOS 上为 `⌘+Enter`），让 `Enter` 键变为换行，方便你轻松撰写多行提示词。

## 为什么需要这个功能

默认情况下，按下 `Enter` 会立即发送消息。撰写较长的提示词、粘贴多行代码，或者精心排版输入内容时，这常常导致误发：你只是想换一行，消息却已经发出去了。

开启后：

- **Enter** → 插入换行
- **Ctrl+Enter**（macOS：**⌘+Enter**）→ 发送消息

Shift+Enter 和输入法组合输入保持网站自身的行为；如果附件仍在上传，Ctrl/⌘+Enter 会等待上传完成后再发送。

## 如何开启

1. 打开 Voyager 弹窗。
2. 在 **输入选项** 中开启 **Ctrl+Enter 发送**（macOS 上显示为 **⌘+Enter 发送**）。

## 其他网站

- **AI Studio** 的逻辑相反：开启 **AI Studio Enter 发送**，即可用 `Enter` 发送，并用 `Ctrl/⌘+Enter` 换行。
- **Claude、ChatGPT 和 DeepSeek**：请从[插件目录](/plugins)中为对应网站安装 **Ctrl/Cmd+Enter 发送** 插件。
- **Safari**：如果 Gemini 需要按两次回车才能发送，请开启 **修复 Safari 回车键**。

## 功能特点

- **零性能开销**：关闭时不会激活任何键盘事件监听器，不影响页面性能。
- **即时切换**：在设置中切换后立即生效，无需刷新页面。
