# 云同步

Voyager 云同步会备份您的文件夹、提示词库、星标消息以及受支持的设置。所有受支持的浏览器都可以使用 Google Drive；Safari 上还可以选择 iCloud。数据会在 Voyager 与您选择的个人云端账户之间直接传输，Voyager 不运营同步服务器。

## 同步内容

| 数据类型   | 是否同步 | 说明                                                |
| ---------- | -------- | --------------------------------------------------- |
| 文件夹结构 | 是       | 所有文件夹、嵌套层级、颜色以及对话归属              |
| 提示词库   | 是       | 所有已保存的提示词，包括标签和文件夹分类            |
| 星标消息   | 是       | 来自任意对话的时间线书签                            |
| 扩展设置   | 是       | 排序、颜色、输入行为等跨设备偏好                    |
| 插件配置   | 是       | 安装/启用状态和插件设置；网站权限仍然按设备单独管理 |
| 模型回答   | 否       | 星标备份只包含用户提示词，不包含模型回答            |

## 星标数据与同步限制

上传云同步备份时，星标消息会包含您标记的**用户提示词全文**（每条最多 16 KiB UTF-8），并保存到您自己的 Google Drive 或 iCloud 中。星标备份不保存模型回答。旧的 v1 备份只保留预览，新的 v2 备份包含提示词全文及删除记录。

删除记录保留 180 天。旧版 Voyager 不识别这些记录，可能会显示或重新上传已删除的星标；新版会拦截时间戳未更新的旧副本。用户明确重新加星，或删除记录已过期，星标都可能恢复。长期离线和设备时钟偏差也会影响删除的传播。

同步会合并并检查写入结果，最多尝试三次，但它不是跨设备的原子事务：并发上传仍可能覆盖其他设备的写入。保留缺失数据的设备再次同步，可以修复这种情况；如果该设备之后不再同步，则无法保证恢复。部分上传失败不会撤销已经成功的写入，请再次同步以完成修复。

## 功能特点

- **多设备同步**：在多台电脑之间保持配置一致。
- **数据隐私**：数据存储在您自己的 Google Drive 或私有 iCloud 数据库中，不经过 Voyager 服务器。
- **灵活同步**：支持手动上传，以及下载并合并数据。

::: info
设备标识、访问令牌、缓存、视口坐标和临时运行状态都不会作为个性化设置同步。
:::

## 如何使用

1. 点击浏览器工具栏中的 Voyager 图标，打开弹窗。
2. 找到 **云同步** 区域。
3. 在 Safari 上选择 **Google Drive** 或 **iCloud**；其他浏览器使用 Google Drive。
4. 使用 Google Drive 时，点击 **使用 Google 登录** 并完成授权；使用 iCloud 时，请确保 Mac 已登录 iCloud。
5. 点击 **上传到云端**，将本地数据发送到云端；或点击 **从云端下载合并**，将云端数据合并到本浏览器。**覆盖下载** 会用云端副本替换本地数据，而不是合并，因此尚未上传的内容会丢失。

使用 iCloud 时，**删除 iCloud 备份** 会从 iCloud 中删除所有 Voyager 备份；Mac 上的本地数据保持不变。

### 💡 快速同步

最快捷的方式是使用左侧边栏文件夹区域顶部的 **上传到云端** 和 **从云端同步** 按钮。

云同步虽然很方便，但我们强烈建议您同时定期将核心数据备份到**本地文件**。

1. **文件夹**：打开文件夹区域的菜单，选择“导入/导出文件夹”，再点击“导出文件夹”，即可保存所有文件夹和对话归属。
2. **提示词**：在提示词管理器中点击“导出”，保存您的提示词库。

## 云同步与手动备份

| 方面     | 手动备份（导出/导入）  | 云同步                                 |
| -------- | ---------------------- | -------------------------------------- |
| 频率     | 想起来时再操作         | 一键按需同步                           |
| 数据位置 | 电脑上的本地文件       | 您的 Google Drive 或私有 iCloud 数据库 |
| 跨设备   | 需要手动传输文件       | 登录同一云端账户的设备即可使用         |
| 合并方式 | 替换，或需要手动合并   | 智能合并，不会产生重复数据             |
| 隐私     | 文件只保存在您的电脑上 | 保存在您的个人云端账户中               |

## 工作原理

1. **服务提供方**：Google Drive 使用权限受限的 `drive.file` 范围，因此 Voyager 只能访问它自己创建的文件。在 Safari 上，iCloud 使用应用自己的私有 CloudKit 数据库，不会向 Voyager 暴露 Apple ID 令牌。
2. **上传**：点击 **上传到云端** 时，Voyager 会把文件夹、提示词、星标、分支、时间线层级、个性化设置和插件配置分别写成独立的备份文件，保存到所选服务中。开启高亮云同步后，高亮数据也会一并上传。
3. **下载并合并**：在另一台设备上点击 **从云端下载合并** 时，Voyager 会读取这些文件并按数据类型合并：新的文件夹和提示词会被添加且不产生重复，云端偏好会被恢复，插件条目则按插件 ID 合并。
4. **没有后台同步**：同步是手动、按需进行的，Voyager 绝不会在您没有明确操作的情况下同步。

切换服务提供方不会在两者之间复制数据，也不会同时写入两个服务。切换后如果要把当前本地数据放到新选择的服务中，请手动上传一次。

## 支持的平台

Google Drive 同步可在 Chrome、Edge、Firefox 和 Safari 上使用。iCloud 同步仅在 Safari 直装版中可用，使用 Mac 上登录的 iCloud 账户。
