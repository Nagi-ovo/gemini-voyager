# 消息时间戳

::: info
**注意**：该功能在 1.3.7 及后续版本中支持。
:::

Voyager 会显示每条消息的发送时间，帮助你回溯对话的完整脉络。

## 功能介绍

当对话变长后，很难回忆某段讨论发生在何时。

Voyager 在每条消息上方标注精确的发送时间戳（格式：`YYYY-MM-DD HH:mm:ss`），鼠标停在时间线的圆点上也能看到同一时间。

## 如何开启

1. 打开 Voyager 设置面板（浏览器右上角插件图标）。
2. 打开 **插件** → **消息时间戳**（标有 **实验性**，默认关闭）。

## 时间从哪里来

- **Gemini**：Voyager 从 Gemini 自己的对话数据中读取每条消息真实的发送时间，所以在别的设备上、或安装 Voyager 之前进行的对话也能显示准确时间。只有拿不到这个时间时，才退回到 Voyager 首次看到这条消息的时间，保存在本地浏览器中。
- **ChatGPT**：开关打开期间，Voyager 会记录你发出的每条消息的时间，保存在本地浏览器中；之前发送的、或在其他设备上发送的消息没有时间戳。

## 功能特点

- **精确到秒**：完整的日期与时间，适合复盘长对话。
- **零干扰**：时间信息以简洁的方式呈现，不影响对话阅读体验。

## 使用场景

- **工作记录**：回顾某个决策是在什么时间点达成的。
- **学习笔记**：标记某个知识点是何时讨论的，方便后续复习。
- **长对话复盘**：在跨天的深度对话中，清晰区分不同时间段的讨论内容。

## 平台

**Google Gemini**（`gemini.google.com`）和 **ChatGPT**（`chatgpt.com`）。Claude 和 DeepSeek 暂不支持。
