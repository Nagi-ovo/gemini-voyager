# 你的数字资产：提示词库

你精心写出了一条完美的提示词，它解决了一个复杂的编程问题，或者写出了一封漂亮的邮件。
你会把它扔掉吗？
不会，你会把它保存下来。

## 提示词宝库

这是你个人的智慧仓库。

### 1. 收藏

写出好东西时，点击悬浮的 Voyager 球（默认位于输入区域旁边，你可以把它拖到任意位置），打开 **提示词管理器**。
它就成了你宝库的一部分。

### 2. 分类

添加 `编程`、`邮件` 或 `研究` 之类的标签（用逗号分隔）。
让你的工具保持锋利，也保持井井有条。

### 3. 调用

下次需要时，不必再重新输入。
打开管理器，按标签或关键词搜索，然后点击插入。
一键完成，效率成倍提升。

## 紧凑列表与备注名

当提示词越攒越多，卡片列表已经放不下时，面板会自动适配：

### 视图切换

搜索栏右侧的 `≡ / ▦` 按钮可以在 **紧凑列表**（默认）和 **舒适视图** 之间切换。

- **紧凑列表**：每条提示词占一行，一屏大约可见 10 条；右侧依次是标签、展开、编辑和删除按钮。
- **舒适视图**：完整的 Markdown 预览，适合提示词数量较少的情况。

### 必填备注名

添加或编辑提示词的表单顶部有 **备注名** 字段，它会作为提示词的简短标题，创建或编辑提示词时必须填写。没有备注名的旧提示词仍然可以使用，但下次编辑时需要补上备注名。

### 快速悬停预览

在紧凑模式下，将鼠标悬停在任意一行上约 **250 毫秒**，即可在浮动提示框中查看完整内容。它取代了浏览器原生的 title 提示（原生提示通常要等 1 到 3 秒才会出现）。

### 斜杠快速插入

在对话输入框中输入 `/`，然后输入提示词备注名的一部分。列表会显示匹配的名称和标签；将鼠标悬停在某一项上可以预览完整正文，然后点击该项，或按 `Tab` / `Enter` 确认选择。输入框会把选中的名称显示为高亮的标记，而发送时则会发送完整的提示词正文。

## 任何网站都能用

提示词管理器现在可以用在你选择的任何网站上，不再局限于 Gemini™ 和 AI Studio。

### 如何启用

在 Claude、ChatGPT 和 DeepSeek 上，请在该网站打开时点击 Voyager 弹窗，并打开该网站的开关（例如 **在 Claude 上开启提示词管理器**）。系统会请求你授予访问权限。

对于其他网站：

1. 点击浏览器扩展栏中的 Voyager 图标。
2. 滚动到 **提示词管理器** 区域。
3. 输入网站地址（例如 `chatgpt.com` 或 `claude.ai`）。
4. 点击 **添加网站**，并授予权限。
5. **刷新目标页面**，即可看到悬浮球。

### 常见 AI 网站

- `chatgpt.com`：ChatGPT
- `claude.ai`：Claude
- `copilot.microsoft.com`：Microsoft Copilot
- `poe.com`：Poe

### 本地应用

本地地址同样可以添加：输入 `localhost:3080` 或 `127.0.0.1:3080` 即可。例如 [DeepSeek Harness](/guide/deepseek-harness) 运行在 `localhost:3080` 上，提示词管理器会像挂载到其他网站一样挂载到它上面。

![在 DeepSeek Harness 中运行的提示词管理器](/assets/prompt-manager-deepseek-harness.png)

::: tip
在你自行添加的网站上，**只会**激活提示词管理器。时间线、文件夹等功能不会在那里加载。Claude、ChatGPT 和 DeepSeek 则不同，它们有各自的官方插件，你可以在[插件目录](/plugins)中浏览。
:::
