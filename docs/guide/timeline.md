# 时间旅行

Voyager 时间线是一套可视化的对话导航系统，支持 Gemini、Claude 和 ChatGPT。它会把对话中的每条消息映射为屏幕右侧的一个可交互节点，把冗长的 AI 对话变成一张可以即时跳转的导航图。

长对话是灾难。上上下下，找不着北。
Voyager 把对话变成一条线。

在 Gemini 上，**时间线** → **显示时间线** 控制时间线轨道及其导航快捷键。关闭后会保留已保存的星标和层级。消息时间标签独立跟随 **时间线** → **消息时间戳**，所以关闭时间线后仍可显示消息时间。

在 Claude、ChatGPT 和 DeepSeek 上，时间线轨道就是该网站的时间线插件：在 **插件** 中打开它，其 **选项** 包含时间线样式、节点层级（部分网站提供）、**重置时间线位置** 和 **查看收藏库**；ChatGPT 上还有消息时间。

## 看见节奏

看屏幕右侧。
每个点都是一句话。那是你对话的脉搏。

## 导航，一步到位

- **瞬移**：点哪去哪，绝不拖泥带水。
- **偷看**：鼠标放上去，不用跳转也能看内容。
- **插眼**：长按节点 **加星**。给大脑打个书签。
- **层级 (实验性)**：默认关闭。先开启 **时间线** → **显示时间线**，再在该行下方打开 **启用节点层级**，再右键点击节点，设置不同层级（1-3 级）或折叠子节点。让深度分支对话一目了然。层级只在 `节点` 样式下显示：打开后时间线会切换到 `节点`，层级开着时不能选 `刻度` 和 `紧凑索引`。
- **调宽窄**：拖动时间轴内侧边缘，自由调整宽度。
- **快捷键**：用键盘飞速穿梭。默认 `j`/`k` 上下跳转，`gg`/`GG` 直达首尾，想改就改。

## 插眼：给灵感钉个钉

长对话里藏着金子。用星标把重要时刻钉住。

**怎么用**：长按（约 0.5 秒）时间轴上任意节点，看到它亮起来——这条消息就被加星了。

- 再次长按取消星标。
- 加星的节点会保持高亮，一眼就能找到。
- 在 Voyager 弹窗中开启 **时间线** → **显示时间线** 后，在该行下方点 **查看收藏库**，或从提示词管理器面板打开，集中查看所有标记过的消息。

把它想象成在对话中插旗——灵感迸发的瞬间、完美的回答、或者下次要从这里继续的位置。

::: tip 小贴士
开启[云同步](/guide/cloud-sync)后，星标会跨设备同步。
:::

## 外观设置

在 Voyager 弹窗中开启 **时间线** → **显示时间线** 后，选项会显示在该行下方：

- **时间线样式**：`节点`、`刻度` 或 `紧凑索引`。
- **固定预览面板**：让预览面板常驻在时间线旁边。它的搜索框可以在你输入时过滤消息。
- **可拖拽时间线**：可以把时间线拖到页面的任意位置。点击 **重置时间线位置** 即可恢复默认位置。

## 键盘，更快

不想用鼠标？用键盘。

**就像在 Gemini 里开了 Vim Mode。**

### 默认快捷键

- `k` - 跳到上一个节点
- `j` - 跳到下一个节点
- `gg` - 跳到第一轮
- `GG` - 跳到最后一轮

### 自定义

打开扩展设置，点击快捷键框，按下你想用的键。
任意键，任意组合。`n`/`p`？`,`/`.`？随你。

**流动模式**下连按会排队播放动画。
**跳跃模式**下立即响应，速度拉满。

## 什么时候用时间线

时间线在超过 10 条消息的长对话中最有价值，因为这时滚动查找的效率很低：

- **研究会话**：你让 Gemini 围绕一个主题探讨了 30 轮以上。时间线可以让你直接跳回关键结论，无需重读全部内容。
- **代码调试**：一段很长的调试对话，解决方案出现在第 47 轮。给它加星，之后一键就能找到。
- **学习和辅导**：分步骤学习一个复杂的主题。用层级折叠你已经掌握的部分。
- **头脑风暴复盘**：回顾一次创意讨论，提炼最好的想法。星标标记值得保留的时刻。

## 时间线与手动滚动

| 能力                  | 没有时间线         | 使用 Voyager 时间线                                     |
| --------------------- | ------------------ | ------------------------------------------------------- |
| 找到特定消息          | 反复上下滚动       | 点击节点，或按 j/k                                      |
| 标记关键时刻          | 复制粘贴到外部笔记 | 长按加星，并同步到云端                                  |
| 查看对话结构          | 只能逐条阅读       | 可视化地图一眼看清整体结构                              |
| 键盘导航              | Gemini 中不可用    | Vim 风格的 j/k、gg/GG，并可完全自定义                   |
| 浏览 100 条以上的消息 | 需要滚动好几分钟   | 瞬间跳到任意位置                                        |
| 整理长线程            | 没有内置工具       | 1 至 3 级层级，以及可折叠的子节点（实验性，需手动开启） |

## 支持的浏览器

时间线支持 Google Gemini，并以内置插件的形式支持 Claude 和 ChatGPT，覆盖 Chrome、Edge、Firefox、Safari、Opera 和 Brave。快捷键和星标在这三个平台上的表现一致。层级在各平台都是需要手动开启的实验性功能：在 Gemini 上，开启 **时间线** → **显示时间线** 后，在该行下方打开 **启用节点层级**；在 Claude 和 ChatGPT 上，到 **插件** 里 **时间线** 的设置中打开同一个开关。开启 [云同步](/guide/cloud-sync) 后，加星的消息会在多台设备之间同步。

AI Studio 上没有时间线。DeepSeek 在插件目录中提供了一个可选的时间线插件（默认未启用）。
