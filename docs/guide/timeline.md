# 时间旅行

Voyager 时间线是一套可视化的对话导航系统，支持 Gemini、Claude 和 ChatGPT。它会把对话中的每条消息映射为屏幕右侧的一个可交互节点，把冗长的 AI 对话变成一张可以即时跳转的导航图。

长对话很容易乱。你上上下下地翻，然后找不到自己读到哪里了。
Voyager 把你的对话变成一条时间线。

在 Gemini 设置中，**显示时间线** 控制时间线轨道及其导航快捷键。关闭后，已保存的星标和层级会保留。消息时间标签则独立由 **显示消息时间** 控制，因此即使关闭时间线，你仍可以显示消息时间。

## 看清对话的走向

看屏幕右侧。
每个节点代表一条消息。时间线呈现出你们对话的节奏。

## 导航，一步到位

- **瞬移**：点击节点，立即跳转到对应消息。
- **偷看**：鼠标悬停即可查看内容，无需移动视角。
- **书签**：长按节点即可 **加星**，就像给大脑加了一个书签。
- **层级（实验性）**：右键点击节点，可以设置 1 至 3 级层级，或折叠其子节点。适合梳理分支较多的对话。
- **调整宽度**：拖动时间线的内侧边缘即可调整宽度。
- **快捷键**：用键盘快速穿梭。默认 `j`/`k` 切换上一个、下一个节点，`gg`/`GG` 跳到第一轮和最后一轮。

## 星标：标记关键时刻

长对话里往往埋着宝贵的内容。给重要的时刻加上星标。

**使用方法**：在时间线上长按（约 0.5 秒）任意节点，看到它亮起，就表示这条消息已加星。

- 再次长按即可取消星标。
- 加星的节点会保持高亮，方便你一眼找到。
- 在 Voyager 弹窗中点击 **查看收藏库**，或从提示词管理器面板中打开，即可查看所有加星的消息。

可以把它理解为在对话中插上一面旗帜：灵感迸发的时刻、拿到完美答案的时刻，或者你之后想接着看的位置。

::: tip 小贴士
开启 [云同步](/guide/cloud-sync) 后，星标会在多台设备之间同步。
:::

## 外观设置

在 Voyager 弹窗的 **时间线选项** 下：

- **时间线样式**：`节点`、`刻度` 或 `紧凑索引`。
- **固定预览面板**：让预览面板常驻在时间线旁边。它的搜索框可以在你输入时过滤消息。
- **可拖拽时间线**：可以把时间线拖到页面的任意位置。点击 **重置时间线位置** 即可恢复默认位置。

## 键盘，更快

不想用鼠标？那就用键盘。

**相当于在 Gemini 里开启了 Vim 模式。**

### 默认快捷键

- `k`：跳到上一个节点
- `j`：跳到下一个节点
- `gg`：跳到第一轮
- `GG`：跳到最后一轮

### 自定义

打开扩展设置，点击快捷键输入框，按下你想用的按键即可。
任意按键、任意组合都可以，比如 `n`/`p`，或者 `,`/`.`，由你决定。

**流动模式**：快速连按时，跳转会排队平滑执行。
**跳跃模式**：立即响应，速度最快。

## 什么时候用时间线

时间线在超过 10 条消息的长对话中最有价值，因为这时滚动查找的效率很低：

- **研究会话**：你让 Gemini 围绕一个主题探讨了 30 轮以上。时间线可以让你直接跳回关键结论，无需重读全部内容。
- **代码调试**：一段很长的调试对话，解决方案出现在第 47 轮。给它加星，之后一键就能找到。
- **学习和辅导**：分步骤学习一个复杂的主题。用层级折叠你已经掌握的部分。
- **头脑风暴复盘**：回顾一次创意讨论，提炼最好的想法。星标标记值得保留的时刻。

## 时间线与手动滚动

| 能力                  | 没有时间线         | 使用 Voyager 时间线                   |
| --------------------- | ------------------ | ------------------------------------- |
| 找到特定消息          | 反复上下滚动       | 点击节点，或按 j/k                    |
| 标记关键时刻          | 复制粘贴到外部笔记 | 长按加星，并同步到云端                |
| 查看对话结构          | 只能逐条阅读       | 可视化地图一眼看清整体结构            |
| 键盘导航              | Gemini 中不可用    | Vim 风格的 j/k、gg/GG，并可完全自定义 |
| 浏览 100 条以上的消息 | 需要滚动好几分钟   | 瞬间跳到任意位置                      |
| 整理长线程            | 没有内置工具       | 1 至 3 级层级，以及可折叠的子节点     |

## 支持的浏览器

时间线支持 Google Gemini，并以内置插件的形式支持 Claude 和 ChatGPT，覆盖 Chrome、Edge、Firefox、Safari、Opera 和 Brave。快捷键、星标和层级在所有平台上的表现一致。开启 [云同步](/guide/cloud-sync) 后，加星的消息会在多台设备之间同步。

AI Studio 上没有时间线。DeepSeek 在插件目录中提供了一个可选的时间线插件（默认未启用）。
