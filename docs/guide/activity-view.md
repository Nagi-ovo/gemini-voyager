# Activity：把注意力留给正在发生的对话

文件夹回答的是「这段对话放在哪里」。当归档越来越多，另一个问题会更频繁地出现：现在应该先看什么？

Activity 是文件夹之上的时间视图。点击 **文件夹** 旁边的铃铛，原来的文件夹树会换成一组按真实对话活动排列的会话。它不会改变你的文件夹、对话归属或 Star 状态。

**设计灵感：** 这个视图的灵感来自 OpenAI Codex / ChatGPT Desktop 的侧边栏。Voyager 沿用了把仍在活跃的对话优先显示出来的思路，并把它改造成基于时间的 Gemini 文件夹视图。

## 优先分组跟随最近活动

优先分组收录最近 **3 小时**内有新对话轮次的会话。它使用的是真实的对话时间，而不是你打开或查看对话的时间。

进入优先分组的对话不会同时出现在今天分组中。当它的 3 小时活动窗口结束后，Activity 会自动把它放回今天或对应的日期分组，无需刷新页面。

Star 仍然是一个独立的手动标记。给对话加 Star 不会让它进入优先分组；取消 Star 也不会把仍在活动的对话移出优先分组。

## 只显示最近几天

在优先分组下方，Activity 会依次显示「今天」「昨天」以及更早几天的星期标题。该视图涵盖今天和之前的四个自然日，让列表始终贴近你当前的工作。

更早的对话，以及没有活动时间的旧记录，不会显示在这里。它们并没有被隐藏或删除。再次点击铃铛即可回到文件夹树，并在原来的位置找到它们。

## 一段对话只占一行

一段对话可以同时属于多个文件夹。Activity 会把这些归属合并成一行，并在标题下方保留文件夹名称。将鼠标悬停在文件夹信息上，可以查看完整路径。

这样，同一段对话就不会在优先或今天分组中占用多个位置，同时仍保留它所属项目的上下文。

## 三种信号，各司其职

| 信号     | 依据                 | 回答的问题                 |
| -------- | -------------------- | -------------------------- |
| 文件夹   | 你整理的项目和主题   | 这段对话属于哪里？         |
| Activity | 最近一次真实对话轮次 | 最近有哪些工作仍在推进？   |
| Star     | 手动标记             | 哪些对话应该一直保持标记？ |

文件夹适合在归档中检索内容。Activity 则在你每次回到 Gemini 时缩小需要选择的范围：先从优先分组中仍有动能的对话接着做，再处理今天或昨天的内容；需要查找旧资料时，再切回完整的文件夹树。

## 支持的位置

Activity 可用于 Gemini 的文件夹侧边栏，以及 ChatGPT 的文件夹区域（属于内置的 ChatGPT 文件夹插件的一部分）。
