# 默认模型

::: info
**注意**：该功能在 1.1.9 及后续版本中可用。
:::

将你常用的 Gemini™ 模型设为默认模型，这样每次开启新对话时都无需手动切换。

## 功能特点

- **交互式设置**：直接在 Gemini 原生的模型选择菜单中加入“星标”按钮。
- **自动切换**：每次开启新对话时，自动切换到你设定的模型。
- **同时设置思考强度**：给 **Extended thinking（扩展思考）** 选项加星后，新对话也会默认启用它。
- **偏好持久保存**：你的选择会被保存，并在多台设备之间同步。
- **针对单页应用优化**：点击“新对话”按钮、使用快捷键，或返回首页时，都能准确触发。

## 如何使用

1. 点击 Gemini 输入框上方的 **模型选择器**。
2. 将鼠标悬停在想要设为默认的模型上，然后点击 **星标图标**。
3. 星标变为**实心**后，该模型即被设为默认。
4. 之后，插件会在所有新对话中自动选中该模型。
5. 如果希望新对话也默认启用扩展思考，请在同一菜单中点击 **Extended thinking** 旁边的星标。
6. 如需取消，再次点击实心星标即可。

如果想暂时停用这一功能但保留你的选择，请在 Voyager 弹窗中关闭 **新对话时自动应用默认模型**。
