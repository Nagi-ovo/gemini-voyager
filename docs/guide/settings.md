# 随心所欲

默认体验已经很好。但你可能希望它更完美。
每一个细节都可以调。

## 影院模式

为什么要透过一条门缝看世界？
Voyager 让你可以拉宽聊天区域。

- **对话区域宽度**：滑块范围为窗口宽度的 30% 至 100%（默认 70%）。写代码、看复杂表格时可以拉宽，阅读时则可以收窄。
- **编辑输入框宽度**：拉宽编辑已发送消息时出现的输入框。

## 掌控

点击扩展图标，进入控制面板。

- **滚动模式**：`流动` 平滑滚动到目标消息；`跳跃` 则立即跳转。
- **时间线位置**：开启 **可拖拽时间线**，把它拖到顺手的位置。点击 **重置时间线位置** 即可恢复。
- **视觉特效**：可选择 `飘雪`、`樱花` 或 `雨`，为页面营造季节氛围。

## 自定义排序

弹窗里的功能区域太多，而你最常用的功能却埋在最下面？

把鼠标悬停在任意设置卡片上，右上角会出现 ▲/▼ 箭头。点击即可将卡片上移或下移。你的布局会自动保存，并在下次打开时保留。

## 氛围

Voyager 不只是实用的小调整，你还可以改变页面的气氛。

- **飘雪**：柔和的雪花缓缓飘落，带来宁静的冬日感觉。
- **樱花**：飘散的樱花花瓣，带来轻快的春日氛围。
- **雨**：电影感的雨幕效果，带有斜向雨丝和细微的水花涟漪。
- **平滑切换**：关闭某个特效或切换到另一个特效时，现有粒子会自然淡出。
