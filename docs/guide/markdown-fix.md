# Markdown 渲染修复

Gemini™ 的网页界面有时会在文本中插入 HTML 元素（例如引用来源或高亮标记），这可能会破坏 Markdown 的加粗语法（`**text**`），导致文本无法正确加粗显示。

Voyager 内置了自动修复功能，能够智能识别并修复这些断裂的加粗标签，确保文档渲染的整洁与准确。

> [!NOTE]
> 此功能随 Voyager 作为官方插件提供，默认开启。点击浏览器工具栏中的扩展图标，在弹窗的 **插件** → **Markdown 渲染修复** 中切换。关闭后不再修复新内容，页面上已修复的内容不会立刻还原，重新加载后恢复 Gemini 原本的显示。重新开启后，会修复当前页面中的格式问题。

关闭后仍可导出对话或创建对话分支，但 Gemini 原有的格式问题可能会保留，例如导出文件中仍显示 Markdown 标记。
