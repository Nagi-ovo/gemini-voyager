# 字体大小

自由调整 Gemini 对话区域的字体大小，获得最舒适的阅读体验。

## 功能介绍

每个人对字体大小的偏好都不同：有人喜欢紧凑的小字，以获得更高的信息密度；也有人偏好大字，以减轻眼睛的疲劳。Voyager 允许你将对话字体大小在 80% 到 150% 之间调整。

## 功能特点

- **灵活范围**：支持 80%–150% 的字体大小调整，覆盖大多数阅读需求。
- **全面覆盖**：同时作用于你的消息和模型回复，包括正文、列表、表格和代码块。
- **代码块优化**：代码块的字体大小会按比例自动缩放（正文字号 × 0.875），保持代码与正文之间的视觉层次。
- **即时生效**：调整后立即生效，无需刷新页面。

## 如何使用

1. 打开 Voyager 设置面板（弹窗）。
2. 找到 **对话字体大小**，并将其开启。
3. 拖动滑块调整字体大小的百分比，页面会实时预览变化。
