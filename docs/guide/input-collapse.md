# 输入框折叠

输入框为空时将其折叠，以获得更多阅读空间。点击折叠后的条形按钮即可展开并开始输入。

## 如何使用

1. 当输入框为空且失去焦点时，它会自动折叠成一个紧凑的胶囊按钮。
2. 点击胶囊按钮即可展开输入框并开始输入。
3. 也可以按 <kbd>Ctrl</kbd>/<kbd>⌘</kbd>+<kbd>I</kbd> 快速展开输入框。
4. 在弹窗的 **输入选项** 下，通过 **启用输入框折叠** 开启或关闭此功能（默认关闭）。
5. 如果希望即使输入框中有文字或附件也能折叠，还需开启 **允许折叠有内容的输入框**。
