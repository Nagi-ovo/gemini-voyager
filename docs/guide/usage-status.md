# 用量状态栏

Gemini 2026 年为对话加入了用量限额，但要查看还剩多少，就得打开完整的 `gemini.google.com/usage` 页面。

Voyager 把你的 **每日** 和 **每周** 限额做成了一个可以拖动的小浮条，常驻在对话界面中。你随时可以瞥一眼，无需离开对话。

![用量状态栏](/assets/gemini-usage-status.png)

## 外观

这是一个紧凑的迷你条：套餐徽章（例如 `PRO`），两条细进度条（每日 / 每周）及其百分比，外加一个刷新按钮和一个用于打开原生用量页面的小图标。整体半透明、低调，不会干扰对话。

## 工作方式

- **可拖动并记住位置**：在浮条任意位置按住即可拖动，松手后放到你顺手的位置。位置会在刷新、页面切换和标签页之间保留。默认位于输入框正上方居中。
- **后台静默刷新**：数据会自动更新，**你无需刷新页面，也无需打开 `/usage`**。每次回复完成后数秒，即用量发生变化时，它会自动刷新；同时还有一个较保守的空闲兜底刷新，每隔几分钟执行一次。
- **悬停查看详情**：将鼠标悬停在某一条上，可以看到该额度的重置时间；悬停在整个浮条上，则显示“刚刚更新”或“X 分钟前更新”。
- **两个专用按钮**：
  - **刷新 ↻**：立即静默更新一次（图标会旋转，数据原地更新，**不会跳转页面**）。
  - **打开 ↗**：在新标签页中打开原生的 `/usage` 页面。这是浮条上**唯一**会跳转的操作。

## 使用方法

1. 打开 Voyager 设置面板（浏览器工具栏中的扩展图标）。
2. 打开 **用量状态栏** 开关（默认关闭）。
3. 浮条会立即出现在对话界面中，你可以将它拖到任意位置。

::: tip 开箱即用
启用后，Voyager 会在后台自动获取你的用量，**无需先访问 `/usage`**。如果 Google 某天修改了内部接口，导致数据无法获取，只需访问一次 `gemini.google.com/usage`，Voyager 就会根据该页面上显示的真实数值重新校准。
:::

## 更新频率与检测

更新采用**事件驱动**方式：只有在你的用量真正发生变化（即你发送了一条消息）之后才会刷新，另外还有一个保守的空闲兜底刷新，**不会进行高频轮询**。每次刷新使用的都是网页本身获取用量时所用的同一个请求，并使用你已登录的会话，频率与正常人工操作相当。请求量大致为“每轮对话一次”，因此对 Google 的检测几乎没有影响。

## 隐私

- 用量数值和浮条位置都**仅保存在本地**（`chrome.storage.local`），不会上传到任何服务器。
- 从不读取或缓存任何对话内容，只保存两个百分比、重置时间和套餐名称。
- 关闭开关后，浮条会被移除；缓存仍保留在本地，因此重新开启时无需重新加载。

## 平台

仅支持 **Google Gemini**（`gemini.google.com`）。
