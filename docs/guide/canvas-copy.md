# Canvas 复制为 Markdown

Voyager 在 Gemini Canvas 的导出菜单中添加 **复制为 Markdown**，将文档内容复制到剪贴板，方便粘贴到笔记或 Markdown 编辑器。

此功能默认开启，无需设置。如需关闭，请打开 Voyager 弹窗，关闭**导出与图片** → **Canvas 复制为 Markdown**。

## 使用方法

1. 在 Gemini Canvas 中打开一篇文本文档。
2. 打开 Canvas 的导出菜单，点击 **复制为 Markdown**。
3. 将内容粘贴到需要的位置。

此功能复制当前 Canvas 文档。要导出整段对话，请使用[对话导出](/guide/export)。
