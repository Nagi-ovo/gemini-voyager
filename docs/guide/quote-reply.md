# 引用回复

Voyager 提供了便捷的“引用回复”功能，让针对特定内容的回复更加精准高效。

## 功能介绍

日常对话中，我们常常需要针对 AI 输出的某一段内容进行追问或反驳。传统做法是复制那段文字，再在输入框里手动输入 `> ` 符号，非常繁琐。

Voyager 简化了这一流程：

1. **选中即引**：在对话页面中用鼠标选中任意文字（无论是你的提问还是 Gemini 的回答）。
2. **悬浮按钮**：选中文字附近会自动出现一个“引用回复”按钮。
3. **一键插入**：点击按钮，选中的文字会以标准的 Markdown 引用格式（`> 内容`）自动插入到输入框中。

![引用回复](/assets/quote-reply.png)

## 如何开启

在 Gemini 上，引用回复由 Voyager 弹窗中 **通用选项** 下的 **启用引用回复** 控制。

在 Claude、ChatGPT 和 DeepSeek 上，请从[插件目录](/plugins)为对应网站安装 **引用回复** 插件。安装后，当你在单条 AI 回复内选中文字时会出现 **Quote** 按钮，引用内容会被添加到草稿中，而不会直接发送。

## 特性

- **上下文感知**：智能识别对话内容，避免在无关区域（例如输入框本身）误触发。
- **标准格式**：使用通用的 Markdown 语法，Gemini 能够完美理解，从而给出更精准的回应。
- **多行支持**：选中多行文字时，Voyager 会自动为每一行添加引用符号，保持格式整洁。

## 使用技巧

- **追问细节**：选中 Gemini 回答中某个不清楚的概念，点击引用，然后输入“请详细解释这个概念”。
- **纠正错误**：选中回答中错误的代码或事实，引用后指出“这里不对，应该是……”。
