# Modelo predeterminado

::: info
**Nota**: esta función es compatible con la versión 1.1.9 y posteriores.
:::

Establece un modelo de Gemini™ preferido como predeterminado para no tener que cambiarlo manualmente en cada conversación nueva.

## Funciones

- **Configuración interactiva**: añade un botón de estrella directamente en el menú nativo de selección de modelos de Gemini.
- **Cambio automático**: cambia al modelo preferido cada vez que empiezas una conversación nueva.
- **También el nivel de razonamiento**: si marcas la opción **Extended thinking**, los chats nuevos también empezarán con ella.
- **Preferencia persistente**: tu elección se guarda y se sincroniza entre tus dispositivos.
- **Optimizado para SPA**: se activa con precisión al hacer clic en el botón "Nuevo chat", al usar atajos o al volver a la página de inicio.

## Cómo usarla

1. Haz clic en el **selector de modelos** situado encima del área de entrada de Gemini.
2. Pasa el cursor sobre el modelo que prefieras y haz clic en el **icono de estrella**.
3. Cuando la estrella esté **rellena**, ese modelo queda establecido como predeterminado.
4. La extensión seleccionará ahora este modelo automáticamente en todos los chats nuevos.
5. Para que los chats nuevos empiecen también con extended thinking, haz clic en la estrella junto a **Extended thinking** en el mismo menú.
6. Para desactivarlo, vuelve a hacer clic en el icono de estrella rellena.

Para pausarlo sin perder tu elección, desactiva **Aplicar modelo predeterminado en chats nuevos** en el popup de Voyager.
