# Evitar el desplazamiento automático

Cuando lees conversaciones anteriores, enviar un nuevo prompt con Enter hace que Gemini™ desplace la página a la fuerza hasta el final para seguir la respuesta recién generada. Esto puede romper la lectura.

La función **Prevent Auto Scroll** (evitar el desplazamiento automático) intercepta ese salto no deseado:

- Cuando has subido para leer el historial, el sistema impide que la página vuelva a bajar de golpe.
- Gemini todavía puede saltar al último mensaje justo después de abrir o cambiar de chat; la protección se aplica mientras lees dentro de un chat.
- Esta función viene **desactivada** por defecto. Puedes activarla en los ajustes del popup, en "Opciones de Línea de Tiempo".

## Cómo activarla

1. Haz clic en el icono de la extensión Voyager en la barra de herramientas del navegador para abrir el popup.
2. Busca la sección "Opciones de Línea de Tiempo".
3. Activa el interruptor "Evitar desplazamiento automático".
