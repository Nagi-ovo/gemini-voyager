# Ocultar elementos recientes y Gems

::: info Función retirada
Voyager ya no oculta estas secciones. El interruptor de elementos recientes se activaba por error con facilidad y era difícil de deshacer, así que se eliminó en mayo de 2026; lo que ocultaste antes vuelve a mostrarse automáticamente. Gemini también ha movido Gems al menú «Más», así que el interruptor de Gems también se ha retirado.
:::

Esta página se mantiene para que los marcadores y enlaces existentes sigan funcionando.
