# Correction du Rendu Markdown

L'interface web de Gemini™ insère parfois des éléments HTML (tels que des sources de citation ou des marqueurs de mise en évidence) dans le texte, ce qui peut briser la syntaxe Markdown pour le gras (`**texte**`), empêchant le texte de s'afficher correctement en gras.

Voyager dispose d'une fonction de correction automatique intégrée qui identifie et répare intelligemment ces balises de gras corrompues, garantissant ainsi un rendu propre et précis de vos documents.

> [!NOTE]
> Ce plugin officiel est inclus dans Voyager et activé par défaut. Cliquez sur l’icône de l’extension dans la barre d’outils du navigateur, puis utilisez **Contenu des réponses** → **Correction du rendu Markdown** dans la fenêtre contextuelle pour l’activer ou le désactiver. Une fois désactivé, il ne corrige plus les nouveaux contenus, mais les corrections déjà visibles restent en place. Rechargez la page pour retrouver la mise en forme d’origine de Gemini. En le réactivant, vous corrigez la mise en forme de la page actuelle.

L’exportation et la bifurcation de conversation restent disponibles lorsque ce plugin est désactivé, mais les défauts de mise en forme de Gemini peuvent subsister, notamment des marqueurs Markdown visibles dans les fichiers exportés.
