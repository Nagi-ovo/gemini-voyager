# Modèle par défaut

::: info
**Remarque** : cette fonctionnalité est prise en charge à partir de la version 1.1.9.
:::

Définissez un modèle Gemini™ préféré comme modèle par défaut, pour ne plus le changer manuellement à chaque nouvelle conversation.

## Fonctionnalités

- **Configuration interactive** : ajoute un bouton « Étoile » directement dans le menu natif de sélection de modèle de Gemini.
- **Bascule automatique** : passe automatiquement à votre modèle préféré chaque fois que vous commencez une nouvelle conversation.
- **Niveau de réflexion aussi** : mettez en favori l'option **Réflexion approfondie** (Extended thinking), et les nouvelles conversations démarrent avec elle également.
- **Préférence persistante** : votre choix est enregistré et synchronisé entre vos appareils.
- **Optimisé pour les SPA** : se déclenche correctement lorsque vous cliquez sur le bouton « Nouveau chat », que vous utilisez un raccourci ou que vous revenez à la page d'accueil.

## Mode d'emploi

1. Cliquez sur le **sélecteur de modèle** au-dessus de la zone de saisie de Gemini.
2. Survolez votre modèle préféré et cliquez sur l'**icône Étoile**.
3. Une fois l'étoile **pleine**, ce modèle est défini comme modèle par défaut.
4. L'extension sélectionnera désormais automatiquement ce modèle pour toutes les nouvelles conversations.
5. Pour démarrer aussi les nouvelles conversations avec la réflexion approfondie, cliquez sur l'étoile à côté de **Réflexion approfondie** dans le même menu.
6. Pour annuler, cliquez à nouveau sur l'icône d'étoile pleine.

Pour la mettre en pause sans perdre votre choix, désactivez **Appliquer le modèle par défaut aux nouveaux chats** dans la fenêtre de Voyager.
