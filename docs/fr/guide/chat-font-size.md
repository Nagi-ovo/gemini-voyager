# Taille de police

Ajustez librement la taille de police dans la zone de chat de Gemini pour une lecture la plus confortable possible.

## Présentation

Chacun a ses préférences en matière de taille de police : certains préfèrent un texte compact pour une densité d'information plus élevée, d'autres un texte plus grand pour limiter la fatigue visuelle. Voyager vous permet de régler la taille de police du chat entre 80 % et 150 %.

## Fonctionnalités

- **Plage souple** : ajustement de la taille de police de 80 % à 150 %, pour couvrir la plupart des besoins de lecture.
- **Couverture complète** : s'applique aux messages utilisateur et aux réponses du modèle, y compris le texte courant, les listes, les tableaux et les blocs de code.
- **Blocs de code adaptés** : la taille de police des blocs de code s'adapte automatiquement en proportion (police du texte × 0,875), pour préserver la hiérarchie visuelle entre le code et le texte.
- **Effet instantané** : les changements prennent effet immédiatement, sans rechargement de la page.

## Mode d'emploi

1. Ouvrez le panneau des paramètres de Voyager (fenêtre de l'extension).
2. Repérez le réglage **Taille de police du chat** et activez-le.
3. Faites glisser le curseur pour ajuster le pourcentage : la page affiche les changements en temps réel.
