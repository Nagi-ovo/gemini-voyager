# Empêcher le défilement auto

Lorsque vous lisez vos conversations passées, si vous appuyez sur Entrée pour envoyer un nouveau prompt, Gemini™ a pour habitude de faire défiler automatiquement la page tout en bas afin de suivre la réponse générée. Cela peut perturber votre lecture.

La fonctionnalité **Empêcher le défilement auto** intercepte ce comportement indésirable :

- Lorsque vous avez fait défiler la page vers le haut, le système empêche le saut incontrôlé vers le bas de la page.
- Gemini peut toujours aller au dernier message juste après l'ouverture ou le changement d'une discussion : la protection s'applique pendant que vous lisez à l'intérieur d'une discussion.
- Cette fonctionnalité est **désactivée** par défaut. Vous pouvez l'activer manuellement dans les paramètres de l'extension ("Options de la chronologie").

## Comment l'activer

1. Cliquez sur l'icône de l'extension Voyager pour ouvrir la popup.
2. Repérez la section "Options de la chronologie".
3. Activez l'option "Empêcher le défilement auto".
