# Suppression par lot

Supprimez plusieurs conversations à la fois sur Gemini et AI Studio : fini la suppression une par une.

## Fonctionnalités

- **Mode multi-sélection** : faites un appui long sur n'importe quelle conversation pour passer en mode multi-sélection, puis cochez celles que vous voulez supprimer.
- **Nettoyage en un clic** : une fois la sélection faite, cliquez sur le bouton de suppression pour retirer toutes les conversations choisies d'un seul coup.
- **Suivi de la progression** : la progression est affichée en temps réel pendant la suppression, pour que vous sachiez où en est l'opération.
- **Confirmation de sécurité** : une boîte de dialogue de confirmation s'affiche avant la suppression pour éviter les manipulations accidentelles.

## Mode d'emploi

### Gemini

1. Dans la liste des conversations de la barre latérale, faites un **appui long** sur n'importe quel élément de conversation.
2. Une fois le mode multi-sélection activé, des cases à cocher apparaissent à gauche de chaque conversation.
3. Cochez les conversations à supprimer (jusqu'à 50 à la fois).
4. Cliquez sur le **bouton Supprimer** qui apparaît.
5. Cliquez sur « Confirmer » dans la zone de confirmation rouge qui s'affiche **au-dessus de la liste des dossiers** pour lancer la suppression.

### AI Studio

1. Ouvrez la page **Library** d'AI Studio.
2. Faites un **appui long** sur n'importe quelle ligne de prompt pour passer en mode multi-sélection.
3. Sélectionnez les prompts à supprimer (jusqu'à 50 à la fois).
4. Cliquez sur le **bouton Supprimer** flottant, puis confirmez l'invite du navigateur.

::: tip Remarque
Sur Gemini, le panneau de confirmation se superpose à la zone des dossiers pour ne pas bloquer la liste des conversations. Les suppressions par lot ne peuvent pas être annulées : procédez avec prudence.
:::
