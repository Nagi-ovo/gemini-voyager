# Copier un document Canvas en Markdown

Voyager ajoute **Copier en Markdown** au menu de partage de Gemini Canvas. Copiez le document dans le presse-papiers, puis collez-le dans vos notes ou dans un éditeur Markdown.

Cette fonction est activée par défaut et ne nécessite aucun réglage.

## Utilisation

1. Ouvrez un document texte dans Gemini Canvas.
2. Ouvrez le menu de partage de Canvas et cliquez sur **Copier en Markdown**.
3. Collez le contenu à l’endroit souhaité.

Seul le document Canvas ouvert est copié. Pour exporter toute une conversation, utilisez l’[export de conversations](/fr/guide/export).
