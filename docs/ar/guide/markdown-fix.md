# إصلاح عرض Markdown

تُدرج واجهة ويب Gemini™ أحيانًا عناصر HTML (مثل مصادر الاستشهاد أو علامات التمييز) داخل النص، وقد يؤدي ذلك إلى كسر صياغة Markdown للنص العريض (`**text**`)، فلا يظهر النص بالخط العريض كما ينبغي.

يتضمن Voyager ميزة إصلاح تلقائي مدمجة تتعرف بذكاء على وسوم النص العريض المكسورة وتصلحها، لضمان أن يُعرض مستندك بشكل نظيف ودقيق.

> [!NOTE]
> هذه الميزة مفعّلة تلقائيًا ولا تحتاج إلى أي إعداد إضافي.
