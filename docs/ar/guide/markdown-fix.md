# إصلاح عرض Markdown

تقوم واجهة ويب Gemini™ أحياناً بإدراج عناصر HTML (مثل مصادر الاقتباس أو علامات التمييز) داخل النص، مما قد يؤدي إلى كسر تنسيق Markdown للنص العريض (`**النص**`)، ويتسبب في عدم ظهور النص بشكل عريض صحيحاً.

يتضمن Voyager ميزة إصلاح تلقائي مدمجة تتعرف بذكاء على علامات النص العريض المكسورة هذه وتقوم بإصلاحها، مما يضمن عرض مستنداتك بشكل نظيف ودقيق.

> [!NOTE]
> هذه إضافة رسمية مضمنة في Voyager ومفعّلة افتراضيًا. انقر على أيقونة الإضافة في شريط أدوات المتصفح، ثم استخدم **الإضافات** ← **إصلاح عرض Markdown** في النافذة المنبثقة لتشغيلها أو إيقافها. عند إيقافها، تتوقف عن إصلاح المحتوى الجديد، لكن الإصلاحات الظاهرة على الشاشة تبقى كما هي. أعد تحميل الصفحة لرؤية تنسيق Gemini الأصلي. عند تشغيلها مجددًا، تُصلح التنسيق في الصفحة الحالية.

يظل تصدير المحادثات وتفريعها متاحًا عند تعطيل الإضافة، لكن قد تبقى مشكلات التنسيق في Gemini، مثل ظهور علامات Markdown في الملفات المُصدَّرة.
