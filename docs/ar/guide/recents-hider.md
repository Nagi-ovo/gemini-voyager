# إخفاء العناصر الأخيرة والـ Gems

::: info ميزة متوقفة
لم يعد Voyager يخفي هذه الأقسام. كان مفتاح "العناصر الأخيرة" سهل النقر عن طريق الخطأ وصعب التراجع عنه، لذا أُزيل في مايو 2026؛ وأي عناصر أخفيتها من قبل ستظهر مجددًا تلقائيًا. ونقل Gemini أيضًا Gems إلى قائمة «المزيد»، لذا أُلغي مفتاح Gems أيضًا.
:::
