# نقل الذاكرة: مزامنة السياق (تجريبي)

**أبعاد مختلفة، ومشاركة سلسة**

طوّر المنطق على الويب، ونفّذ الكود في بيئة التطوير (IDE). يكسر Voyager حواجز الأبعاد، فيمنح IDE الخاص بك "عملية التفكير" من الويب فورًا.

## لا مزيد من التنقل بين التبويبات

أكبر إزعاج للمطورين: بعد مناقشة حل بالتفصيل على الويب، تعود إلى VS Code أو Trae أو Cursor فتضطر إلى إعادة شرح المتطلبات وكأنك تتحدث إلى غريب. فبسبب الحصص وسرعة الاستجابة، يكون الويب هو "الدماغ" وIDE هو "اليدين". يتيح Voyager لهما أن يتشاركا الروح نفسها.

## ثلاث خطوات بسيطة للمزامنة

1. **ثبّت CoBridge وشغّله**:
   ثبّت إضافة **CoBridge** في VS Code أو في أي محرر متوافق. وهي الجسر الأساسي الذي يربط واجهة الويب ببيئة التطوير المحلية لديك.
   - **[التثبيت من Open VSX](https://open-vsx.org/extension/windfall/co-bridge)**

   ![إضافة CoBridge](/assets/CoBridge-extension.png)

   بعد التثبيت، **افتح أي مجلد عمل**، وانقر على الأيقونة على اليمين، ثم شغّل الخادم.
   ![تشغيل خادم CoBridge](/assets/CoBridge-on.png)

2. **المصافحة والاتصال**:
   - في قسم **مزامنة السياق** في نافذة Voyager المنبثقة، اضبط **وضع المزامنة** على **يدوي**.
   - اجعل **منفذ الخادم** مطابقًا للمنفذ الذي يستخدمه CoBridge. عندما ترى **IDE متصل**، يكون الاتصال قد تم.

   ![لوحة مزامنة السياق](/assets/context-sync-console.png)

3. **مزامنة بنقرة واحدة**: انقر على **مزامنة مع IDE**. سواء كانت **جداول بيانات** معقدة أو **صورًا مرجعية** بديهية، يمكن نقل كل ذلك إلى IDE فورًا.

   ![اكتملت المزامنة](/assets/sync-done.png)

## الترسيخ داخل IDE

بعد المزامنة، يظهر الملف `.cobridge/AI_CONTEXT.md` في مجلد العمل داخل IDE. سواء كنت تستخدم Trae أو Cursor أو Copilot، فستقرأ هذه "الذاكرة" تلقائيًا من خلال ملفات القواعد (Rule) الخاصة بكل منها.

```
your-project/
├── .cobridge/
│   ├── images/
│   │   ├── context_img_1_1.png
│   │   └── context_img_1_2.png
│   └── AI_CONTEXT.md
├── .github/
│   └── copilot-instructions.md
├── .gitignore
├── .traerules
└── .cursorrules
```

## المبادئ

- **دون تلويث**: يتولى CoBridge إدارة `.gitignore` تلقائيًا، ليضمن عدم دفع محادثاتك الخاصة إلى مستودعات Git.
- **متوافق مع المعايير**: تنسيق Markdown كامل، ما يجعل قراءة الذكاء الاصطناعي داخل IDE له بسلاسة قراءة دليل التعليمات.
- **نصيحة احترافية**: إذا كانت المحادثة قديمة، فمرّر إلى الأعلى باستخدام [الجدول الزمني](/ar/guide/timeline) أولًا، ليتذكر الويب السياق ويعطيك نتائج مزامنة أفضل.
