# Copiar Canvas como Markdown

O Voyager adiciona **Copiar como Markdown** ao menu de compartilhamento do Gemini Canvas. Copie o documento para a área de transferência e cole nas suas notas ou em um editor de Markdown.

Esse recurso está ativado por padrão e não precisa de configuração.

## Como usar

1. Abra um documento de texto no Gemini Canvas.
2. Abra o menu de compartilhamento do Canvas e clique em **Copiar como Markdown**.
3. Cole o conteúdo onde precisar.

Apenas o documento aberto no Canvas é copiado. Para exportar uma conversa inteira, use a [exportação de conversas](/pt/guide/export).
