# Recolher a entrada

Recolha a área de entrada quando ela estiver vazia para ganhar mais espaço de leitura. Clique na barra recolhida para expandir e começar a digitar.

## Como usar

1. Quando a área de entrada está vazia e perde o foco, ela se recolhe automaticamente em um botão compacto em formato de pílula
2. Clique no botão em formato de pílula para expandir a área de entrada e começar a digitar
3. Você também pode pressionar <kbd>Ctrl</kbd>/<kbd>⌘</kbd>+<kbd>I</kbd> para expandir a área de entrada rapidamente
4. Ative ou desative o recurso em **Habilitar contração de entrada**, em **Opções de entrada** no popup (desativado por padrão)
5. Ative também **Permitir recolher com conteudo** se quiser que a área de entrada se recolha mesmo quando tiver texto ou anexos
