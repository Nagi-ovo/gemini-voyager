# Tamanho da fonte

Ajuste livremente o tamanho da fonte na área de chat do Gemini para uma leitura mais confortável.

## Introdução

Cada pessoa tem preferências diferentes de tamanho de fonte: algumas preferem texto compacto para mais informação na tela, enquanto outras preferem texto maior para reduzir a fadiga visual. O Voyager permite ajustar o tamanho da fonte do chat entre 80% e 150%.

## Recursos

- **Faixa flexível**: Suporta ajuste de 80% a 150%, cobrindo a maioria das necessidades de leitura.
- **Cobertura completa**: Vale tanto para as mensagens do usuário quanto para as respostas do modelo, incluindo texto corrido, listas, tabelas e blocos de código.
- **Otimização de blocos de código**: O tamanho da fonte dos blocos de código é reduzido proporcionalmente (fonte do texto × 0,875), mantendo a hierarquia visual entre código e texto.
- **Efeito instantâneo**: As mudanças valem imediatamente, sem recarregar a página.

## Como usar

1. Abra o painel de configurações do Voyager (popup).
2. Encontre **Tamanho da fonte do chat** e ative a opção.
3. Arraste o controle deslizante para ajustar a porcentagem do tamanho da fonte; a página mostra as mudanças em tempo real.
