# Modelo padrão

::: info
**Nota**: Este recurso é suportado na versão 1.1.9 e posteriores.
:::

Defina um modelo Gemini™ preferido como padrão para não precisar trocar manualmente a cada nova conversa.

## Recursos

- **Configuração interativa**: Adiciona um botão de estrela diretamente no menu nativo de seleção de modelos do Gemini.
- **Troca automática**: Seleciona automaticamente o seu modelo preferido sempre que você inicia uma nova conversa.
- **Nível de raciocínio também**: Marque com estrela a opção **Extended thinking** e os novos chats também começam com ela.
- **Preferência persistente**: Sua escolha é salva e sincronizada entre os seus dispositivos.
- **Otimizado para SPA**: É acionado com precisão ao clicar no botão "Novo chat", usar atalhos ou voltar à página inicial.

## Como usar

1. Clique no **Seletor de modelo** acima da área de entrada do Gemini.
2. Passe o mouse sobre o modelo preferido e clique no **ícone de estrela**.
3. Quando a estrela estiver **preenchida**, esse modelo fica definido como padrão.
4. A extensão passa a selecionar esse modelo automaticamente em todos os novos chats.
5. Para que os novos chats também comecem com o Extended thinking, clique na estrela ao lado de **Extended thinking** no mesmo menu.
6. Para desfazer, basta clicar de novo no ícone de estrela preenchida.

Para pausar sem perder a sua escolha, desative **Aplicar modelo padrão em novos chats** no popup do Voyager.
