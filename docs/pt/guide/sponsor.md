Manter projetos de código aberto é movido principalmente por paixão (e café) ☕

Não há Google Ads neste site, e a extensão não tem versão paga. Também recusei financiamento de serviços de API relay/revenda, porque não consigo garantir como eles tratam os dados dos usuários. A intenção é simples: construir uma ferramenta que eu uso todo dia e recomendaria com prazer a um amigo, mantendo a autenticidade num mundo barulhento.
