# Ecossistema

Os projetos a seguir foram inspirados no Voyager ou são construídos sobre ele, trazendo melhorias semelhantes para outras plataformas.

- **[DeepSeek Voyager](https://github.com/Azurboy/deepseek-voyager)** — Um fork do Voyager adaptado para o DeepSeek, trazendo navegação por linha do tempo e gerenciamento de conversas para quem usa o DeepSeek!
- **[claude-nexus](https://github.com/Qiuner/claude-nexus)** — Uma extensão de aprimoramento para o Claude.ai inspirada no Voyager, com navegação por linha do tempo, organização em pastas, biblioteca de prompts e muito mais, com compatibilidade total de importação e exportação de prompts com o Voyager!
- **[Better_Doubao](https://github.com/Rex16200513/Better_Doubao)** — Uma extensão de navegador avançada que turbina o Doubao com recursos aprimorados de navegação, organização e produtividade.
- **[DeepSeek Enhancer](https://github.com/dlshuangchenyue1210/DeepSeek-Enhancer)** — Uma extensão inspirada no Voyager para o app web do DeepSeek, com pastas em vários níveis, exportação de conversas, cópia de fórmulas, backup de dados e muito mais.
