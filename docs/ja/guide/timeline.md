# タイムトラベル

Voyager タイムラインは、Gemini・Claude・ChatGPT のための、視覚的な会話ナビゲーションです。チャット内のすべてのメッセージを画面右側のインタラクティブなノードに対応させ、長い AI との会話を、瞬時に飛び移れるナビゲーションマップに変えます。

長い会話は散らかりがちです。上へスクロールし、下へスクロールし、今どこにいるのか分からなくなります。
Voyager は、会話をタイムラインに変えます。

Gemini の設定にある **タイムラインを表示** は、タイムラインのバーとナビゲーションのショートカットを制御します。オフにしても、保存したスターと階層は残ります。メッセージの時刻ラベルは **メッセージのタイムスタンプを表示** で個別に制御するため、タイムラインをオフにしたままでも時刻だけを表示できます。

## 会話の形を見る

画面の右端を見てください。
各ノードが一つのメッセージを表しています。タイムラインは、対話のリズムを可視化します。

## ナビゲーションが、ぐっと楽に

- **瞬間移動**: ノードをクリックすると、そのメッセージへ即座に移動します。
- **プレビュー**: カーソルを重ねると、位置を動かさずに中身を確認できます。
- **ブックマーク**: ノードを長押しして **スター** を付けます。自分用の栞のようなものです。
- **階層（実験的）**: ノードを右クリックすると、レベル（1〜3）を設定したり、子ノードを折りたためたりします。分岐した会話を整理するのに役立ちます。
- **サイズ変更**: タイムラインの内側の端をドラッグして、幅を調整できます。
- **キーボード**: 思考と同じ速さで移動できます。既定では `j`/`k`、`gg`/`GG` で最初・最後のターンへ移動します。

## スター: 大事な瞬間に栞を挟む

長い会話には、大切な内容が埋もれがちです。重要な瞬間にスターを付けておきましょう。

**使い方**: タイムライン上の任意のノードを長押し（約 0.5 秒）します。ノードが光れば、そのメッセージにスターが付いた状態です。

- もう一度長押しすると、スターを外せます。
- スター付きのノードは強調表示されるので、ひと目で見つけられます。
- Voyager のポップアップにある **保存済みライブラリを表示** をクリックするか、プロンプトマネージャーのパネルから開くと、スターを付けたメッセージを **保存済みライブラリ** でまとめて確認できます。

会話の中に旗を立てるようなものです。ひらめいた瞬間、ほしかった答えが得られた瞬間、あとで続きから再開したい瞬間に使えます。

::: tip ヒント
[クラウド同期](/ja/guide/cloud-sync) を有効にしていれば、スターはデバイス間で同期されます。
:::

## 見た目を整える

Voyager のポップアップの **タイムラインオプション** で設定できます。

- **タイムライン表示**: `ノード`、`目盛り`、`コンパクト` から選べます。
- **プレビューを固定表示**: タイムラインの横にプレビューパネルを開いたままにできます。パネルの検索ボックスに入力すると、メッセージを絞り込めます。
- **ドラッグ可能なタイムライン**: タイムラインをページ上の好きな位置に動かせます。**タイムラインの位置をリセット** を押すと元に戻ります。

## キーボードでさらに速く

マウスを使いたくない？ キーボードで操作できます。

**まるで Gemini で Vim モードを使っているような感覚です。**

### 既定のショートカット

- `k` - 前のノードへ移動
- `j` - 次のノードへ移動
- `gg` - 最初のターンへ移動
- `GG` - 最後のターンへ移動

### カスタマイズ

拡張機能の設定を開き、ショートカットの欄をクリックしてから、好きなキーを押します。
任意のキー、任意の組み合わせに設定できます。`n`/`p` でも `,`/`.` でも、お好みで。

**フローモード**: 連続して押したキーが、なめらかに順番に処理されます。
**ジャンプモード**: 即座に反応し、最高速で移動します。

## タイムラインが役立つ場面

タイムラインが特に役立つのは、10 件を超える長い会話で、スクロールが非効率になってきたときです。

- **リサーチ**: ある話題について 30 往復以上 Gemini と掘り下げた。タイムラインを使えば、すべてを読み直さなくても、重要な知見に戻れます。
- **コードのデバッグ**: 長いデバッグの会話で、47 ターン目に解決策が出てきた。そこにスターを付けておけば、あとからワンクリックで見つけられます。
- **学習と個別指導**: 複雑な話題を一歩ずつ進めている。習得済みの部分はレベルで折りたためます。
- **アイデアの振り返り**: 発想のセッションを見直して、良いアイデアを拾い出す。残す価値のある瞬間にスターを付けます。

## タイムラインと手動スクロールの比較

| できること                     | タイムラインなし               | Voyager タイムラインあり                       |
| ------------------------------ | ------------------------------ | ---------------------------------------------- |
| 特定のメッセージを探す         | 上下に何度もスクロールする     | ノードをクリックするか、j/k を押す             |
| 大事な瞬間を残す               | 外部のメモにコピーペーストする | 長押しでスターを付ける。クラウドにも同期される |
| 会話の構造を見る               | 順番に読む                     | 視覚的なマップで全体の形がひと目で分かる       |
| キーボード操作                 | Gemini では利用不可            | Vim 風の j/k、gg/GG。すべてカスタマイズ可能    |
| 100 件を超えるメッセージの移動 | 何分もスクロールする           | 任意の地点へ瞬時にジャンプ                     |
| 長いスレッドの整理             | 組み込みのツールなし           | レベル（1〜3）と折りたたみ可能な子ノード       |

## 対応ブラウザ

タイムラインは Google Gemini で動作し、Claude と ChatGPT では組み込みのプラグインとして動作します。対応ブラウザは Chrome、Edge、Firefox、Safari、Opera、Brave です。キーボードショートカット、スター、階層はどのプラットフォームでも同じように動作します。[クラウド同期](/ja/guide/cloud-sync) を有効にすると、スター付きのメッセージはデバイス間で同期されます。

タイムラインは AI Studio では利用できません。DeepSeek には、プラグインカタログにオプションのタイムラインプラグインがあります（初期状態では無効です）。
