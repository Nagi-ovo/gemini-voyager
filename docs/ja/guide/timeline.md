# 時間旅行

Voyager タイムラインは、Gemini・Claude・ChatGPT のための、視覚的な会話ナビゲーションです。チャット内のすべてのメッセージを画面右側のインタラクティブなノードに対応させ、長い AI との会話を、瞬時に飛び移れるナビゲーションマップに変えます。

長い会話は迷宮です。上へ下へとスクロールし、方向を見失います。
Voyager は、会話を一筋の「線」に変えます。

Gemini の **タイムライン** → **タイムラインを表示** は、タイムラインのバーとナビゲーション用ショートカットを制御します。オフにしても、保存済みのスターと階層は残ります。メッセージの時刻ラベルは**タイムライン** → **メッセージのタイムスタンプ** で個別に設定するため、タイムラインをオフにしたまま表示できます。

Claude、ChatGPT、DeepSeek では、タイムラインのバーはそのサイトのタイムラインプラグインです。**プラグイン** でオンにすると、その **オプション** にスタイル、ノード階層(提供されている場合)、**タイムラインの位置をリセット**、**保存済みライブラリを表示** が並びます。ChatGPT ではメッセージのタイムスタンプもここにあります。

## リズムを見る

画面の右端を見てください。
そこにある点は、一つひとつが発言です。それは、あなたとAIの対話の脈動そのものです。

## ナビゲーション、一足飛び

- **瞬時に移動**：クリックした場所へ、即座に飛びます。もたつきません。
- **のぞき見**：マウスを乗せるだけで、ジャンプせずに中身を確認できます。
- **ブックマーク**：ノードを長押しして **スター** を付けましょう。脳のしおりです。
- **階層化 (実験的)**：デフォルトはオフです。まず **タイムライン** → **タイムラインを表示** をオンにし、その行の下で **ノード階層を有効化** をオンにしてから、ノードを右クリックして、レベル（1-3）を設定したり、子ノードを折りたたんだりできます。深い議論の枝葉を一目で把握できます。階層は `ノード` 表示でのみ表示されます。オンにするとタイムラインは `ノード` に切り替わり、オンの間は `目盛り` と `コンパクト` を選べません。
- **幅の調整**：タイムラインの内側の端をドラッグして幅を調整できます。
- **ショートカット**：キーボードで高速移動。デフォルトは `j`/`k`、`gg`/`GG` で最初/最後のターンへ。

## スター：ひらめきをブックマーク

長い会話の中に、宝石が埋もれています。大事な瞬間をスターで留めましょう。

**使い方**：タイムライン上の任意のノードを長押し（約0.5秒）します。ノードが光れば、そのメッセージにスターが付きました。

- もう一度長押しでスターを解除。
- スター付きノードはハイライト表示され、ひと目で見つけられます。
- Voyager のポップアップの **タイムライン** → **タイムラインを表示** をオンにし、その行の下で **保存済みライブラリを表示** をクリックするか、プロンプトマネージャーのパネルから開くと、**保存済みライブラリ** で全てのスター付きメッセージをまとめて確認できます。

会話にフラグを立てるようなものです——ひらめきの瞬間、完璧な回答、次回ここから再開したいポイント。

::: tip ヒント
[クラウド同期](/ja/guide/cloud-sync)を有効にすると、スターはデバイス間で同期されます。
:::

## 見た目を整える

Voyager のポップアップで **タイムライン** → **タイムラインを表示** をオンにすると、その行の下で設定できます。

- **タイムライン表示**: `ノード`、`目盛り`、`コンパクト` から選べます。
- **プレビューを固定表示**: タイムラインの横にプレビューパネルを開いたままにできます。パネルの検索ボックスに入力すると、メッセージを絞り込めます。
- **ドラッグ可能なタイムライン**: タイムラインをページ上の好きな位置に動かせます。**タイムラインの位置をリセット** を押すと元に戻ります。

## キーボードが生む速度

マウスを使いたくない？ キーボードがあります。

**まるで Gemini で Vim モードを使っているかのように。**

### デフォルト・ショートカット

- `k` - 前のノードへ移動
- `j` - 次のノードへ移動
- `gg` - 最初のターンへ移動
- `GG` - 最後のターンへ移動

### カスタマイズ

拡張機能の設定を開き、ショートカットの入力欄をクリックして、使いたいキーを押すだけです。
任意のキー、任意の組み合わせで。`n`/`p`？ `,`/`.`？ お好みでどうぞ。

**フローモード**では、連打するとアニメーションがキューに入って滑らかに再生されます。
**ジャンプモード**では、即座に反応し、最高速度で移動します。

## タイムラインが役立つ場面

タイムラインが特に役立つのは、10 件を超える長い会話で、スクロールが非効率になってきたときです。

- **リサーチ**: ある話題について 30 往復以上 Gemini と掘り下げた。タイムラインを使えば、すべてを読み直さなくても、重要な知見に戻れます。
- **コードのデバッグ**: 長いデバッグの会話で、47 ターン目に解決策が出てきた。そこにスターを付けておけば、あとからワンクリックで見つけられます。
- **学習と個別指導**: 複雑な話題を一歩ずつ進めている。習得済みの部分はレベルで折りたためます。
- **アイデアの振り返り**: 発想のセッションを見直して、良いアイデアを拾い出す。残す価値のある瞬間にスターを付けます。

## タイムラインと手動スクロールの比較

| できること                     | タイムラインなし               | Voyager タイムラインあり                                   |
| ------------------------------ | ------------------------------ | ---------------------------------------------------------- |
| 特定のメッセージを探す         | 上下に何度もスクロールする     | ノードをクリックするか、j/k を押す                         |
| 大事な瞬間を残す               | 外部のメモにコピーペーストする | 長押しでスターを付ける。クラウドにも同期される             |
| 会話の構造を見る               | 順番に読む                     | 視覚的なマップで全体の形がひと目で分かる                   |
| キーボード操作                 | Gemini では利用不可            | Vim 風の j/k、gg/GG。すべてカスタマイズ可能                |
| 100 件を超えるメッセージの移動 | 何分もスクロールする           | 任意の地点へ瞬時にジャンプ                                 |
| 長いスレッドの整理             | 組み込みのツールなし           | レベル（1〜3）と折りたたみ可能な子ノード（実験的、要オン） |

## 対応ブラウザ

タイムラインは Google Gemini で動作し、Claude と ChatGPT では組み込みのプラグインとして動作します。対応ブラウザは Chrome、Edge、Firefox、Safari、Opera、Brave です。キーボードショートカットとスターは 3 つのプラットフォームで同じように動作します。階層はどのプラットフォームでも実験的なオプトイン機能です。Gemini では **タイムライン** → **タイムラインを表示** をオンにし、その行の下で **ノード階層を有効化** をオンにし、Claude と ChatGPT では **プラグイン** にある **タイムライン** の設定で同じスイッチをオンにします。[クラウド同期](/ja/guide/cloud-sync) を有効にすると、スター付きのメッセージはデバイス間で同期されます。

タイムラインは AI Studio では利用できません。DeepSeek には、プラグインカタログにオプションのタイムラインプラグインがあります（初期状態では無効です）。
