# 入力欄の折りたたみ

入力欄が空のときは折りたたんで、読書のためのスペースを広げられます。折りたたまれたバーをクリックすると展開し、入力を始められます。

</div>

## 使い方

1. 入力欄が空で、フォーカスが外れると、コンパクトなカプセル型のボタンに自動的に折りたたまれます。
2. カプセル型のボタンをクリックすると、入力欄が展開され、入力を始められます。
3. <kbd>Ctrl</kbd>/<kbd>⌘</kbd>+<kbd>I</kbd> を押しても、入力欄を素早く展開できます。
4. ポップアップの **入力オプション** で **入力欄の自動非表示を有効化** をオンまたはオフにします（既定ではオフです）。
5. テキストや添付ファイルがあっても入力欄を折りたたみたい場合は、**内容ありでも折りたたみを許可** もオンにしてください。
