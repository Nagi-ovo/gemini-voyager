# デフォルトモデル

::: info
**注意**: この機能はバージョン 1.1.9 以降でサポートされています。
:::

お気に入りの Gemini™ モデルをデフォルトに設定すると、新しい会話のたびに手動で切り替える必要がなくなります。

## 機能の特徴

- **直感的な設定**: Gemini のネイティブのモデル選択メニューに、「スター」ボタンを直接追加します。
- **自動切り替え**: 新しい会話を始めるたびに、お好みのモデルへ自動的に切り替わります。
- **思考レベルも対象**: **Extended thinking**（拡張思考）にスターを付けると、新しいチャットもその設定で始まります。
- **設定の保存**: 選んだ内容は保存され、デバイス間で同期されます。
- **SPA に最適化**: 「新しいチャット」ボタンをクリックしたとき、ショートカットを使ったとき、ホームページに戻ったときに、正しく動作します。

## 使い方

1. Gemini の入力欄の上にある **モデルセレクター** をクリックします。
2. お好みのモデルにカーソルを合わせ、**スターアイコン** をクリックします。
3. スターが **塗りつぶされた**状態になると、そのモデルがデフォルトに設定されます。
4. 以降は、新しいチャットを始めるたびに、このモデルが自動で選ばれます。
5. 新しいチャットでも拡張思考を使うには、同じメニューで **Extended thinking** の横にあるスターをクリックします。
6. 解除するには、塗りつぶされたスターアイコンをもう一度クリックします。

選択内容を失わずに一時停止したい場合は、Voyager のポップアップで **新しい会話でデフォルトモデルを自動適用** をオフにしてください。
