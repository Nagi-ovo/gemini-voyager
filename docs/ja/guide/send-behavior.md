# 送信動作

::: info
**注意**: この機能はバージョン 1.3.7 以降でサポートされています。
:::

送信ショートカットを `Ctrl+Enter`（macOS では `⌘+Enter`）に変更し、`Enter` キーを改行キーにすることで、複数行のプロンプトをゆったりと作成できます。

## なぜこの機能が必要か

デフォルトでは `Enter` を押すとメッセージが即座に送信されます。長めのプロンプトを書いたり、複数行のコードを貼り付けたり、入力を丁寧にフォーマットしたりする際に、誤送信がよく起こります——改行したかっただけなのに、メッセージが送信されてしまうのです。

有効にすると：

- **Enter** → 改行を挿入
- **Ctrl+Enter**（macOS: **⌘+Enter**） → メッセージを送信

Shift+Enter と IME の変換中はサイト本来の動作のままです。添付ファイルのアップロード中は、Ctrl/⌘+Enter での送信はアップロード完了を待ちます。

## 有効にする方法

1. Voyager のポップアップを開きます。
2. **入力** → **Ctrl/Cmd+Enter で送信** をオンにします。

## ほかのサイト

- **AI Studio** は逆の動作です：**AI Studio で Enter 送信** をオンにすると、`Enter` で送信、`Ctrl/⌘+Enter` で改行になります。
- **Claude、ChatGPT、DeepSeek**：[マーケットプレイス](/ja/guide/plugins) から、そのサイト用の **Ctrl/⌘+Enterで送信** プラグインをインストールしてください。
- **Safari**：Gemini で送信に Enter を 2 回押す必要がある場合は、**Safari の Enter キーを修正** をオンにしてください。

## 機能の特徴

- **ゼロパフォーマンスオーバーヘッド**：無効時はキーボードイベントリスナーが一切動作せず、ページパフォーマンスに影響しません。
- **即時切り替え**：設定でトグルした後すぐに反映、ページの更新は不要です。
