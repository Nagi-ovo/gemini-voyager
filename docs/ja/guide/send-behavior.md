# 送信の動作

::: info
**注意**: この機能はバージョン 1.3.7 以降で利用できます。
:::

送信ショートカットを `Ctrl+Enter`（macOS では `⌘+Enter`）に変えると、`Enter` キーは改行になります。複数行のプロンプトを、楽に書けるようになります。

## この機能が必要な理由

既定では、`Enter` を押すとすぐにメッセージが送信されます。長いプロンプトを書いたり、複数行のコードを貼り付けたり、入力を丁寧に整えたりするときに、誤送信がよく起きます。改行したかっただけなのに、メッセージが送られてしまうのです。

有効にすると、次のようになります。

- **Enter** → 改行を入力
- **Ctrl+Enter**（macOS では **⌘+Enter**）→ メッセージを送信

Shift+Enter と IME の変換中は、サイトの既定の動作のままです。また、添付ファイルがまだアップロード中のときは、Ctrl/⌘+Enter による送信を待ちます。

## 有効にする方法

1. Voyager のポップアップを開きます。
2. **入力オプション** で、**Ctrl+Enter で送信**（macOS では **⌘+Enter で送信** と表示されます）をオンにします。

## その他のサイト

- **AI Studio** は逆の仕組みです。**AI Studio で Enter 送信** をオンにすると、`Enter` で送信し、`Ctrl/⌘+Enter` で改行します。
- **Claude、ChatGPT、DeepSeek**: 各サイト用の **Ctrl/Cmd+Enter to send** プラグインを、[マーケットプレイス](/ja/plugins) からインストールしてください。
- **Safari**: Gemini で送信するのに Enter を 2 回押す必要がある場合は、**Safari の Enter キーを修正** をオンにしてください。

## 機能の特徴

- **パフォーマンスへの影響ゼロ**: 無効にしているとき、キーボードのイベントリスナーは動作しないため、ページの性能に影響しません。
- **即時の切り替え**: 設定で切り替えると、すぐに反映されます。ページの再読み込みは不要です。
