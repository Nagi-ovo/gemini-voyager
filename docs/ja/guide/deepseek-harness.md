# DeepSeek Harness

DeepSeek が公開しているオープンソースのコーディングエージェントです。お使いのマシン上で動作します。

`localhost:3080` でウェブインターフェースが提供されます。

ウェブインターフェースがあるので、Voyager から利用できます。

## なぜ動作するのか

Voyager のプロンプトマネージャーは、ドメインを気にしません。気にするのは、ご自身が追加したサイトです。

ローカルアドレスも、ひとつのサイトです。

そのため DeepSeek Harness も、Gemini、Claude、ChatGPT と違いはありません。プロンプトがついてこられる場所が、もうひとつ増えるだけです。

## 3 つのステップ

### 1. DSH を起動する

```bash
npm i -g @deepseek-ai/dsh
dsh web
```

ブラウザで `http://localhost:3080` を開きます。

### 2. ポップアップでスイッチを入れる

![ツールバーのパズルアイコンをクリックし、Voyager をクリックして、localhost:3080 でプロンプトマネージャーを有効にする](/assets/dsh-enable-steps-en.png)

すでに `localhost:3080` を開いているので、ポップアップの一番上にその項目が表示されます。オンにして、アクセスを許可してください。

アドレスを入力する必要はありません。

### 3. ページを再読み込みする

右下にフローティングボタンが表示されます。

![DeepSeek Harness 内で動作するプロンプトマネージャー](/assets/prompt-manager-deepseek-harness.png)

## どこでも同じライブラリ

サイトごとにライブラリが分かれるわけではありません。どこにでもついてくる、ひとつのライブラリです。

Gemini、Claude、ChatGPT で保存したプロンプトは、DSH を開けば、すべてそこにあります。逆も同じです。DSH の中で書いたプロンプトは、Gemini に戻ったときにも使えます。

タグも、お気に入りも、検索も、すべて同じです。

![どのインターフェースにも届く、ひとつのライブラリ](/assets/one-prompt-library.png)

## いくつかの注意点

**ポート番号は固定ではありません。** DSH はまだ開発者向けプレビューの段階で、既定のポート番号は変わる可能性があります。変わった場合は、新しいアドレスを追加し直してください。

**読み込まれるのはプロンプトマネージャーだけです。** DSH のようなカスタムサイトでは、タイムラインやフォルダなどは起動しません。（DeepSeek 公式のウェブサイトでは、その多くが公式プラグインとして利用できます。）

**プロンプトがマシンの外に出ることはありません。** DSH はローカルで動き、Voyager のライブラリもローカルにあります。その経路のどこからも、外部には送られません。

::: tip
同じ方法は、どのローカルのウェブ UI にも使えます。Open WebUI、LibreChat、ご自身で作ったものでも同じです。アドレスを追加して、再読み込みすれば完了です。
:::
