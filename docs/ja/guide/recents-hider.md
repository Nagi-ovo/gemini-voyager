# 最近の項目と Gems を非表示（廃止）

::: info 廃止された機能
Voyager はもうこれらのセクションを非表示にしません。「最近の項目」のトグルは誤って押しやすく、元に戻しにくかったため、2026 年 5 月に削除しました。それ以前に非表示にしたものは、自動的に再び表示されます。Gemini の 2026 年のリデザインでは、サイドバーの Gems セクションが単一の Gems リンクに置き換えられたため、Gems のトグルは古いレイアウトでのみ表示されます。
:::

既存のブックマークやリンクが引き続き機能するように、このページは残しています。
