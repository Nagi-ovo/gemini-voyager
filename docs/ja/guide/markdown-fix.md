# Markdown レンダリングの修正

Gemini™ のウェブインターフェースでは、テキスト内に HTML 要素（引用元やハイライトマーカーなど）が挿入されることがあり、これにより Markdown の太字構文（`**text**`）が壊れ、テキストが正しく太字で表示されない場合があります。

Voyager には自動修正機能が組み込まれており、これらの壊れた太字タグをインテリジェントに識別して修復し、ドキュメントが綺麗かつ正確に表示されるようにします。

> [!NOTE]
> Voyager に含まれる公式プラグインで、標準でオンになっています。ブラウザのツールバーにある拡張機能アイコンをクリックし、ポップアップの **回答の表示** → **Markdown 表示の修正** で切り替えられます。オフにすると新しい内容は修正されなくなりますが、画面上の修正済みの内容はそのまま残ります。Gemini 本来の表示に戻すには、ページを再読み込みしてください。再びオンにすると、現在のページの書式が修正されます。

無効にしてもエクスポートや会話の分岐は利用できますが、エクスポートしたファイルに Markdown 記号がそのまま表示されるなど、Gemini の書式の問題が残る場合があります。
