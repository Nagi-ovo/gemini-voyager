# Activity：動いている会話に注意を向ける

フォルダは「この会話はどこに属するか」に答えます。アーカイブが大きくなるほど、「今、何を見るべきか」という別の問いが増えていきます。

Activity は、フォルダの上に重ねる時間ベースのビューです。**Folders** の横にあるベルをクリックすると、フォルダのツリーが、実際のチャットの動きに基づいて並んだ会話の一覧に切り替わります。フォルダ、会話の割り当て、スターの状態は変わりません。

**デザインの着想：** このビューは、OpenAI の Codex / ChatGPT Desktop のサイドバーに着想を得ています。Voyager は、まだ動いている会話を表に出すという考え方を取り入れ、Gemini のフォルダ上の時間ベースのビューとして作り直しました。

## 優先は、最近の動きに従う

**優先（Priority）** には、直近 **3 時間** に新しいターンがあった会話が入ります。使われるのは、実際のチャットの時刻です。チャットを開いたり閲覧したりした時刻ではありません。

優先に入っている会話は、今日の欄には重ねて表示されません。3 時間の活動期間が終わると、Activity が自動的にその会話を今日、または該当する日付のグループに戻します。ページを再読み込みする必要はありません。

スターは、独立した手動のマーカーとして引き続き使えます。会話にスターを付けても優先には移動せず、スターを外しても、動いている会話が優先から外れることはありません。

## 直近数日に絞った表示

優先の下には、今日、昨日、そして前日までの曜日の見出しが表示されます。このビューが扱うのは、今日と直前の 4 日分の暦日です。一覧を現在の作業の近くに保ちます。

それより古い会話や、活動時刻のない旧データは、ここには表示されません。非表示にされたり削除されたりしているわけではありません。ベルをもう一度クリックするとフォルダのツリーに戻り、元の場所から見つけられます。

## 1 つの会話は 1 行にまとめる

1 つの会話が、複数のフォルダに属することがあります。Activity はそれらの参照を 1 行にまとめ、タイトルの下にフォルダ名を残します。フォルダの情報にカーソルを合わせると、完全なパスが表示されます。

これにより、1 つの会話が優先や今日の欄を何枠も占めることを防ぎつつ、そのプロジェクトの文脈は残ります。

## 役割の異なる 3 つの情報

| 情報     | 元になるもの                         | 答える問い                       |
| -------- | ------------------------------------ | -------------------------------- |
| フォルダ | ご自身が整理するプロジェクトやテーマ | この会話はどこに属するか？       |
| Activity | 最新の実際のチャットのターン         | 最近、どの作業が動いているか？   |
| スター   | 手動のマーカー                       | どの会話に印を付けておくべきか？ |

アーカイブから何かを探し出す必要があるときは、フォルダが役立ちます。Activity は、Gemini に戻るたびに選ぶ候補の数を絞ります。優先に入っている、まだ勢いのある会話から始め、次に今日や昨日の会話へ進みます。古い資料が必要になったら、フォルダのツリー全体に戻ってください。

## 対応している場所

Activity は、Gemini のフォルダサイドバーと、ChatGPT のフォルダ欄（ChatGPT に組み込まれたフォルダのプラグインの一部）で利用できます。
