# 思うがままに

デフォルトも優れていますが、私たちは完璧を求めます。
あなたの環境は、あなた好みに整えましょう。

## シネマモード

ドアの隙間から世界を覗く必要はありません。
チャットボックスを広げましょう。

- **チャットの幅**: まずポップアップで **プラグイン** → **チャットの幅** をオンにします。デフォルトはオフで、オンにすると行の下にスライダーが表示されます。オンにすると、ウィンドウの 30%〜100% をスライダーで調整できます（デフォルトは 70%）。コードや大きな表には広く、読書に没頭するなら狭く。
- **入力欄の幅**: こちらも先に **プラグイン** → **入力欄の幅** をオンにすると、送信済みメッセージを編集するときの入力欄を広げられます。

## コントロール

拡張機能のアイコンをクリックして、コントロールパネルへ。

- **スクロール**: **プラグイン** → **タイムラインを表示** → **オプション** で選べます。`フロー` でメッセージまで滑らかに、`ジャンプ` で一瞬で。
- **配置**: タイムラインは右利き用？ 左利き用？ **プラグイン** → **タイムラインを表示** → **オプション** で **ドラッグ可能なタイムライン** をオンにして、使いやすい場所に。**タイムラインの位置をリセット** で元に戻せます。
- **ビジュアルエフェクト**: Gemini と AI Studio では、**プラグイン** → **視覚効果** をオンにして、その行の下で `雪`、`桜`、`雨` から選びます。オフにするとエフェクトも止まります。ほかのサイト(Claude、ChatGPT、DeepSeek、カスタムサイト)では、同じ行がそのサイトの **プラグイン** カードに表示されます。Voyager がそのサイトで動作している(プロンプトマネージャー、またはそのサイトで有効にしたプラグインがある)場合に表示されます。

## カスタム並び替え

ポップアップの設定項目が多すぎて、よく使うものが下に埋もれていませんか？

設定カードにマウスを合わせると、右上に ▲/▼ ボタンが表示されます。クリックでカードを上下に移動でき、並び順は自動保存されます。

## アトモスフィア

Voyager は効率化だけでなく、ページの気分を変えることもできます。

- **雪**: やわらかな雪の結晶がゆっくり舞い落ちる、穏やかな冬の雰囲気。
- **桜**: 花びらが自然に舞い散る、軽やかな春の雰囲気。
- **雨**: 斜めの雨筋と微かな水しぶきが映画的な臨場感を演出。
- **スムーズな切り替え**: エフェクトをオフにしたり切り替えたりすると、パーティクルは自然に退場。
