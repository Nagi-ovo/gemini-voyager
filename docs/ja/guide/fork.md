# 会話の分岐（実験的）

思考は一方通行であるべきではありません。複雑な探究では、重要なノードに戻って、別の可能性を試したくなることがよくあります。

**会話の分岐** 機能を使うと、Voyager では思考を枝分かれさせ、チャットの並行した世界を探ることができます。

## 仕組み

> **⚠️ 注意**: これは実験的な機能です。まず、ブラウザのツールバーにある拡張機能アイコンをクリックして設定ポップアップを開き、**会話分岐を有効化** のスイッチをオンにしてください。

別の道を進みたいときは、プロンプトにカーソルを合わせ、**Fork** ボタンをクリックするだけです。

![会話の分岐](/assets/branching.png)

Voyager は、会話の最初からその地点までの文脈をすべて取り込み、確認ダイアログを表示します。文脈の長さに応じて選んでください。

- **MD をダウンロード**（ほとんどの会話に推奨）: Gemini の入力欄には長さの制限があるため、長い文脈を直接貼り付けると収まらないことがあります。Voyager は文脈を含む Markdown ファイルをダウンロードし、新しい会話を開きます。右下の 2 分間のカウントダウンが終わる前に、`.md` ファイルを Gemini にドラッグしてください。入力欄には、添付ファイルが前の会話の文脈であることを示す短い注記があらかじめ入り、その後に **New request:** が残るので、次のメッセージを書けます。
- **Fork**（短い会話向け）: 文脈が短い場合は、Voyager が新しい会話を開き、入力欄に直接文脈を入れます。送信すると分岐が作成されます。

送信した後、Voyager が記録するのは分岐の関係だけです。元の会話を削除したり、書き換えたりすることはありません。

この新しい分岐では、元のチャット履歴を壊す心配なく、質問を自由に変えて、別の方向を探れます。創造力と好奇心を解き放ちましょう！
