# Mermaid 図のレンダリング

Mermaid のコードを、自動的に図としてレンダリングします。

## 概要

Gemini™ が Mermaid のコードブロック（フローチャート、シーケンス図、ガントチャートなど）を出力すると、Voyager はそれを自動的に検出し、インタラクティブな図としてレンダリングします。

### 主な機能

- **自動検出**: `graph`、`flowchart`、`sequenceDiagram`、`gantt`、`pie`、`classDiagram` など、主要な Mermaid の図の種類をすべてサポートします。
- **表示の切り替え**: レンダリングされた図と元のソースコードを、ワンクリックで切り替えられます。
- **全画面表示**: 図をクリックすると全画面になり、ズームとパンに対応します。
- **ダークモード**: ページのテーマに自動的に合わせます。

## オンとオフの切り替え

Gemini では、Mermaid のレンダリングは既定でオンです。オフにするには、Voyager のポップアップを開き、**一般オプション** の **Mermaid 図表のレンダリング** をオフにします。AI Studio では利用できません。

## 使い方

1. Gemini に Mermaid の図のコードを生成させます。
2. コードブロックが、レンダリングされた図に自動的に置き換わります。
3. **</> Code** ボタンをクリックすると、ソースコードを表示できます。
4. **📊 Diagram** ボタンをクリックすると、図の表示に戻ります。
5. 図のエリアをクリックすると、全画面になります。

## 全画面での操作

- **スクロールホイール**: ズームイン／ズームアウト
- **ドラッグ**: 図をパン（移動）
- **+/-**: ツールバーのズームボタン
- **⊙**: 表示のリセット
- **✕ / ESC**: 全画面を閉じる

## 互換性とトラブルシューティング

::: warning 注意

- **Firefox の制限**: 環境の制約により、Firefox には Mermaid 9.2.2 が同梱されており、**Timeline** や **Sankey** などの新機能には対応していません。
- **構文エラー**: レンダリングが失敗するのは、多くの場合、Gemini の出力に構文エラーがあるためです。今後のアップデートで一般的な生成エラーを自動修正するパッチを用意するため、現在「不具合の事例」を収集しています。
  :::
