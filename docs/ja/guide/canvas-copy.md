# CanvasをMarkdownとしてコピー

VoyagerはGemini Canvasの共有メニューに **Markdown としてコピー** を追加します。ドキュメントをクリップボードにコピーして、メモやMarkdownエディターに貼り付けられます。

この機能は既定でオンになっており、設定は不要です。

## 使い方

1. Gemini Canvasでテキストドキュメントを開きます。
2. Canvasの共有メニューを開き、**Markdown としてコピー** をクリックします。
3. 必要な場所に貼り付けます。

コピーされるのは現在のCanvasドキュメントです。会話全体を保存するには、[会話のエクスポート](/ja/guide/export)を使ってください。
