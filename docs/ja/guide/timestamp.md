# メッセージタイムスタンプ

::: info
**注意**: この機能はバージョン 1.3.7 以降でサポートされています。
:::

Voyager は各メッセージの送信時刻を表示し、会話の全体的な流れを振り返るのに役立ちます。

## 機能紹介

会話が長くなると、特定の議論がいつ行われたか思い出すのが難しくなります。

Voyager は各メッセージの上に正確なタイムスタンプ（形式：`YYYY-MM-DD HH:mm:ss`）を表示し、タイムラインのドットにホバーしたときにも同じ時刻を表示します。

## 有効にする方法

1. Voyager の設定パネルを開きます(ブラウザのツールバーにある拡張機能アイコン)。
2. **タイムラインオプション** で **メッセージのタイムスタンプを表示** をオンにします(**実験的** 機能、デフォルトはオフ)。

## 時刻の取得元

- **Gemini**：Voyager は Gemini 自身の会話データから各メッセージの実際の送信時刻を読み取るため、別のデバイスで行った会話や Voyager をインストールする前の会話でも正しい時刻が表示されます。その時刻が取得できない場合に限り、Voyager がそのメッセージを最初に検出した時刻(ブラウザ内にローカル保存)にフォールバックします。
- **ChatGPT**：設定がオンの間に送信した各メッセージの時刻を Voyager が記録し、ブラウザ内にローカル保存します。それ以前に送信したメッセージや、別のデバイスから送信したメッセージにはタイムスタンプがありません。

## 機能の特徴

- **秒単位の精度**：完全な日付と時刻で、長い会話のレビューに最適です。
- **ゼロ干渉**：時間情報は控えめに表示され、読書体験に影響を与えません。

## 利用シーン

- **作業記録**：特定の決定がいつ行われたかを振り返る。
- **学習ノート**：概念がいつ議論されたかを記録し、後の復習に役立てる。
- **長い会話のレビュー**：複数日にわたる深い会話で、異なる時間帯の議論を明確に区別する。

## プラットフォーム

**Google Gemini**(`gemini.google.com`)と **ChatGPT**(`chatgpt.com`)。Claude と DeepSeek では利用できません。
