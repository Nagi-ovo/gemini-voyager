# 自動スクロールの防止

過去の会話を読んでいるときに Enter で新しいプロンプトを送ると、Gemini™ は新しく生成された回答を追うために、ページを一番下まで強制的にスクロールします。これは読書の妨げになります。

**自動スクロール防止** の機能は、この望ましくないジャンプを止めます。

- 履歴を読むために上へスクロールしている間は、ページが下へ戻されるのをブロックします。
- チャットを開いた直後や切り替えた直後には、Gemini が最新のメッセージへ移動することがあります。その後、チャットの中で読んでいる間は、この防止が適用されます。
- この機能は既定で **無効** です。ポップアップの **タイムラインオプション** から、手動で有効にできます。

## 有効にする方法

1. ブラウザのツールバーにある Voyager の拡張機能アイコンをクリックして、ポップアップを開きます。
2. **タイムラインオプション** のセクションを見つけます。
3. **自動スクロール防止** のスイッチをオンにします。
