# 自動スクロール防止

過去の会話を読んでいるときに新しいプロンプトを送信すると、Gemini™ は新しく生成された回答を追跡するためにページを一番下まで強制的にスクロールします。これにより読書体験が妨げられる可能性があります。

**自動スクロール防止** 機能は、この迷惑なジャンプ動作を阻止します。

- 履歴を読むために上にスクロールしている間、システムはページが一番下にジャンプするのをブロックします。
- チャットを開いた直後や切り替えた直後は、Gemini が最新のメッセージへジャンプすることがあります。防止が働くのは、チャット内で読んでいる間です。
- この機能はデフォルトで**無効**になっています。ポップアップの **プラグイン** → **自動スクロール防止** から手動で有効にできます。

## 有効にする方法

1. ブラウザのツールバーにある Voyager 拡張機能アイコンをクリックしてポップアップを開きます。
2. **プラグイン** カードを見つけます。
3. **自動スクロール防止** スイッチをオンにします。
