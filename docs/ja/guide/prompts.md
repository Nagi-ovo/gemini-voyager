# あなたの知的資産：プロンプトライブラリ

完璧なプロンプトを作りました。複雑なコードの問題を解いたり、美しいメールを書いたりできました。
捨てますか？
いいえ、保存しましょう。

## プロンプトの金庫

ここは、あなたの優れた発想を収めておく個人用の保管庫です。

### 1. 保存する

優れたプロンプトを書けたら、Voyager のフローティングボタンをクリックして **プロンプトマネージャー** を開きます。フローティングボタンは既定で入力欄の近くにあり、好きな場所にドラッグできます。
そのプロンプトは、この金庫の一部になります。

### 2. 分類する

`coding`、`email`、`research` などのタグを追加します（カンマで区切ります）。
道具は、研ぎ澄まして整理しておきましょう。

### 3. 呼び出す

次に必要になったとき、もう一度入力し直す必要はありません。
マネージャーを開き、タグやキーワードで検索して、クリックして挿入します。
ワンクリックで、何倍もの効果を得られます。

![プロンプトマネージャー](/assets/gemini-prompt-manager.png)

## コンパクトリストとメモ

プロンプトが増えてカード一覧が収まらなくなると、パネルは表示を切り替えます。

### 表示の切り替え

検索バーの右側にある `≡ / ▦` ボタンで、**コンパクトリスト**（既定）と **快適表示** を切り替えます。

- **コンパクトリスト**: 1 行に 1 つのプロンプトを表示し、一度に約 10 件が見えます。右側にタグ、展開、編集、削除のボタンが並びます。
- **快適表示**: Markdown の全文プレビューを表示します。プロンプトの数が少ない場合に向いています。

### 名前は必須

追加・編集フォームの上部にある **名前** 欄で、各プロンプトに短いタイトルを付けます。プロンプトを新規作成・編集するときは、名前が必須です。名前のない既存のプロンプトもそのまま使えますが、次に編集するときに名前を付ける必要があります。

### 素早いホバープレビュー

コンパクトモードでは、任意の行に **約 250 ミリ秒** カーソルを合わせると、フローティングのツールチップに全文が表示されます。ブラウザ標準の `title` ツールチップ（表示まで 1〜3 秒かかることがあります）の代わりになります。

### スラッシュで素早く挿入

チャットの入力欄で `/` を入力し、続けてプロンプト名の一部を入力します。一致する名前とタグが一覧に表示されます。項目にカーソルを合わせると全文をプレビューでき、クリックするか `Tab` / `Enter` で選択できます。エディタには選んだ名前が強調表示されたトークンとして表示され、送信されるのは完全なプロンプト本文です。

## どのサイトでも使える

プロンプトマネージャーは、Gemini™ と AI Studio だけでなく、選んだどのウェブサイトでも使えるようになりました。

### 有効にする方法

Claude、ChatGPT、DeepSeek では、そのサイトを開いた状態で Voyager のポップアップを開き、そのサイトのスイッチをオンにします（例：**Claude でプロンプトマネージャーを有効化**）。アクセス許可を求められたら、許可してください。

それ以外のサイトでは、次の手順で有効にします。

1. ブラウザの拡張機能ツールバーで Voyager のアイコンをクリックします。
2. **Prompt Manager** のセクションまでスクロールします。
3. ウェブサイトの URL を入力します（例：`chatgpt.com` や `claude.ai`）。
4. **ウェブサイトを追加** をクリックし、許可を与えます。
5. フローティングボタンを表示するには、**対象のページを再読み込み** します。

### よく使われる AI サイトの例

- `chatgpt.com` - ChatGPT
- `claude.ai` - Claude
- `copilot.microsoft.com` - Microsoft Copilot
- `poe.com` - Poe

### ローカルのアプリ

ローカルのアドレスも使えます。`localhost:3080` や `127.0.0.1:3080` も、同じように入力してください。たとえば [DeepSeek Harness](/ja/guide/deepseek-harness) は `localhost:3080` で動作します。プロンプトマネージャーは、ほかのホスト型サイトと同じように、そこに組み込まれます。

![DeepSeek Harness で動作するプロンプトマネージャー](/assets/prompt-manager-deepseek-harness.png)

::: tip
ご自身で追加したウェブサイトでは、**プロンプトマネージャーだけ** が有効になります。タイムラインやフォルダなどの機能は読み込まれません。Claude、ChatGPT、DeepSeek は別です。それぞれ専用の公式プラグインがあり、[マーケットプレイス](/ja/plugins) で確認できます。
:::
