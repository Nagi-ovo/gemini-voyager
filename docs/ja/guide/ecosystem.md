# エコシステム

以下のプロジェクトは、Voyager に着想を得たもの、あるいは Voyager を土台にしたものです。他のプラットフォームでも、同様の機能強化を提供しています。

- **[DeepSeek Voyager](https://github.com/Azurboy/deepseek-voyager)** — DeepSeek 向けに移植された Voyager のフォークです。タイムラインのナビゲーションとチャットの管理を、DeepSeek のユーザーにも届けます！
- **[claude-nexus](https://github.com/Qiuner/claude-nexus)** — Voyager に着想を得た Claude.ai 向けの拡張機能です。タイムラインのナビゲーション、フォルダ管理、プロンプトライブラリなどを備え、Voyager のプロンプトのインポートとエクスポートに完全に対応しています！
- **[Better_Doubao](https://github.com/Rex16200513/Better_Doubao)** — 豆包（Doubao）を強化する高機能なブラウザ拡張機能です。ナビゲーション、整理、生産性の機能を向上させます。
- **[DeepSeek Enhancer](https://github.com/dlshuangchenyue1210/DeepSeek-Enhancer)** — Voyager に着想を得た、DeepSeek のウェブアプリ向けの拡張機能です。多階層のフォルダ、チャットのエクスポート、数式コピー、データのバックアップなどを提供します。
