# クラウド同期

Voyager のクラウド同期は、フォルダ、プロンプトライブラリ、スター付きメッセージ、対応している設定をバックアップします。どのブラウザでも Google ドライブを選べ、Safari では iCloud も選べます。データは Voyager と、ご自身が選んだ個人のクラウドアカウントの間で直接やり取りされ、Voyager 側に同期サーバーはありません。

## 同期されるデータ

| データの種類         | 同期   | 詳細                                                                                       |
| -------------------- | ------ | ------------------------------------------------------------------------------------------ |
| フォルダ構造         | はい   | すべてのフォルダ、入れ子構造、色、会話の割り当て                                           |
| プロンプトライブラリ | はい   | タグとフォルダ構成を含む保存済みのすべてのプロンプト                                       |
| スター付きメッセージ | はい   | どの会話からでも付けられるタイムラインのブックマーク                                       |
| 拡張機能の設定       | はい   | 並べ替え、色、入力動作など、デバイス間で共有する環境設定                                   |
| プラグインの設定     | はい   | インストールと有効化の状態、プラグインの設定。サイトごとの権限はデバイスごとに保持されます |
| モデルの回答         | いいえ | スターのバックアップにはユーザーのプロンプトが含まれ、モデルの回答は含まれません           |

## スターのデータと同期の制限

クラウドへのアップロードには、**スターを付けたユーザープロンプトの全文**（1 件あたり UTF-8 で最大 16 KiB）が、ご自身の Google ドライブまたは iCloud に保存されます。スターのバックアップにモデルの回答は保存されません。従来の v1 バックアップはプレビューのみ、新しい v2 バックアップはプロンプト本文と削除記録を含みます。

削除記録は 180 日間保持されます。古い Voyager は削除記録を認識しないため、削除済みのスターを再表示したり再アップロードしたりすることがあります。新しいバージョンは、タイムスタンプが変わっていない古いコピーを無視します。より新しい時刻で改めてスターを付けた場合や、削除記録の期限が切れた場合は、スターが復元されることがあります。長期間オフラインだった場合やデバイス間で時計がずれている場合も、削除の反映に影響します。

同期は書き込みを照合して検証し、最大 3 回まで試行します。ただし、デバイス間で原子性のあるトランザクションではないため、同時にアップロードすると別のデバイスの書き込みを上書きすることがあります。欠けているデータを保持しているデバイスが後から同期すれば修復できますが、そのデバイスが二度と同期しなければ復旧は保証されません。アップロードの一部が失敗した場合、成功した書き込みは残ります。もう一度同期して修復を完了してください。

## 主な機能

- **マルチデバイス同期**: 複数のコンピュータで設定を同期できます。
- **データのプライバシー**: データは Voyager のサーバーを介さず、ご自身の Google ドライブまたは非公開の iCloud データベースに保存されます。
- **柔軟な同期**: 手動でのアップロード、およびデータのダウンロードとマージに対応しています。

::: info
デバイス識別子、アクセストークン、キャッシュ、ビューポートの座標、一時的な実行状態は、個人設定として意図的に同期されません。
:::

## 使い方

1. ブラウザのツールバーにある Voyager のアイコンをクリックして、ポップアップを開きます。
2. **クラウド同期**セクションを探します。
3. Safari では **Google ドライブ**または **iCloud** を選びます。ほかのブラウザでは Google ドライブを使います。
4. Google ドライブの場合は **Google でサインイン**をクリックし、認証を完了します。iCloud の場合は、Mac が iCloud にサインインしていることを確認します。
5. **ドライブへ保存**をクリックしてローカルのデータをクラウドに送るか、**ドライブからマージ**をクリックしてクラウドのデータをこのブラウザに取り込みます。**上書き**は、マージせずにローカルのデータをクラウドのコピーで置き換えます。そのため、まだアップロードしていない内容は失われます。

iCloud を使っている場合、**iCloud バックアップを削除**は iCloud 上のすべての Voyager バックアップを削除します。Mac 上のローカルデータはそのまま残ります。

### 💡 クイック同期

最も手早い方法は、左側のサイドバーにあるフォルダエリアの上部の **クラウドにアップロード**と**クラウドから同期**ボタンを使うことです。

::: warning
**安全上の推奨事項：二重の保護**
クラウド同期は非常に便利ですが、定期的にコアデータを**ローカルファイル**にもバックアップすることを強くおすすめします。

1. **フォルダ**: フォルダエリアのメニューを開き、**フォルダのインポート/エクスポート**を選んでから、**フォルダをエクスポート**をクリックすると、すべてのフォルダと会話の割り当てを保存できます。
2. **プロンプト**: プロンプトマネージャーで **エクスポート**をクリックして、プロンプトライブラリを保存します。
   :::

## クラウド同期と手動バックアップの比較

| 観点             | 手動バックアップ（エクスポート/インポート） | クラウド同期                                               |
| ---------------- | ------------------------------------------- | ---------------------------------------------------------- |
| 頻度             | 思い出したときに行う                        | ワンクリックでいつでも行える                               |
| データの保存先   | ご自身のコンピュータ上のローカルファイル    | ご自身の Google ドライブまたは非公開の iCloud データベース |
| デバイス間の利用 | ファイルの受け渡しが必要                    | 選択したクラウドアカウントにサインインしたデバイス同士     |
| マージの動作     | 置き換えか、手動でのマージが必要            | 重複させずに賢くマージ                                     |
| プライバシー     | ファイルはご自身のマシン上に残る            | ご自身の個人クラウドアカウントに保存                       |

## 仕組み

1. **プロバイダー**: Google ドライブは制限付きの `drive.file` 権限を使うため、Voyager が作成したファイルにしかアクセスできません。Safari の iCloud はアプリ専用の非公開 CloudKit データベースを使い、Apple ID のトークンを Voyager に渡しません。
2. **アップロード**: **ドライブへ保存**をクリックすると、Voyager はフォルダ、プロンプト、スター、分岐、タイムラインの階層、個人設定、プラグインの設定を、それぞれ別のバックアップファイルとして選択したプロバイダーに書き込みます。ハイライトのクラウド同期が有効な場合は、ハイライトのデータも含まれます。
3. **ダウンロードとマージ**: 別のデバイスで **ドライブからマージ**をクリックすると、Voyager はそれらのファイルを読み込み、データの種類ごとにマージします。新しいフォルダとプロンプトは重複せずに追加され、クラウドの環境設定が復元され、プラグインのエントリはプラグイン ID ごとにマージされます。
4. **バックグラウンドでの同期はありません**: 同期は手動で、必要なときだけ行われます。Voyager がご自身の明示的な操作なしに同期することはありません。

プロバイダーを切り替えても、データが両方のプロバイダー間でコピーされることはなく、両方に書き込まれることもありません。切り替えたあとに現在のローカルデータを新しいプロバイダーにも保存したい場合は、一度アップロードしてください。

## 対応プラットフォーム

Google ドライブの同期は Chrome、Edge、Firefox、Safari で利用できます。iCloud の同期は、直接配布される Safari アプリでのみ利用でき、Mac にサインインしている iCloud アカウントを使います。
