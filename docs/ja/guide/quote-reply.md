# 引用返信

Voyager の「引用返信」機能を使うと、特定の内容への返信を、より正確かつ効率的に行えます。

## はじめに

日々の会話では、AI の出力の特定の部分に続けて質問したり、反論したりしたい場面がよくあります。従来の方法では、その部分をコピーして、入力欄に `> ` の記号を手で入力する必要があり、面倒でした。

Voyager なら、この手順を簡単にできます。

1. **選択して引用**: マウスで、会話ページの任意のテキストを選択します（ご自身の質問でも、Gemini の回答でもかまいません）。
2. **フローティングボタン**: 選択したテキストの近くに、**引用返信** のボタンが自動的に表示されます。
3. **ワンクリックで挿入**: ボタンをクリックすると、選択したテキストが標準的な Markdown の引用形式（`> 内容`）で、入力欄に自動的に挿入されます。

![引用返信](/assets/quote-reply.png)

## 有効にする方法

Gemini では、引用返信は Voyager のポップアップの **一般オプション** にある **引用返信を有効化** で切り替えます。

Claude、ChatGPT、DeepSeek では、そのサイト用の **Quote replies** プラグインを、[マーケットプレイス](/ja/plugins) からインストールしてください。このプラグインを使うと、1 つのアシスタントの回答の中でテキストを選択したときに **Quote** ボタンが表示されます。送信はされず、引用が下書きに追加されます。

## 特徴

- **文脈を認識**: 会話の内容を賢く認識するため、入力欄そのものなど、関係のない場所で誤って動作することはありません。
- **標準の形式**: 一般的な Markdown の構文を使うので、Gemini が正確に理解でき、より的確な回答が得られます。
- **複数行に対応**: 複数行のテキストを選択すると、Voyager が各行に引用記号を自動的に付け、形式をきれいに保ちます。

## ヒント

- **詳細を掘り下げる**: Gemini の回答の中で分かりにくい概念を選択して引用し、「この概念を詳しく説明してください」と入力します。
- **誤りを正す**: 回答の中の誤ったコードや事実を選択して引用し、「これは誤りです。正しくは…です」と指摘します。
