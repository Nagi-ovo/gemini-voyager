# 一括削除

Gemini と AI Studio で複数の会話を一度に削除し、一つずつ消す面倒な作業に別れを告げましょう。

## 機能紹介

- **複数選択モード**：任意の会話を長押しすると複数選択モードに入り、削除したい会話を複数チェックできます。
- **一括削除**：選択後、削除ボタンをクリックするだけで、選択した会話をまとめて削除できます。
- **進捗表示**：削除中は進捗が表示され、現在の状態を確認できます。
- **安全確認**：削除前には削除ボタンの横に確認カードが表示され、誤操作を防ぎます。

## 使い方

デフォルトでオンです。**会話の管理** → **一括削除** で切り替えられます（Gemini と AI Studio で共通）。フォルダが必要なため、**フォルダオプション** → **フォルダ機能を有効化** がオフの間はこの項目がグレーアウトされます。先にフォルダ機能をオンにしてください。

### Gemini

1. サイドバーの会話リストで、任意の会話項目を **長押し** します。
2. 複数選択モードに入ると、会話項目の左側にチェックボックスが表示されます。
3. 削除したい会話にチェックを入れます（一度に最大50件まで選択可能）。
4. 出現した **削除ボタン** をクリックします。
5. 削除ボタンの横に表示される確認カードで「削除」をクリックすると、一括削除が開始されます。

### AI Studio

1. AI Studio の **Library** ページを開きます。
2. 任意の prompt 行を **長押し** して複数選択モードに入ります。
3. 削除したい prompt を選択します（一度に最大50件まで）。
4. フローティング表示された **削除ボタン** をクリックし、横に表示される確認カードで「削除」をクリックします。AI Studio 自体の削除ダイアログは Voyager が自動で確定します。

::: tip ヒント
一括削除操作は取り消せませんので、慎重に操作してください。
:::
