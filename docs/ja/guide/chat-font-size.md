# フォントサイズ

Gemini のチャットエリアのフォントサイズを自由に調整し、最も快適な読書体験を実現できます。

## はじめに

フォントサイズの好みは人によって違います。情報を詰め込みたい人はコンパクトな文字を好み、目の疲れを減らしたい人は大きな文字を好みます。Voyager では、チャットのフォントサイズを 80% から 150% の間で調整できます。

## 機能の特徴

- **柔軟な範囲**: 80%〜150% のフォントサイズ調整に対応し、ほとんどの読書のニーズに応えます。
- **広い適用範囲**: ユーザーのメッセージとモデルの回答の両方に適用されます。本文、リスト、表、コードブロックも対象です。
- **コードブロックの最適化**: コードブロックのフォントサイズは、本文のフォントサイズに比例して自動的に調整されます（本文フォント × 0.875）。コードと本文の視覚的な階層が保たれます。
- **即時の反映**: 変更はすぐに反映され、ページの再読み込みは不要です。

## 使い方

1. Voyager の設定パネル（ポップアップ）を開きます。
2. **チャットのフォントサイズ** を見つけて、オンにします。
3. スライダーをドラッグして、フォントサイズの割合を調整します。変更はページ上でリアルタイムにプレビューされます。
