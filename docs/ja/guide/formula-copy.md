# 数式コピー

Voyager を使うと、数式や科学記号を簡単に再利用できます。数式をクリックすると、LaTeX、Word に貼り付け可能な MathML、または Notion で使いやすいブロックとしてコピーできます。

## はじめに

Gemini に数式の導出や数学的な表現を依頼すると、通常は LaTeX を使ってレンダリングされます。見た目は美しいのですが、そのソースを自分の論文、ドキュメント、エディタで使うには、手作業で取り出す必要があることがよくあります。

Voyager はこれを次のように支援します。

1. **自動検出**: Voyager は、ページ上でレンダリングされた数式を自動的に認識します。数式にカーソルを合わせると、クリックできることが分かります。
2. **クリックでコピー**: インラインまたはブロックの数式をクリックすると、すぐにコピーされ、短い確認が表示されます。
3. **形式を選ぶ**: ポップアップで、事前に **数式コピー形式** を選びます。
   - **LaTeX**: ドル記号の区切りを含む標準の LaTeX ソースです。Overleaf や Markdown エディタなどに適しています。
   - **LaTeX (ドル記号なし)**: 区切り記号を自分で付けるエディタ向けの、素の LaTeX ソースです。
   - **MathML (Word)**: **Microsoft Word** に直接貼り付けるのに最適な形式です。
   - **Notion ($$ 形式)**: すべての数式を `$$` で囲みます。Notion ではこれが数式ブロックになります。

## 特徴

- **Word との互換性**: MathML に対応しているため、AI が生成した複雑な数式を、編集可能な形式を保ったまま Word 文書に直接貼り付けられます。
- **文脈の保持**: 数式そのものだけでなく、その数学的な文脈もコピーします。
- **即座の反応**: すべての処理はローカルで行われるため、すぐに結果が得られます。

## 使いどころ

- **論文の執筆**: Word で論文を書くときは、Gemini に数式を導出してもらい、MathML でコピー＆ペーストします。Word の数式エディタで手入力する手間が省けます。
- **ノートの作成**: Obsidian や Notion でメモを取るときは、LaTeX のソースをそのままコピーできます。

## 利用できる場所

Gemini と AI Studio では、ポップアップの **数式コピーを有効にする** でオンにします。このスイッチとコピー形式は、両方のサイトに適用されます。Claude と ChatGPT は、組み込みのプラグインとして数式コピーに対応しています。DeepSeek には、[プラグインカタログ](/ja/plugins) に数式コピーのプラグインがあります。
