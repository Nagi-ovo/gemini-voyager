# サイドバーの自動非表示

もっと没入感のあるチャット体験をお望みですか？

**サイドバー自動非表示** の機能があります。有効にすると、マウスがサイドバーの領域から離れたときにサイドバーが自動的に折りたたまれ、マウスを戻すと自動的に展開されます。

### 有効にする方法

1. Voyager のポップアップを開きます。
2. **サイドバー自動非表示** をオンにします。**サイドバーの幅** のスライダーのすぐ下にあります。
3. 折りたたまれたバーも隠したい場合は、**サイドバー完全非表示** をオンにします（単独でも使えます）。

_注意: この機能は現在、Google Gemini のみで対応しています。_
