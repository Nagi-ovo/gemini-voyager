# ようこそ、船上へ

おめでとうございます。あなたの知性は、たったいまアップグレードされました。
Voyager は単なるユーティリティではなく、ワークフローそのものです。最初の 5 分で、最大限に活用する方法をご紹介します。

## 1. セットアップ

まだインストールしていない場合は、[インストールガイド](/ja/guide/installation) をご覧ください。
インストールが済んだら、Gemini のタブを再読み込みしてください。違いがすぐに分かるはずです。

Claude、ChatGPT、DeepSeek も使っていますか？ Voyager のポップアップを開き、**プラグイン** に進んで、そのサイトで使いたいプラグインをオンにしてください。初回はブラウザがサイトへのアクセス許可を求めます。何も表示されない場合は、タブを再読み込みしてください。すべてのプラグインは [プラグインカタログ](/ja/plugins) で確認できます。

## 2. タイムライン

会話を始めましょう。少し長めの会話がおすすめです。たとえば、タイポグラフィの歴史や、ブラックホールの物理について尋ねてみてください。
右側を見てください。
**あの点の列が、あなたの地図です。**

- **ホバー**: 自分が送った内容を、のぞき見できます。
- **クリック**: その場所へ瞬時に移動できます。
- **長押し**（約 0.5 秒）: 残しておきたい瞬間に **スター** を付けます。脳の栞のようなものです。

もう延々とスクロールする必要はありません。思考と同じ速さで移動できます。

## 3. 整理

左側のチャット一覧を見てください。新しいものに気づきましたか？
**フォルダ** です。

チャットをつかみ、ドラッグして、フォルダにドロップします。
自然な操作だと感じるはずです。実際そのように設計されています。フォルダは入れ子にでき、名前も変えられます。ごちゃごちゃした状態から、ようやく解放されるでしょう。

## 4. プロンプトの金庫

優れたプロンプトを書き上げたところです。それを消えるままにしてはいけません。
入力欄の横にある Voyager のフローティングボタン（好きな場所にドラッグできます）をクリックして、プロンプトマネージャーを開きます。
プロンプトを保存して、タグを付けましょう。

次に使いたいときは、ボタンをクリックして、探して、挿入するだけです。
もはや、ただチャットをするだけではありません。あなた自身の知性の金庫を築いているのです。
