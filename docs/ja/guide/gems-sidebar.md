# サイドバーの最近の Gems

::: info 現在利用できません
Geminiの新しいサイドバーではGemsが「その他」メニューに移動し、Gemsの項目がなくなりました。そのため、この機能は現在表示されず、Voyagerポップアップのスイッチもグレー表示で無効になっています。
:::

Gemini 2026 のリデザインでは Gems が一度「設定 → Gems」に移され、その後サイドバーの上部にこっそりエントリが戻りましたが、それはただのリンクで、押すと `/gems/view` のフルページに飛ばされるだけです。

Voyager はそのネイティブの Gems エントリを「展開」させて、gems のリストをサイドバー内に直接表示します。ピン留めした gems が先頭に、その後に最近使った gems が並びます。

## 見た目

- **ネイティブ Gems エントリの下にぶら下がります。** Gemini 自身の「Gems」ラベルと揃うようにインデントされ、貼り付けたパネルではなく、そのエントリのサブリストとして読めます。
- **シェブロンで開閉。** Gems エントリの右側に小さな `›` ボタンがあり、開くと `⌄` に回転します。クリックで展開/折りたたみ。状態はローカルに保存され、タブをまたいで同期されます。
- **最近使ったものが先頭に。** 自分の gem でも Google 製の gem でも、開いた gem がリストの先頭に移動します。
- **ピン留めした gems は動きません。** ピン留めした gems は常にピン留めした順で先頭に並び、スライダーの上限にも数えられません。
- **ネットワーク負荷ゼロ。** すべては、あなたが開いたページで Voyager が見た内容から作られます。API 呼び出しもポーリングもバックグラウンド取得もありません。

## 使い方

1. Voyager ポップアップを開きます(ツールバーの拡張機能アイコン)。
2. **プラグイン** → **サイドバーに最近使った Gem を表示** がオンになっていることを確認します（デフォルトでオン）。オンの間は、行の下に件数スライダーが表示され、デフォルトでは 3 件表示されます。
3. 表示したい数(1–10)までドラッグします。**`0` は最近の Gems リストを非表示にするだけ**で、機能自体はオフになりません。機能をオフにするには、行のスイッチをオフにしてください。

自分の gem をピン留めするには、`gemini.google.com/gems/view` を開き、その行のピンボタン（**Pin to sidebar**）をクリックします。もう一度クリックすると解除されます。

::: tip 初回セットアップ
リストは使うほどに埋まっていきます — gem を開けば、そこに現れます。最近開いていない gems も表示したいなら、一度 `gemini.google.com/gems/view` を訪れてください — Voyager が静かにあなたの gems リストをスナップショットします。
:::

## リストが更新されるタイミング

- **gem を開く**（`/gem/<id>`）と、その gem が「使ったばかり」として記録されます。
- **`/gems/view` を訪問する**とスナップショットが更新されます。そこで並べ替える、名前を変える、作成する、削除する — どれもすぐに同期されます。
- それ以外のページからは何も読み取りません。

つまり、別のデバイスから gem を追加した場合、Voyager は「魔法のように」それを知ることはありません。このマシンでその gem か `/gems/view` を一度開けば反映されます。

## プライバシー

- gems リストのスナップショットと最近使った履歴は**ローカルブラウザストレージ** (`chrome.storage.local`) に留まります。
- スライダーの値とピン留めした gem の ID は、ほかの Voyager の設定と一緒に**ブラウザの同期ストレージ**に保存され、同じブラウザプロファイルでサインインしたデバイス間で引き継がれます。名前やアイコンは同期されません。
- gem の会話内容は読み取らずキャッシュもしません — 名前、説明、リンク、アバター用の頭文字だけです。
- 機能を無効化(数 = 0)してもローカルデータはそのまま残るので、再有効化は即座に反映されます。

## プラットフォーム

Gemini のみ(`gemini.google.com`)。AI Studio の gem エントリは形が異なり、対象外です。
