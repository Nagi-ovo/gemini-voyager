# サイドバーの最近の Gems

Gemini の 2026 年のリデザインでは、まず Gems が設定メニューの裏に移されました。その後、サイドバーにナビゲーションの項目が静かに戻りましたが、それは `/gems/view` へ移動するだけのリンクです。

Voyager を使うと、そのネイティブの Gems の項目をサイドバーの中で「展開」し、gem の一覧として表示できます。ピン留めした gem が先頭に来て、続けて最近よく使った gem が並びます。

## 表示の仕組み

- **ネイティブの Gems 項目にぶら下がります。** Gemini 自身の「Gems」ラベルに合わせてインデントされるため、後から貼り付けたパネルではなく、その項目のサブリストに見えます。
- **シェブロンで開閉。** Gems の項目の右側にある小さな `›` ボタンは、開くと `⌄` に回転します。クリックすると、折りたたみと展開が切り替わります。この状態はローカルに保存され、タブをまたいで同期されます。
- **最近使った順に表示。** 自分の gem でも Google が用意した gem でも、開いたものは一覧の先頭に移動します。
- **ピン留めした gem は固定。** ピン留めした gem は、ピン留めした順番で常に先頭に来ます。また、スライダーの上限にも数えられません。
- **ネットワーク通信はゼロ。** すべての情報は、開いたページで Voyager が見た内容から得られます。API 呼び出しもポーリングもバックグラウンドでの取得もありません。

## 使い方

1. Voyager のポップアップを開きます（ツールバーの拡張機能アイコン）。
2. **サイドバーの最近の Gems** のスライダーを見つけます。既定では 3 件の gem が表示されます。
3. 表示したい件数（1〜10）までドラッグします。**`0` にするとセクション全体が非表示になります**。この機能が不要な場合は、0 に設定してください。

自分の gem をピン留めするには、`gemini.google.com/gems/view` を開き、その行のピンボタン（**サイドバーにピン留め**）をクリックします。もう一度クリックすると、ピン留めを解除できます。

::: tip 初回の設定
一覧は使いながら少しずつ埋まっていきます。gem を開くと、そこに表示されます。最近開いていない gem も表示したい場合は、一度 `gemini.google.com/gems/view` を開いてください。Voyager がそこで gem の一覧を静かに保存します。
:::

## 一覧が更新されるタイミング

- **gem を開く**（`/gem/<id>`）と、その gem は最近使われたものとして記録されます。
- **`/gems/view` を開く**と、gem の一覧の保存内容が更新されます。そこで並べ替えたり、名前を変えたり、作成したり、削除したりすると、すぐに反映されます。
- ほかのページからは、何も読み取られません。

そのため、別のデバイスで gem を追加しても、Voyager が自動的に気づくことはありません。このマシンで、その gem を開くか、一度 `/gems/view` を開いてください。

## プライバシー

- gem の一覧の保存内容と最近使った履歴は、**ローカルのブラウザストレージ**（`chrome.storage.local`）に残ります。
- スライダーの値とピン留めした gem の ID は、ほかの Voyager の設定と一緒に、**ブラウザの同期ストレージ**に保存されます。そのため、同じブラウザプロファイルでサインインしている別のデバイスでも同じ設定になります。名前とアイコンが同期されることはありません。
- gem の会話の内容は読み取らず、保存もしません。保存するのは、名前、説明、リンク、アバターに使う頭文字だけです。
- 機能を無効にしても（件数を 0 にしても）ローカルのデータはそのまま残るため、再び有効にすると即座に使えます。

## 対応プラットフォーム

Gemini（`gemini.google.com`）のみです。AI Studio の gem の項目は形式が異なるため、対象外です。
