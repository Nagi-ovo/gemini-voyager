# プライバシーポリシー

最終更新日：2026年10月14日

## 概要

Voyager は、対応している AI チャットのワークスペースを整理・拡張するための、ローカルファーストのブラウザ拡張機能です。ユーザーが要求した機能を提供するためにのみ、限られたユーザーデータを処理します。Voyager は、会話、プロンプト、閲覧履歴、画像、アカウント識別子を受け取るバックエンドを運営しておらず、広告やアナリティクスのトラッカーも使用しません。

## 処理されるデータ

利用する機能によって、Voyager は次のデータを処理することがあります。

- **ウェブサイトの内容と個人的なやり取り**: フォルダ、ナビゲーション、エクスポート、プロンプト管理、リサーチ、インターフェース機能に使われる、会話のテキスト、プロンプト、下書き、画像、リンク、その他の対応ページの内容。
- **アカウント識別子**: 対応している Google サービスは、サインイン中のメールアドレスを公開することがあります。Voyager はそれをローカルのアカウント識別子に変換し、異なるアカウントのデータが混ざらないようにします。生のメールアドレスが Voyager に送信されることはありません。
- **閲覧履歴とユーザーの操作**: ナビゲーション、ショートカット、利用状況の表示、応答完了の通知、その他の要求された機能に必要な、対応サイトの URL、会話のルート、限られたページ・操作・ネットワークのイベント。このデータはプロファイリングや広告には使用されません。
- **認証情報**: `drive.file` スコープの OAuth2 トークン。ユーザーが Google ドライブ同期を明示的に有効にした場合にのみ使われます。
- **拡張機能のデータと設定**: フォルダ、プロンプトテンプレート、下書き、スター付きメッセージ、利用状況のスナップショット、プラグインの状態、インターフェースの設定。

このデータは、`chrome.storage.local` にローカルで保存されます。対応している設定については `chrome.storage.sync` に保存されることもあります。ユーザーが後述する転送を明示的に利用しない限り、データはユーザーのデバイスまたはブラウザの同期アカウント内に残ります。

## ユーザーが要求する転送

- **Google ドライブ同期（任意）**: Google ドライブ同期を明示的に有効にした場合、Chrome・Edge・Firefox ではブラウザの Identity API、Safari 直装版ではネイティブ Google Sign-In を使用し、認証情報は macOS キーチェーンに保存されます。どちらも `drive.file` スコープのみを要求し、選択したバックアップデータは端末と**ユーザー自身の Google ドライブ**の間で直接転送されます。OAuth トークンが Voyager のサーバーへ送信されることはありません。
- **Safari の iCloud 同期（任意）**: 選択したバックアップデータは、ネイティブの Safari 拡張機能によって、ユーザーの iCloud アカウント内の非公開 CloudKit データベースへ直接転送されます。Voyager は、ユーザーの Apple ID や iCloud の認証トークンを受け取らず、開発者もその非公開データベースのレコードにはアクセスできません。
- **エクスポートと画像**: ユーザーがエクスポートを要求すると、Voyager は既存のページがホストしている画像元から画像を取得することがあり、生成されたインターフェースの内容を取り込むために一時的なアクセスを要求することもあります。作成されたファイルはユーザーのためのものであり、Voyager のサーバーにはアップロードされません。
- **公開プロジェクトのリソース**: Voyager は、公開リリース、お知らせ、ドキュメントのリソースを要求することがあります。これらのリクエストには、会話やプロンプトの内容は含まれません。
- **プラグインカタログの更新**: プラグインを 1 つ以上有効にしているサイトでは、Voyager がそのサイト用のカタログファイルを HTTPS で取得することがあります（`https://voyager.nagi.fun/catalog/hosts/<サイトのホスト名>.json`、例：`https://voyager.nagi.fun/catalog/hosts/chat.deepseek.com.json`）。取得は該当ページを開いたとき、またはそのページで拡張機能のポップアップを開いたときだけ行われ、前回のチェックからユーザーが選んだ間隔（既定は 6 時間。1 時間・6 時間・24 時間・手動のみから選択）が経過している場合に限られます。Gemini と AI Studio は拡張機能に同梱された公式プラグインだけを使うため、リクエストは一切発生しません。リクエストは通常の GET で、Cookie もアカウント識別子も拡張機能の識別子も送信せず、ページやチャットの内容も送信しません。一般的なウェブリクエストと同様に、サーバーからはリクエスト元の IP アドレスとブラウザのユーザーエージェント、および URL のパスに含まれるサイトのホスト名が見えます。プラグインのあるサイトでは、ポップアップに「プラグインのオンライン更新」スイッチとチェック間隔の選択肢があり、どちらもブラウザの同期ストレージに保存され、設定のバックアップにも含まれます。スイッチをオフにすると、「今すぐプラグインの更新を確認」を押したとき以外は voyager.nagi.fun に接続しません。取得に失敗した場合や、そのサイトのカタログファイルが存在しない場合は、拡張機能に同梱されたプラグインのスナップショットがそのまま使われます。取得されるカタログは CSS と JSON のみで、使用前に検証とサニタイズが行われます。JavaScript をダウンロードすることも実行することもありません。このチェックはお知らせのチェックとは別のもので、専用の設定があります。voyager.nagi.fun は Cloudflare プロキシ配下の静的ホスティングです。Voyager プロジェクトはこれらのリクエストを記録・保存せず、接続メタデータ（IP アドレス、User-Agent）はホスティング事業者がそれぞれのプライバシーポリシーに基づいて扱います。

Voyager はユーザーのデータを販売せず、広告、信用評価、または拡張機能のユーザー向け機能と無関係な目的のために転送することもありません。

## 権限

- **Storage（ストレージ）**: 拡張機能のデータと環境設定をローカルに保存し、対応している場合はブラウザの同期経由でも保存します。Chrome、Edge、Firefox は `unlimitedStorage` も付与されるため、既定のブラウザ容量上限でローカルデータが切り捨てられることはありません。ただし Voyager 自身の容量制限は引き続き適用されます。Safari では、この権限は任意です。
- **Identity（認証）**: ユーザーが明示的に操作した後に、任意の Google ドライブ同期の認証を行います。Safari の iCloud 同期は、このブラウザの権限ではなく Mac のシステムの iCloud アカウントを使います。
- **Scripting（スクリプト注入）**: 対応サイトに、拡張機能に同梱されたスクリプトだけを注入します。リモートの JavaScript や WebAssembly は実行しません。
- **Active tab と宣言的コンテンツ**: ユーザーが開いた対応サイトを特定し、そのサイトに適した操作項目を表示します。宣言的コンテンツは Chrome と Edge でのみ使われます。
- **Alarms（アラーム）**: 公開されている互換性のお知らせを定期的に確認します。
- **通知（任意）**: 応答完了の通知をユーザーがオンにした場合にのみ要求します。
- **ホスト権限**: Gemini、Gemini Enterprise、AI Studio についてはインストール時に付与され、さらにユーザーが要求する Google ドライブと画像の操作に必要な Google のドメインも含まれます。
- **任意のホスト権限**: Claude、ChatGPT、DeepSeek、およびカスタムサイトには、ユーザーがそのサイトで Voyager またはプラグインを有効にし、ブラウザの権限の確認に承認した後にだけアクセスします。生成されたインターフェースの内容を取り込むエクスポートをユーザーが選んだ場合は、`<all_urls>` の権限を一時的に要求することもあります。拒否された場合、その取り込みを除いてエクスポートを続行します。

## 保持とユーザーによる管理

ローカルとブラウザ同期のデータは、ユーザーが削除するか、拡張機能のストレージを消去するか、拡張機能をアンインストールするまで残ります。クラウドのバックアップは、ユーザーがその Google ドライブまたは iCloud アカウントから削除するまで、そのアカウントに残ります。ユーザーは Voyager とブラウザの設定から、任意の機能を無効にしたり、任意のサイトへのアクセスや Google の認可を取り消したりできます。

## Google API の限定的利用

Voyager による Google API から受け取った情報の利用と転送は、限定的利用の要件を含む Chrome ウェブストアのユーザーデータポリシーに従います。

## ポリシーの変更

プライバシーポリシーは随時更新される可能性があります。変更があった場合は、このページに新しいプライバシーポリシーを掲載することで通知します。
