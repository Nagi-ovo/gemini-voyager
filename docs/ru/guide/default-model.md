# Модель по умолчанию

::: info
**Примечание**: эта функция поддерживается начиная с версии 1.1.9.
:::

Назначьте предпочитаемую модель Gemini™ моделью по умолчанию, чтобы не переключать её вручную в каждом новом диалоге.

## Возможности

- **Настройка в интерфейсе**: добавляет кнопку-звезду прямо в стандартное меню выбора модели Gemini.
- **Автоматическое переключение**: при каждом новом диалоге Voyager сам выбирает вашу модель.
- **Уровень размышления тоже**: отметьте звездой пункт **Расширенное мышление**, и новые чаты будут начинаться с ним.
- **Сохранение выбора**: ваш выбор сохраняется и синхронизируется между устройствами.
- **Работа в SPA**: срабатывает при нажатии кнопки «Новый чат», при использовании горячих клавиш или при возврате на главную страницу.

## Как использовать

1. Нажмите на **селектор модели** над полем ввода Gemini.
2. Наведите курсор на нужную модель и нажмите на **значок звезды**.
3. Когда звезда станет **закрашенной**, модель назначена по умолчанию.
4. Расширение теперь будет автоматически выбирать эту модель во всех новых чатах.
5. Чтобы новые чаты начинались и с расширенным мышлением, нажмите на звезду рядом с пунктом **Расширенное мышление** в том же меню.
6. Чтобы отменить выбор, просто снова нажмите на закрашенную звезду.

Чтобы временно приостановить функцию, не теряя выбор, выключите **Автоматически применять модель по умолчанию в новых чатах** во всплывающем окне Voyager.
