# Размер шрифта

Свободно меняйте размер шрифта в области чата Gemini, чтобы читать максимально комфортно.

## Введение

У каждого свои предпочтения по размеру шрифта: кому-то удобнее компактный текст, чтобы поместилось больше информации, а кому-то — крупный, чтобы меньше уставали глаза. Voyager позволяет настроить размер шрифта чата от 80% до 150%.

## Возможности

- **Гибкий диапазон**: регулировка размера шрифта от 80% до 150% покрывает большинство задач чтения.
- **Полное покрытие**: изменение применяется и к сообщениям пользователя, и к ответам модели, включая основной текст, списки, таблицы и блоки кода.
- **Оптимизация блоков кода**: размер шрифта блоков кода автоматически масштабируется пропорционально (шрифт основного текста × 0,875), сохраняя визуальную иерархию между кодом и текстом.
- **Мгновенное действие**: изменения вступают в силу сразу, без обновления страницы.

## Как использовать

1. Откройте панель настроек Voyager (всплывающее окно).
2. Найдите **Размер шрифта чата** и включите его.
3. Перетащите ползунок, чтобы задать процент размера шрифта, — страница покажет изменения в реальном времени.
