# Локальный мост ChatGPT

«ChatGPT · Локальный мост» — официальный плагин Voyager. По умолчанию он выключен.

Когда вы включите его и выполните сопряжение, Voyager откроет локальным программам на этом компьютере набор действий со страницей ChatGPT. Программа говорит, что нужно сделать, а Voyager делает это в собственной вкладке — через тот ChatGPT, в который вы уже вошли в браузере. Для ChatGPT это обычный чат из вашего собственного браузера.

## Что он предлагает

- Открыть разговор: новый или существующий
- Выбрать модель: только в режиме чата; ChatGPT никогда не переключается в режим Work
- Отправить запрос, в том числе с вложениями
- Дождаться ответа и прочитать его
- Прочитать последний ответ в существующем разговоре
- Показать список проектов и создать проект
- Показать, загрузить и удалить файлы проекта (удаление происходит сразу и безвозвратно)
- Сразу заново загрузить данные страниц (данные сайта, по которым Voyager распознаёт страницы ChatGPT), не дожидаясь следующей плановой проверки

## Как он себя ведёт

**Только локально.** Мост общается с программами на этом компьютере только через `127.0.0.1` и только после сопряжения.

**Своя вкладка.** Каждая задача выполняется во вкладке ChatGPT, которую открывает Voyager; по завершении вкладка закрывается.

**По умолчанию одна задача за раз.** Обычно задачи идут одна за другой. Включите **Запускать задачи параллельно** в карточке **Локальный мост** во всплывающем окне и задайте **Задач одновременно** (от 2 до 10, по умолчанию 3): каждая задача работает в своей вкладке, а ввод и нажатия по-прежнему идут по очереди. Для параллельных задач нужен Voyager CLI новее 0.4.0; со старым `voyager serve` задачи по-прежнему идут по одной.

**Вход и проверки — за вами.** Если ChatGPT просит войти или пройти проверку, мост останавливается и сообщает об этом. Он никогда не пытается её обойти.

**Тариф в каждом результате.** В каждом результате указан ваш тариф ChatGPT (`Pro Lite ($100)`, `Pro ($200)`, …) — таким, каким его в последний раз сообщила страница.

**Браузеры.** Проверено в Chrome. Версии Voyager для Edge и Firefox тоже содержат мост; версия для Safari — нет.

## Пример использования: Voyager CLI

[Voyager CLI](https://github.com/voyager-crew/voyager-cli) (npm `@voyager-crew/cli`, команда `voyager`) — эталонный клиент, построенный на этих действиях: спрашивайте ChatGPT из терминала или поручите это своему агенту для программирования.

### Три шага

1. Установите CLI (нужен Node.js 20.3 или новее):

   ```sh
   npm install -g @voyager-crew/cli
   ```

2. Во всплывающем окне Voyager откройте **Плагины**, включите **ChatGPT · Локальный мост** и разрешите доступ к chatgpt.com.
3. Один раз выполните сопряжение:

   ```sh
   voyager pair
   ```

   Введите восьмизначный код, который он выведет, в настройках «Локальный мост» во всплывающем окне.

### Несколько примеров

```sh
voyager ask "Объясни этот стек вызовов" --attach crash.log
voyager ask --chat <link|id> "А граничные случаи?"  # продолжить разговор
voyager read <link|id>                              # сохранить последний ответ из разговора
voyager project upload "Диссертация" ./thesis       # его прочитает любой чат в проекте
voyager ask --project "Диссертация" "Где аргументация слабее всего?"
voyager ask --drive ./paper.pdf "Кратко изложи методы"  # через Google Drive: читает приложение Drive в ChatGPT
voyager ask --repo owner/name "Почему падает CI?"       # репозиторий читает приложение GitHub в ChatGPT
```

Ответ сохраняется в `response.md`; по умолчанию запросы идут в GPT-6 Pro в режиме чата.

Обе опции работают через собственные приложения Google Drive и GitHub в ChatGPT, поэтому сначала подключите их в ChatGPT; они лишь добавляют текст в запрос, и новая версия Voyager для них не нужна. `--drive` загружает файлы через rclone в новую папку внутри `VOYAGER_DRIVE_REMOTE` (например, `gdrive:Voyager`); этот remote должен быть тем же аккаунтом Google, что и приложение Drive в ChatGPT. Лимита 64 MiB, как у `--attach`, здесь нет, а файлы остаются в Drive. `--repo` просит ChatGPT коммитить только в новую ветку `chatgpt/*`, но это просьба, а не ограничение: приложение может писать везде, куда дотягивается его установка GitHub. Если ChatGPT не может добраться до репозитория, voyager останавливается с кодом выхода 3; добавьте репозиторий в [настройках установок GitHub](https://github.com/settings/installations).

Как дожидаться длинных ответов, что значит каждый код выхода и все команды — в [README CLI](https://github.com/voyager-crew/voyager-cli#readme). Инструкции для Claude Code, Codex и других агентов — в [SKILL.md](https://github.com/voyager-crew/voyager-cli/blob/main/skills/voyager/SKILL.md).

## Отказ от ответственности

- Voyager и Voyager CLI — открытые проекты сообщества. Они не связаны с OpenAI и не одобрены ею.
- Мост автоматизирует веб-версию ChatGPT в вашем собственном браузере, где вы вошли в аккаунт. [Условия использования](https://openai.com/policies/terms-of-use/) OpenAI ограничивают извлечение ответов автоматическими или программными средствами, поэтому сами решите, соответствует ли им ваше использование. Любые ограничения, наложенные на ваш аккаунт в результате, — ваш собственный риск.
- Похожие инструменты поступают так же: например, [oracle](https://github.com/steipete/oracle) делает режим браузера экспериментальной функцией, которую нужно включить вручную, и советует тем, кто не хочет рисковать, использовать API. Если вам нужен поддерживаемый способ, используйте OpenAI API.
- Мост предназначен для вашего собственного удобства на вашем компьютере: подключайте только свой аккаунт, не используйте его, чтобы обслуживать других людей, делиться аккаунтом или перепродавать лимиты, и применяйте его только в законных целях.
