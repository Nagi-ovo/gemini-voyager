# Поведение отправки

::: info
**Примечание**: Эта функция доступна в версии 1.3.7 и выше.
:::

Измените сочетание клавиш для отправки на `Ctrl+Enter` (`⌘+Enter` на macOS), превратив `Enter` в клавишу переноса строки для спокойного написания многострочных промптов.

## Зачем эта функция

По умолчанию нажатие `Enter` немедленно отправляет сообщение. При написании длинных промптов, вставке многострочного кода или аккуратном форматировании ввода это часто приводит к случайной отправке — вы хотели только новую строку, но сообщение уже улетело.

При включении:

- **Enter** → Вставка новой строки
- **Ctrl+Enter** (macOS: **⌘+Enter**) → Отправка сообщения

Shift+Enter и ввод через IME работают так же, как на самом сайте, а Ctrl/⌘+Enter ждёт, пока вложение ещё загружается.

## Как включить

1. Откройте панель настроек Voyager (всплывающее окно).
2. Включите **Плагины** → **Ctrl/Cmd+Enter для отправки**.

## Другие сайты

- **AI Studio** работает наоборот: включите **Enter для отправки в AI Studio**, чтобы отправлять по `Enter`, а новую строку добавлять через `Ctrl/⌘+Enter`.
- **Claude, ChatGPT и DeepSeek**: установите для нужного сайта плагин **Ctrl/Cmd+Enter для отправки** из [магазина плагинов](/ru/guide/plugins).
- **Safari**: если в Gemini для отправки нужно нажать Enter дважды, включите **Исправить клавишу Enter в Safari**.

## Особенности

- **Нулевая нагрузка на производительность**: При отключении слушатели событий клавиатуры не активны — никакого влияния на производительность страницы.
- **Мгновенное переключение**: Изменения вступают в силу сразу после переключения в настройках, без обновления страницы.
