# Поведение отправки

::: info
**Примечание**: эта функция доступна начиная с версии 1.3.7.
:::

Измените сочетание для отправки на `Ctrl+Enter` (или `⌘+Enter` на macOS), и `Enter` превратится в клавишу новой строки: так удобнее писать многострочные промпты.

## Зачем это нужно

По умолчанию `Enter` сразу отправляет сообщение. Когда вы пишете длинный промпт, вставляете многострочный код или аккуратно форматируете текст, это часто приводит к случайной отправке: вы хотели перенести строку, а сообщение уже ушло.

Когда функция включена:

- **Enter** → новая строка
- **Ctrl+Enter** (на macOS: **⌘+Enter**) → отправка сообщения

Shift+Enter и ввод через IME работают так же, как на самом сайте, а Ctrl/⌘+Enter ждёт, пока вложение ещё загружается.

## Как включить

1. Откройте всплывающее окно Voyager.
2. В разделе **Параметры ввода** включите **Ctrl+Enter для отправки** (на macOS отображается как **⌘+Enter для отправки**).

## Другие сайты

- **AI Studio** работает наоборот: включите **Enter для отправки в AI Studio**, чтобы отправлять по `Enter`, а новую строку добавлять через `Ctrl/⌘+Enter`.
- **Claude, ChatGPT и DeepSeek**: установите для нужного сайта плагин **Ctrl/Cmd+Enter для отправки** из [магазина плагинов](/ru/plugins).
- **Safari**: если в Gemini для отправки нужно нажать Enter дважды, включите **Исправить клавишу Enter в Safari**.

## Особенности

- **Нулевые издержки**: когда функция выключена, слушатели событий клавиатуры не работают и не влияют на производительность страницы.
- **Мгновенное переключение**: изменения действуют сразу после переключения в настройках, обновлять страницу не нужно.
