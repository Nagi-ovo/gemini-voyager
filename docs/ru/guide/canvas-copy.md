# Копирование Canvas в Markdown

Voyager добавляет пункт **Скопировать как Markdown** в меню «Экспорт» в Gemini Canvas. Скопируйте документ в буфер обмена, а затем вставьте его в заметки или редактор Markdown.

Функция включена по умолчанию и не требует настройки. Чтобы отключить её, откройте всплывающее окно Voyager и выключите **Плагины** → **Копирование Canvas в Markdown**.

## Как пользоваться

1. Откройте текстовый документ в Gemini Canvas.
2. Откройте меню «Экспорт» в Canvas и нажмите **Скопировать как Markdown**.
3. Вставьте содержимое туда, где оно нужно.

Копируется открытый документ Canvas. Чтобы сохранить весь разговор, воспользуйтесь [экспортом разговоров](/ru/guide/export).
