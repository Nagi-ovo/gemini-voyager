# Рендеринг диаграмм Mermaid

Автоматически превращает код Mermaid в наглядные диаграммы.

## Обзор

Когда Gemini™ выдаёт блоки кода Mermaid (блок-схемы, диаграммы последовательностей, диаграммы Ганта и т. д.), Voyager автоматически распознаёт их и отрисовывает как интерактивные диаграммы.

### Основные возможности

- **Автораспознавание**: поддерживаются `graph`, `flowchart`, `sequenceDiagram`, `gantt`, `pie`, `classDiagram` и все основные типы диаграмм Mermaid
- **Переключение вида**: переключайтесь между отрисованной диаграммой и исходным кодом одним кликом
- **Полноэкранный режим**: нажмите на диаграмму, чтобы открыть её на весь экран с масштабированием и перетаскиванием
- **Тёмная тема**: автоматически подстраивается под тему страницы

## Включение и выключение

На Gemini рендеринг Mermaid включён по умолчанию. Чтобы выключить его, откройте всплывающее окно Voyager и отключите **Включить рендеринг диаграмм Mermaid** в разделе **Общие настройки**. На AI Studio эта функция недоступна.

## Как использовать

1. Попросите Gemini сгенерировать любой код диаграммы Mermaid
2. Блок кода автоматически заменится отрисованной диаграммой
3. Нажмите кнопку **</> Code** (Код), чтобы увидеть исходный код
4. Нажмите кнопку **📊 Diagram** (Диаграмма), чтобы вернуться к виду диаграммы
5. Нажмите на область диаграммы, чтобы открыть полноэкранный режим

## Управление в полноэкранном режиме

- **Колёсико мыши**: масштабирование
- **Перетаскивание**: перемещение диаграммы
- **+/-**: кнопки масштабирования на панели инструментов
- **⊙**: сброс вида
- **✕ / ESC**: закрыть полноэкранный режим

## Совместимость и устранение неполадок

::: warning Примечание

- **Ограничение Firefox**: из-за ограничений среды Firefox поставляется с Mermaid 9.2.2, который не поддерживает новые возможности, например **Timeline** или **Sankey**.
- **Синтаксические ошибки**: сбои рендеринга часто вызваны синтаксическими ошибками в ответе Gemini. Мы собираем «плохие случаи», чтобы в будущих обновлениях добавить автоматические исправления типичных ошибок генерации.
  :::
