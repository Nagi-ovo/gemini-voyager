# Перенос расширения Safari

::: warning Нужно выполнить один раз вручную
Начиная с **v1.6.0** хост-приложение Safari переименовано из «**Gemini Voyager**» в «**Voyager**». macOS определяет приложения по имени, поэтому если сразу установить новую версию, она останется рядом со старым приложением, что может привести к дублированию расширения или странному поведению. Выполните эту замену один раз — после этого автоматические обновления продолжат работать как обычно.
:::

## Ваши данные в сохранности

Bundle ID приложения не изменился. Ваши папки, библиотека промптов, облачная синхронизация и все настройки сохраняются. Этот шаг заменяет только само приложение и никогда не затрагивает данные.

## Шаги переноса

1. **Полностью закройте Safari** (нажмите `⌘Q` внутри Safari, а не просто закройте окно).
2. Откройте **Finder → Программы** и перетащите старое «**Gemini Voyager.app**» в Корзину.
3. Откройте только что скачанный DMG и перетащите «**Voyager.app**» в **Программы**.
4. Снова откройте Safari → **Настройки → Расширения** и включите «**Voyager Extension**».

## Два действия, которых нужно избегать

- ❌ **Не оставляйте оба приложения.** Если старое «Gemini Voyager.app» останется на месте, два расширения начнут конфликтовать.
- ❌ **Не нажимайте «Удалить» для старого расширения на вкладке «Расширения» Safari.** Эта кнопка ведёт к старому приложению и только всё запутает. Просто перетащите старое приложение в Корзину, как в шаге 2.

## Дальше

Сделав эту замену один раз, в будущих версиях Safari новый «Voyager» будет обновляться через встроенный автообновитель (Sparkle), и вручную менять приложение больше не придётся.
