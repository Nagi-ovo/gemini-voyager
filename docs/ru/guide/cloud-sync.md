# Облачная синхронизация

Voyager Cloud Sync создаёт резервную копию ваших папок, библиотеки промптов, избранных сообщений и поддерживаемых настроек. В любом поддерживаемом браузере можно выбрать Google Диск, а в Safari — iCloud. Данные передаются напрямую между Voyager и выбранным личным облачным аккаунтом; Voyager не управляет сервером синхронизации.

## Что синхронизируется

| Тип данных            | Синхронизируется | Подробности                                                                                                  |
| --------------------- | ---------------- | ------------------------------------------------------------------------------------------------------------ |
| Структура папок       | Да               | Все папки, вложенность, цвета и назначения разговоров                                                        |
| Библиотека промптов   | Да               | Все сохранённые промпты с тегами и организацией по папкам                                                    |
| Избранные сообщения   | Да               | Закладки таймлайна из любых разговоров                                                                       |
| Настройки расширения  | Да               | Общие для устройств настройки, например сортировка, цвета и поведение ввода                                  |
| Конфигурация плагинов | Да               | Состояние установки и включения, а также настройки плагинов; разрешения сайтов остаются на каждом устройстве |
| Ответы модели         | Нет              | Резервные копии избранного содержат промпты пользователя, а не ответы модели                                 |

## Избранное и ограничения синхронизации

В облако, в ваш собственный Google Диск или iCloud, загружается **полный текст промптов, которые вы отметили звездой** (до 16 KiB UTF-8 на промпт). Резервные копии избранного не хранят ответы модели. Старая резервная копия v1 содержит только превью; новая v2 включает текст промптов и записи об удалении.

Записи об удалении хранятся 180 дней. Старые версии Voyager игнорируют их и могут снова показать или загрузить удалённое избранное; новые версии блокируют устаревшие копии с неизменившейся отметкой времени. Явная новая пометка звездой или истечение срока записи об удалении могут восстановить звезду. Долгая работа без сети и различия в часах устройств также влияют на распространение удалений.

Синхронизация объединяет данные и проверяет записи, делая не более трёх попыток, но не является атомарной транзакцией между устройствами: одновременные загрузки могут перезаписать чужие изменения. Более поздняя синхронизация с устройства, которое сохранило недостающие данные, может исправить это; если такой синхронизации не будет, восстановление не гарантировано. При частичном сбое загрузки уже принятые записи сохраняются; выполните синхронизацию ещё раз, чтобы завершить восстановление.

## Возможности

- **Синхронизация между устройствами**: поддерживайте одинаковые конфигурации на нескольких компьютерах.
- **Конфиденциальность данных**: данные хранятся в вашем собственном Google Диске или закрытой базе iCloud, без сервера Voyager.
- **Гибкая синхронизация**: поддерживаются ручная загрузка и скачивание с объединением данных.

::: info
Идентификаторы устройств, токены доступа, кэши, координаты области просмотра и временное состояние выполнения намеренно не синхронизируются как персональные настройки.
:::

## Как использовать

1. Нажмите значок Voyager на панели инструментов браузера, чтобы открыть всплывающее окно.
2. Найдите раздел **Облачная синхронизация**.
3. В Safari выберите **Google Диск** или **iCloud**. Остальные браузеры используют Google Диск.
4. Для Google Диска нажмите **Войти через Google** и завершите авторизацию. Для iCloud убедитесь, что на Mac выполнен вход в iCloud.
5. Нажмите **Загрузить**, чтобы отправить локальные данные в облако, или **Синхронизация**, чтобы объединить данные из облака с этим браузером. **Перезаписать** заменяет локальные данные копией из облака вместо объединения, поэтому всё, что вы не загрузили, будет потеряно.

При использовании iCloud **Удалить резервную копию iCloud** удаляет все резервные копии Voyager из iCloud; локальные данные на Mac остаются без изменений.

### 💡 Быстрая синхронизация

Самый быстрый способ — кнопки **«Загрузить в облако»** и **«Синхронизировать из облака»** в верхней части области папок на левой боковой панели.

::: warning
**Рекомендация по безопасности: двойная защита**
Облачная синхронизация очень удобна, но мы настоятельно рекомендуем также периодически создавать резервные копии основных данных в **локальных файлах**.

1. **Папки**: откройте меню области папок, выберите **Импорт/Экспорт папок**, затем **Экспорт папок**, чтобы сохранить все папки и назначения разговоров.
2. **Промпты**: в Менеджере промптов нажмите **Экспорт**, чтобы сохранить библиотеку промптов.
   :::

## Облачная синхронизация и ручное резервное копирование

| Аспект             | Ручное резервное копирование (экспорт/импорт) | Облачная синхронизация                            |
| ------------------ | --------------------------------------------- | ------------------------------------------------- |
| Частота            | Когда вспомните                               | По запросу, одним нажатием                        |
| Расположение       | Локальный файл на компьютере                  | Ваш Google Диск или закрытая база iCloud          |
| Между устройствами | Нужно переносить файлы                        | Устройства, вошедшие в выбранный облачный аккаунт |
| Объединение        | Заменяет данные или требует ручного слияния   | Умное объединение без дублирования                |
| Конфиденциальность | Файл остаётся на вашем компьютере             | Хранится в личном облачном аккаунте               |

## Как это работает

1. **Провайдер**: Google Диск использует ограниченное разрешение `drive.file`, поэтому Voyager может получать доступ только к файлам, которые создал сам. В Safari iCloud использует закрытую базу CloudKit приложения и не передаёт Voyager токен Apple ID.
2. **Загрузка**: когда вы нажимаете **Загрузить**, Voyager записывает у выбранного провайдера отдельные файлы резервных копий для папок, промптов, избранного, форков, иерархии таймлайна, персональных настроек и конфигурации плагинов. Данные выделений включаются, если синхронизация выделений включена.
3. **Синхронизация и объединение**: когда вы нажимаете **Синхронизация** на другом устройстве, Voyager читает эти файлы и объединяет их по типам данных. Новые папки и промпты добавляются без дублирования, облачные настройки восстанавливаются, а записи плагинов объединяются по ID плагина.
4. **Без фоновой синхронизации**: синхронизация выполняется вручную, по запросу. Voyager никогда не синхронизирует данные без вашего явного действия.

Переключение провайдера не копирует данные между ними и не записывает их одновременно в оба. Если после переключения нужно перенести текущие локальные данные в новый выбранный провайдер, выполните загрузку один раз.

## Поддерживаемые платформы

Синхронизация с Google Диском работает в Chrome, Edge, Firefox и Safari. Синхронизация через iCloud доступна только в приложении Safari, распространяемом напрямую, и использует аккаунт iCloud, выполненный на Mac.
