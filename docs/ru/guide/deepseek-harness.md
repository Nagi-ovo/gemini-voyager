# DeepSeek Harness

Открытый агент DeepSeek для программирования. Работает на вашей машине.

У него есть веб-интерфейс по адресу `localhost:3080`.

Веб-интерфейс означает, что Voyager может до него добраться.

## Почему это работает

Менеджер промптов Voyager не смотрит на домены. Он смотрит на сайты, которые вы добавили.

Локальный адрес — тоже сайт.

Поэтому DeepSeek Harness ничем не отличается от Gemini, Claude или ChatGPT: это ещё одно место, куда ваши промпты могут следовать за вами.

## Три шага

### 1. Запустите DSH

```bash
npm i -g @deepseek-ai/dsh
dsh web
```

Откройте `http://localhost:3080` в браузере.

### 2. Включите переключатель во всплывающем окне

![Нажмите значок пазла на панели инструментов, затем Voyager, и включите Менеджер промптов на localhost:3080](/assets/dsh-enable-steps-en.png)

Поскольку вы уже на `localhost:3080`, всплывающее окно предлагает этот адрес вверху. Включите его и предоставьте доступ.

Вводить адрес не нужно.

### 3. Перезагрузите страницу

Плавающая кнопка появится в правом нижнем углу.

![Менеджер промптов внутри DeepSeek Harness](/assets/prompt-manager-deepseek-harness.png)

## Одна библиотека везде

Отдельной библиотеки для каждого сайта нет. Есть одна библиотека, которая следует за вами.

Каждый промпт, сохранённый в Gemini, Claude или ChatGPT, уже на месте, когда вы открываете DSH, — все до одного. Работает и в обратную сторону: промпт, написанный в DSH, будет ждать вас в Gemini.

Те же теги, то же избранное, тот же поиск.

![Одна библиотека, доступная в каждом интерфейсе](/assets/one-prompt-library.png)

## Несколько замечаний

**Порт не фиксирован.** DSH всё ещё в статусе предварительной версии для разработчиков, и порт по умолчанию может измениться. Если это произойдёт, просто добавьте новый адрес.

**Загружается только Менеджер промптов.** На пользовательском сайте, таком как DSH, Таймлайн, Папки и остальные функции не запускаются. (На собственном сайте DeepSeek многие из них доступны как официальные плагины.)

**Ваши промпты никуда не уходят.** DSH работает локально, библиотека Voyager тоже локальная. Ничто в этой цепочке не отправляется наружу.

::: tip
Тот же подход работает с любым локальным веб-интерфейсом: Open WebUI, LibreChat или тем, который вы написали сами. Добавьте адрес, перезагрузите страницу — и готово.
:::
