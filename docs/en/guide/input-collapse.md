# Input Collapse

Collapse the input area when empty to gain more reading space. Click the collapsed bar to expand and start typing.

## How to Use

1. When the input area is empty and loses focus, it automatically collapses into a compact pill button
2. Click the pill button to expand the input area and start typing
3. You can also press <kbd>Ctrl</kbd>/<kbd>⌘</kbd>+<kbd>I</kbd> to quickly expand the input area
4. Turn it on or off with **Plugins** → **Input Collapse** in the popup (off by default)
5. Turn on **Allow collapse with content** as well if you want the input area to collapse even when it holds text or attachments
