# Hide Recent Items and Gems

::: info Retired feature
Voyager no longer hides these sections. The Recent items toggle was easy to click by accident and hard to undo, so it was removed in May 2026; anything you hid before shows again automatically. Gemini's 2026 redesign also dropped the Gems list from the sidebar, so the Gems toggle only appears on older layouts.
:::

This page remains available so existing bookmarks and links continue to work.
