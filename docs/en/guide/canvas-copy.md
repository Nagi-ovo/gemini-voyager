# Copy Canvas as Markdown

Voyager adds **Copy as Markdown** to the Export menu in Gemini Canvas. Copy the document to your clipboard, then paste it into your notes or a Markdown editor.

This feature is on by default and needs no setup.

## How to use it

1. Open a text document in Gemini Canvas.
2. Open the Canvas Export menu and click **Copy as Markdown**.
3. Paste the content where you need it.

This copies the current Canvas document. To export an entire conversation, use [conversation export](/en/guide/export).
