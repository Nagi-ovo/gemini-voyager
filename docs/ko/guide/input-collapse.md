# 입력창 접기

입력창이 비어 있을 때 접으면 읽을 공간이 더 넓어집니다. 접힌 바를 클릭하면 다시 펼쳐져 바로 입력할 수 있습니다.

</div>

## 사용 방법

1. 입력창이 비어 있고 포커스를 잃으면, 자동으로 작은 알약 모양 버튼으로 접힙니다.
2. 알약 버튼을 클릭하면 입력창이 펼쳐져 바로 입력할 수 있습니다.
3. <kbd>Ctrl</kbd>/<kbd>⌘</kbd>+<kbd>I</kbd>를 눌러 입력창을 빠르게 펼칠 수도 있습니다.
4. 팝업의 **입력 옵션**에서 **입력창 접기 활성화**로 켜거나 끌 수 있습니다(기본값은 꺼짐).
5. 입력창에 텍스트나 첨부 파일이 있어도 접히기를 원하면 **내용이 있어도 접기 허용**을 함께 켜세요.
