# 자동 스크롤 방지

이전 대화를 읽고 있을 때 Enter를 눌러 새 프롬프트를 보내면, Gemini™는 새로 생성된 응답을 따라가기 위해 페이지를 맨 아래로 강제로 스크롤합니다. 읽기 흐름이 끊길 수 있습니다.

**자동 스크롤 방지** 기능은 이런 원치 않는 점프를 막습니다.

- 기록을 읽으려고 위로 스크롤한 상태라면, 페이지가 아래로 튀는 것을 막습니다.
- 채팅을 열거나 전환한 직후에는 Gemini가 여전히 최신 메시지로 이동할 수 있습니다. 이 보호는 채팅 안에서 읽는 동안 적용됩니다.
- 이 기능은 기본적으로 **꺼져** 있습니다. 팝업 설정의 "타임라인 옵션"에서 직접 켤 수 있습니다.

## 켜는 방법

1. 브라우저 툴바에서 Voyager 확장 프로그램 아이콘을 클릭해 팝업을 엽니다.
2. "타임라인 옵션(Timeline Options)" 섹션을 찾습니다.
3. "자동 스크롤 방지(Prevent auto-scroll to bottom)" 스위치를 켭니다.
