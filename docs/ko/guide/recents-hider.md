# 최근 항목 및 Gem 숨기기

::: info 지원이 종료된 기능
Voyager는 더 이상 이 섹션들을 숨기지 않습니다. 최근 항목 토글은 실수로 누르기 쉬웠고 되돌리기도 어려워서 2026년 5월에 제거되었습니다. 이전에 숨겨 둔 항목은 자동으로 다시 표시됩니다. Gemini의 2026년 리디자인에서 사이드바의 Gems 섹션이 단일 Gems 링크로 바뀌어, Gems 토글은 이전 레이아웃에서만 나타납니다.
:::

기존 북마크와 링크가 계속 작동하도록 이 페이지는 그대로 남겨 둡니다.
