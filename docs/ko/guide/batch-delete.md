# 일괄 삭제

Gemini와 AI Studio에서 여러 대화를 한 번에 삭제하세요. 이제 더 이상 하나씩 삭제할 필요가 없습니다.

## 주요 기능

- **다중 선택 모드**: 대화를 길게 눌러 다중 선택 모드로 진입하고 삭제할 대화들을 여러 개 체크할 수 있습니다.
- **클릭 한 번으로 정리**: 선택이 완료되면 삭제 버튼을 클릭하여 선택한 모든 대화를 한 번에 제거합니다.
- **진행 상황 피드백**: 삭제 중에 실시간 진행 상황이 표시되어 현재 상태를 알 수 있습니다.
- **안전한 확인**: 실수로 인한 작업을 방지하기 위해 삭제 전 삭제 버튼 옆에 확인 카드가 나타납니다.

## 사용 방법

기본값은 켜짐입니다. **대화 관리** → **일괄 삭제**에서 켜고 끌 수 있습니다(Gemini와 AI Studio 동일). 폴더가 필요하므로 **폴더 옵션** → **폴더 기능 활성화**가 꺼져 있으면 이 항목이 비활성(회색)으로 표시됩니다. 먼저 폴더 기능을 켜세요.

### Gemini

1. 사이드바 대화 목록에서 아무 대화 항목이나 **길게 누릅니다**.
2. 다중 선택 모드로 진입하면 각 대화의 왼쪽에 체크박스가 나타납니다.
3. 삭제하려는 대화들을 체크합니다 (한 번에 최대 50개까지 가능).
4. 나타나는 **삭제 버튼**을 클릭합니다.
5. 삭제 버튼 옆에 나타나는 확인 카드에서 "삭제"를 클릭하여 삭제를 시작합니다.

### AI Studio

1. AI Studio의 **Library** 페이지를 엽니다.
2. 아무 prompt 행이나 **길게 눌러** 다중 선택 모드로 진입합니다.
3. 삭제할 prompt를 선택합니다 (한 번에 최대 50개까지 가능).
4. 떠 있는 **삭제 버튼**을 클릭한 뒤 옆에 나타나는 확인 카드에서 "삭제"를 클릭합니다. AI Studio 자체의 삭제 대화상자는 Voyager가 자동으로 확인합니다.

::: tip 참고
일괄 삭제 작업은 취소할 수 없으므로 주의해서 진행해 주세요.
:::
