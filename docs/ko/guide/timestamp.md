# 메시지 타임스탬프

::: info
**참고**: 이 기능은 버전 1.3.7 이상에서 지원됩니다.
:::

Voyager는 각 메시지의 전송 시간을 표시하여 대화의 전체 흐름을 추적할 수 있도록 도와줍니다.

## 기능 소개

대화가 길어지면 특정 논의가 언제 이루어졌는지 기억하기 어려워집니다.

Voyager는 각 메시지 위에 정확한 타임스탬프(형식: `YYYY-MM-DD HH:mm:ss`)를 표시하며, 타임라인의 점에 마우스를 올려도 같은 시간을 볼 수 있습니다.

## 켜는 방법

1. Voyager 설정 패널을 엽니다(브라우저 도구 모음의 확장 프로그램 아이콘).
2. **타임라인** → **메시지 타임스탬프**를 켭니다(**실험적** 기능, 기본값은 꺼짐).

ChatGPT에서는 **플러그인** → **ChatGPT · 타임라인**을 켠 다음, 그 **옵션**에서 **메시지 타임스탬프 표시**를 켜세요. Gemini의 행과 같은 설정입니다.

## 시간은 어디서 오나요

- **Gemini**: Voyager는 Gemini 자체 대화 데이터에서 각 메시지의 실제 전송 시간을 읽어 오므로, 다른 기기에서 나눈 대화나 Voyager를 설치하기 전의 대화도 정확한 시간이 표시됩니다. 이 시간을 가져올 수 없을 때만 Voyager가 해당 메시지를 처음 발견한 시간(브라우저에 로컬 저장)으로 대체합니다.
- **ChatGPT**: 설정이 켜져 있는 동안 보낸 각 메시지의 시간을 Voyager가 기록해 브라우저에 로컬로 저장합니다. 그 이전에 보냈거나 다른 기기에서 보낸 메시지에는 타임스탬프가 없습니다.

## 기능 특징

- **초 단위 정밀도**: 완전한 날짜와 시간으로 긴 대화 리뷰에 적합합니다.
- **방해 없음**: 시간 정보가 깔끔하게 표시되어 읽기 경험에 영향을 주지 않습니다.

## 사용 시나리오

- **업무 기록**: 특정 결정이 언제 이루어졌는지 되돌아보기.
- **학습 노트**: 개념이 언제 논의되었는지 표시하여 나중에 복습하기.
- **긴 대화 리뷰**: 며칠에 걸친 심층 대화에서 다른 시간대의 토론 내용을 명확히 구분하기.

## 플랫폼

**Google Gemini**(`gemini.google.com`)와 **ChatGPT**(`chatgpt.com`). Claude와 DeepSeek에서는 지원되지 않습니다.
