# 시간 여행

Voyager 타임라인은 Gemini, Claude, ChatGPT를 위한 시각적 대화 탐색 시스템입니다. 채팅의 모든 메시지를 화면 오른쪽의 인터랙티브 노드로 매핑하여, 긴 AI 대화를 즉시 뛰어넘을 수 있는 탐색 지도로 바꿔 줍니다.

긴 대화는 어수선해지기 마련입니다. 위아래로 스크롤하다 보면 현재 위치를 잃어버리곤 하죠.
Voyager는 당신의 대화를 타임라인으로 바꿔줍니다.

Gemini 설정의 **타임라인 표시**는 타임라인 막대와 탐색 단축키를 제어합니다. 꺼도 저장된 별표와 계층은 유지됩니다. 메시지 시간 표시는 **메시지 타임스탬프 표시**로 따로 설정하므로 타임라인을 끈 상태에서도 표시할 수 있습니다.

## 대화의 형태를 확인하세요

화면 오른쪽을 보세요.
각 노드는 메시지를 나타냅니다. 타임라인은 당신의 대화 리듬을 시각화합니다.

## 내비게이션의 해결책

- **순간 이동(Teleport)**: 노드를 클릭하여 해당 메시지로 즉시 이동합니다.
- **미리 보기(Peek)**: 마우스를 올려 이동하지 않고도 내용을 확인합니다.
- **북마크(Bookmark)**: 노드를 길게 눌러 **별표**를 표시하세요. 당신의 뇌를 위한 북마크와 같습니다.
- **레벨 (실험적)**: 기본값은 꺼짐입니다. 먼저 **타임라인 옵션**에서 **노드 레벨 활성화**를 켠 뒤, 노드를 우클릭하여 레벨(1-3)을 설정하거나 하위 노드를 접을 수 있습니다. 분기된 대화를 명확하게 정리하는 데 완벽합니다. 레벨은 `노드` 스타일에서만 표시됩니다. 켜면 타임라인이 `노드`로 바뀌고, 레벨이 켜져 있는 동안에는 `눈금`과 `컴팩트`를 고를 수 없습니다.
- **너비 조절**: 타임라인 안쪽 가장자리를 드래그하여 너비를 조절할 수 있습니다.
- **키보드**: 생각의 속도로 탐색하세요. 기본값은 `j`/`k`, `gg`/`GG`로 처음/마지막 턴으로 이동.

## 별표: 영감의 순간을 북마크하세요

긴 대화 속에 금이 묻혀 있습니다. 별표로 중요한 순간을 고정하세요.

**사용 방법**: 타임라인의 아무 노드나 길게 누르세요(약 0.5초). 노드가 빛나면 — 해당 메시지에 별표가 표시된 것입니다.

- 다시 길게 누르면 별표가 해제됩니다.
- 별표가 표시된 노드는 강조 표시되어 한눈에 찾을 수 있습니다.
- 표시한 모든 메시지는 **저장 보관함**에서 한곳에 확인할 수 있습니다. Voyager 팝업에서 **저장 보관함 보기**를 클릭하거나, 프롬프트 관리자 패널에서 여세요.

대화에 깃발을 꽂는 것과 같습니다 — 영감이 떠오른 순간, 완벽한 답변, 다음에 이어서 할 지점.

::: tip 팁
[클라우드 동기화](/ko/guide/cloud-sync)를 활성화하면 별표가 기기 간에 동기화됩니다.
:::

## 보기 설정

Voyager 팝업의 **타임라인 옵션**에서 설정합니다.

- **타임라인 스타일**: `노드`, `눈금`, `컴팩트` 중에서 고를 수 있습니다.
- **미리보기 패널 고정**: 타임라인 옆에 미리보기 패널을 계속 열어 둡니다. 패널의 검색창에 입력하면 메시지가 실시간으로 걸러집니다.
- **드래그 가능한 타임라인**: 타임라인을 페이지 어디로든 옮길 수 있습니다. **타임라인 위치 초기화**를 누르면 원래 자리로 돌아갑니다.

## 키보드로 더 빠르게

마우스를 사용하고 싶지 않으신가요? 키보드를 사용하세요.

**Gemini에서 Vim 모드를 켜는 것과 같습니다.**

### 기본 단축키

- `k` - 이전 노드로 이동
- `j` - 다음 노드로 이동
- `gg` - 첫 번째 턴으로 이동
- `GG` - 마지막 턴으로 이동

### 맞춤 설정

확장 프로그램 설정을 열고 단축키 상자를 클릭한 다음 원하는 키를 누르세요.
어떤 키나 조합도 가능합니다. `n`/`p`? `,`/`.`? 당신의 선택입니다.

**플로우(Flow) 모드**: 빠르게 누르면 부드럽게 대기열에 추가됩니다.
**점프(Jump) 모드**: 즉각적인 반응, 최대 속도.

## 타임라인을 쓰면 좋은 경우

타임라인은 메시지가 10개를 넘어 스크롤이 번거로워지는 긴 대화에서 특히 유용합니다.

- **리서치 세션**: Gemini에게 30턴 넘게 주제를 탐색하게 했다면, 타임라인으로 핵심 통찰이 나온 지점까지 전부 다시 읽지 않고 바로 돌아갈 수 있습니다.
- **코드 디버깅**: 47번째 턴에서 해결책이 나온 긴 디버깅 대화라면, 그 지점에 별표를 붙여 두고 나중에 한 번의 클릭으로 찾으세요.
- **학습과 튜터링**: 복잡한 주제를 단계별로 공부할 때, 레벨 기능으로 이미 익힌 부분을 접어 두세요.
- **브레인스토밍 복기**: 창의적인 세션을 돌아보며 좋은 아이디어를 뽑아낼 때, 별표로 남길 가치가 있는 순간을 표시하세요.

## 타임라인과 수동 스크롤 비교

| 기능                   | 타임라인 없이               | Voyager 타임라인 사용 시                                 |
| ---------------------- | --------------------------- | -------------------------------------------------------- |
| 특정 메시지 찾기       | 위아래로 반복해서 스크롤    | 노드를 클릭하거나 j/k를 누르기                           |
| 중요한 순간 북마크     | 외부 메모에 복사-붙여넣기   | 길게 눌러 별표 표시, 클라우드에 동기화                   |
| 대화 구조 파악         | 순서대로 읽기               | 시각적 지도로 전체 형태를 한눈에 확인                    |
| 키보드 탐색            | Gemini에서는 사용할 수 없음 | Vim 스타일 j/k, gg/GG, 전부 맞춤 설정 가능               |
| 메시지 100개 이상 탐색 | 몇 분씩 스크롤              | 원하는 지점으로 즉시 이동                                |
| 긴 스레드 정리         | 기본 도구 없음              | 레벨(1~3)과 접을 수 있는 하위 노드(실험적, 직접 켜야 함) |

## 지원 브라우저

타임라인은 Google Gemini에서 작동하며, Claude와 ChatGPT에서는 내장 플러그인으로 작동합니다. Chrome, Edge, Firefox, Safari, Opera, Brave에서 사용할 수 있습니다. 키보드 단축키와 별표는 세 플랫폼에서 똑같이 작동합니다. 레벨은 모든 플랫폼에서 직접 켜야 하는 실험적 기능입니다. Gemini에서는 **타임라인 옵션**에서 **노드 레벨 활성화**를 켜고, Claude와 ChatGPT에서는 **플러그인**의 **Claude · 타임라인** 또는 **ChatGPT · 타임라인** 설정에서 같은 스위치를 켜세요. [클라우드 동기화](/ko/guide/cloud-sync)를 켜면 별표 메시지가 기기 간에 동기화됩니다.

타임라인은 AI Studio에서 사용할 수 없습니다. DeepSeek에는 선택 사항인 타임라인 플러그인이 플러그인 카탈로그에 있으며, 기본적으로 꺼진 상태로 제공됩니다.
