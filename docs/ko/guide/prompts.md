# 지적 자산: 프롬프트 라이브러리

완벽한 프롬프트를 만들었습니다. 복잡한 코딩 문제를 풀었거나 아름다운 이메일을 썼습니다.
그걸 버리시겠습니까?
아니요. 저장하세요.

## 프롬프트 저장소

이곳은 당신의 뛰어난 아이디어를 모아 두는 개인 저장소입니다.

### 1. 저장하기

훌륭한 프롬프트를 작성했다면 Voyager 플로팅 버튼(기본적으로 입력창 옆에 있으며, 어디로든 드래그할 수 있습니다)을 클릭해 **프롬프트 관리자**를 여세요.
이제 그 프롬프트는 저장소의 일부가 되었습니다.

### 2. 분류하기

`coding`, `email`, `research`처럼 태그를 추가하세요(쉼표로 구분합니다).
도구를 날카롭게 다듬고 정리해 두세요.

### 3. 꺼내 쓰기

다음에 필요할 때 다시 입력하지 마세요.
관리자를 열고 태그나 키워드로 검색한 뒤 클릭해서 삽입하세요.
클릭 한 번이면 충분합니다. 무한한 활용이 가능해집니다.

![프롬프트 관리자](/assets/gemini-prompt-manager.png)

## 간결한 목록과 메모

프롬프트가 많아져 카드 목록이 한 화면에 들어가지 않으면, 패널이 그에 맞게 바뀝니다.

### 보기 전환

검색창 오른쪽의 `≡ / ▦` 버튼으로 **간결한 목록**(기본값)과 **편안한 보기**를 전환합니다.

- **간결한 목록**: 한 줄에 프롬프트 하나씩, 한 번에 약 10개가 보입니다. 오른쪽에는 태그, 펼치기, 편집, 삭제 버튼이 있습니다.
- **편안한 보기**: Markdown 전체를 미리 보여 줍니다. 프롬프트가 많지 않을 때 좋습니다.

### 이름 필수

추가하거나 편집하는 폼 맨 위의 **이름** 필드에 짧은 제목을 적어야 합니다. 프롬프트를 만들거나 편집할 때 이름이 필수입니다. 이름이 없는 기존 프롬프트는 계속 사용할 수 있지만, 다음번에 편집할 때 이름을 입력해야 합니다.

### 빠른 호버 미리보기

간결한 모드에서 행 위에 약 **250ms** 동안 마우스를 올리면, 플로팅 툴팁으로 전체 내용을 볼 수 있습니다. 브라우저 기본 `title` 툴팁(열리는 데 1~3초가 걸릴 수 있음)을 대신합니다.

### 슬래시로 빠르게 삽입

채팅 입력창에 `/`를 입력한 뒤 프롬프트 이름의 일부를 적으세요. 일치하는 이름과 태그가 목록에 나타납니다. 항목에 마우스를 올리면 전체 본문을 미리 볼 수 있고, 클릭하거나 `Tab` / `Enter`를 누르면 선택됩니다. 입력창에는 선택한 이름이 강조된 토큰으로 표시되며, 전송할 때는 프롬프트 전체 본문이 사용됩니다.

## 어디에서나 사용하기

프롬프트 관리자는 이제 Gemini™와 AI Studio뿐 아니라, 원하는 모든 웹사이트에서 사용할 수 있습니다.

### 켜는 방법

Claude, ChatGPT, DeepSeek에서는 그 사이트에 있는 상태에서 Voyager 팝업을 열고 해당 사이트의 스위치를 켜세요(예: **Claude에서 프롬프트 관리자 사용**). 접근 권한을 요청하면 허용하세요.

그 밖의 사이트라면 다음과 같이 하세요.

1. 브라우저 확장 프로그램 도구 모음에서 Voyager 아이콘을 클릭합니다.
2. **프롬프트 관리자** 섹션까지 스크롤합니다.
3. 웹사이트 주소(예: `chatgpt.com` 또는 `claude.ai`)를 입력합니다.
4. **웹사이트 추가**를 클릭하고 권한을 허용합니다.
5. **대상 페이지를 새로고침**하면 플로팅 버튼이 나타납니다.

### 인기 AI 웹사이트

- `chatgpt.com` - ChatGPT
- `claude.ai` - Claude
- `copilot.microsoft.com` - Microsoft Copilot
- `poe.com` - Poe

### 로컬 앱

로컬 주소도 같은 방식으로 입력하면 됩니다. `localhost:3080` 또는 `127.0.0.1:3080`이 해당됩니다. 예를 들어 [DeepSeek Harness](/ko/guide/deepseek-harness)는 `localhost:3080`에서 실행되며, 프롬프트 관리자는 다른 호스팅 사이트와 똑같이 연결됩니다.

![DeepSeek Harness에서 실행 중인 프롬프트 관리자](/assets/prompt-manager-deepseek-harness.png)

::: tip
직접 추가한 웹사이트에서는 **프롬프트 관리자**만 활성화됩니다. 타임라인이나 폴더 같은 기능은 로드되지 않습니다. Claude, ChatGPT, DeepSeek은 다릅니다. 이 사이트들은 전용 공식 플러그인을 사용하며, [플러그인 마켓](/ko/plugins)에서 확인할 수 있습니다.
:::
