# 수식 복사

Voyager를 사용하면 수학 공식과 과학 기호를 손쉽게 재사용할 수 있습니다. 수식을 클릭 한 번으로 LaTeX 소스 코드, Microsoft Word 호환 MathML, 또는 Notion에 맞는 블록 형식으로 복사할 수 있습니다.

## 소개

Gemini에게 공식을 유도하거나 수학적 표현을 작성하도록 요청하면 보통 LaTeX를 사용하여 렌더링합니다. 보기에 아름답지만, 자신의 논문, 문서 또는 에디터에서 사용하기 위해 소스 코드를 추출하는 것은 종종 번거로운 수작업을 필요로 합니다.

Voyager는 이를 위한 원활한 지원을 제공합니다:

1. **자동 감지**: Voyager는 페이지에 렌더링된 수식을 자동으로 식별합니다. 수식 위에 마우스를 올리면 클릭할 수 있다는 것을 알 수 있습니다.
2. **클릭하여 복사**: 인라인 수식이든 블록 수식이든 클릭하면 바로 복사되고, 짧은 확인 메시지가 나타납니다.
3. **형식 옵션**: 팝업에서 **수식 복사 형식**을 미리 선택할 수 있습니다:
   - **LaTeX**: 달러 기호 구분자가 포함된 표준 LaTeX 소스로, Overleaf, Markdown 에디터 등에 적합합니다.
   - **LaTeX (달러 기호 없음)**: 구분자가 없는 순수한 LaTeX 소스로, 구분자를 직접 붙이는 에디터에 적합합니다.
   - **MathML (Word)**: **Microsoft Word**에 직접 붙여넣기에 가장 적합한 형식입니다.
   - **Notion ($$ 포맷)**: 모든 수식을 `$$`로 감싸서 Notion이 수식 블록으로 인식하게 합니다.

## 주요 기능

- **Word 호환성**: MathML 지원을 통해 AI가 생성한 복잡한 공식을 편집 가능한 완벽한 서식을 유지하면서 Word 문서에 직접 붙여넣을 수 있습니다.
- **문맥 보존**: 수식 자체뿐만 아니라 수학적 문맥도 보존하여 복사합니다.
- **즉각적인 응답**: 모든 처리가 로컬에서 이루어지므로 결과가 즉시 나타납니다.

## 사용 팁

- **학술 글쓰기**: Word에서 논문을 작성할 때 Gemini에게 공식을 유도하게 한 후, MathML 복사-붙여넣기를 사용하여 Word 수식 에디터에서 수동으로 입력하는 번거로움을 피하세요.
- **노트 필기**: Obsidian이나 Notion에서 노트를 필기할 때 LaTeX 소스를 직접 복사하여 사용하세요.

## 지원 범위

Gemini와 AI Studio에서는 팝업의 **수식 복사 사용**을 켜면 됩니다. 이 스위치와 복사 형식은 두 사이트에 모두 적용됩니다. Claude와 ChatGPT는 내장 플러그인으로 수식 복사를 제공하며, DeepSeek에는 [플러그인 카탈로그](/ko/guide/plugins)에 수식 복사 플러그인이 있습니다.
