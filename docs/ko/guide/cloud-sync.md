# 클라우드 동기화

폴더, 프롬프트 라이브러리 및 기타 데이터를 Google Drive에 동기화하여 여러 기기에서 일관된 환경을 유지하세요.

## 주요 기능

- **다중 기기 동기화**: Google Drive를 사용하여 여러 컴퓨터 간에 설정을 동기화 상태로 유지합니다.
- **데이터 프라이버시**: 데이터가 본인의 Google Drive 저장소에 직접 저장되므로 제3자 서버 없이 프라이버시가 보장됩니다.
- **유연한 동기화**: 수동 업로드 및 데이터 다운로드/병합을 지원합니다.

## 별표 데이터와 동기화 제한

클라우드 업로드에는 **별표로 표시한 사용자 프롬프트의 전체 텍스트**(프롬프트당 UTF-8 최대 16 KiB)가 포함되며, 본인의 Google Drive 또는 iCloud에 저장됩니다. 별표 백업에는 모델 답변이 저장되지 않습니다. 기존 v1 백업은 미리보기만 유지하고, 새 v2 백업은 프롬프트 텍스트와 삭제 기록을 포함합니다.

삭제 기록은 180일 동안 유지됩니다. 이전 Voyager 버전은 이를 무시하여 삭제된 별표를 다시 표시하거나 업로드할 수 있지만, 새 버전은 타임스탬프가 같은 오래된 복사본을 차단합니다. 더 최근 시점에 다시 별표를 표시하거나 삭제 기록이 만료되면 별표가 복원될 수 있습니다. 장기간 오프라인 상태와 기기 시계 차이도 삭제 전파에 영향을 줍니다.

동기화는 데이터를 병합하고 쓰기 결과를 확인하며 최대 세 번 시도하지만, 기기 간 원자적 트랜잭션은 아닙니다. 동시 업로드가 다른 기기의 쓰기를 덮어쓸 수 있습니다. 누락된 데이터를 유지한 기기가 나중에 동기화하면 복구할 수 있지만, 다시 동기화하지 않으면 복구를 보장할 수 없습니다. 일부 업로드가 실패해도 성공한 쓰기는 유지됩니다. 다시 동기화하여 복구를 완료하세요.

## 사용 방법

1. Gemini™ 페이지 우측 하단의 확장 프로그램 아이콘을 클릭하여 설정 패널을 엽니다.
2. **클라우드 동기화 (Cloud Sync)** 섹션을 찾습니다.
3. **Google 계정으로 로그인 (Sign in with Google)**을 클릭하고 권한 승인을 완료합니다.
4. 승인이 완료되면 **클라우드에 업로드 (Upload to Cloud)**를 클릭하여 로컬 데이터를 클라우드로 동기화하거나, **다운로드 및 병합 (Download & Merge)**을 클릭하여 클라우드 데이터를 로컬로 가져옵니다.

가장 쉬운 방법은 왼쪽 사이드바의 폴더 영역 상단에 있는 **"클라우드에 업로드"** 또는 **"다운로드 및 병합"** 버튼을 클릭하는 것입니다.
