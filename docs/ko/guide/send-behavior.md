# 전송 동작

::: info
**참고**: 이 기능은 버전 1.3.7 이상에서 사용할 수 있습니다.
:::

전송 단축키를 `Ctrl+Enter`(macOS에서는 `⌘+Enter`)로 바꾸면 `Enter`는 줄바꿈 키가 되어, 여러 줄 프롬프트도 편하게 작성할 수 있습니다.

## 이 기능이 필요한 이유

기본적으로 `Enter`를 누르면 메시지가 바로 전송됩니다. 긴 프롬프트를 쓰거나, 여러 줄 코드를 붙여넣거나, 입력 내용을 공들여 정리할 때는 이것이 실수로 보내기로 이어지기 쉽습니다. 줄만 바꾸고 싶었는데 메시지가 이미 전송되어 버리는 것이죠.

켜 두면:

- **Enter** → 줄바꿈 삽입
- **Ctrl+Enter** (macOS: **⌘+Enter**) → 메시지 전송

Shift+Enter와 IME 입력 조합은 사이트의 기본 동작을 그대로 유지하며, 첨부 파일이 아직 업로드 중이면 Ctrl/⌘+Enter는 업로드가 끝날 때까지 기다립니다.

## 켜는 방법

1. Voyager 팝업을 엽니다.
2. **입력 옵션**에서 **Ctrl+Enter 로 전송**을 켭니다(macOS에서는 **⌘+Enter 로 전송**으로 표시됩니다).

## 다른 사이트

- **AI Studio**는 반대 방식으로 작동합니다. **AI Studio에서 Enter로 전송**을 켜면 `Enter`로 전송하고 `Ctrl/⌘+Enter`로 줄바꿈합니다.
- **Claude, ChatGPT, DeepSeek**: [플러그인 마켓](/ko/plugins)에서 해당 사이트용 **Ctrl/Cmd+Enter to send** 플러그인을 설치하세요.
- **Safari**: Gemini에서 Enter를 두 번 눌러야 전송된다면 **Safari Enter 키 수정**을 켜세요.

## 기능 특징

- **성능 부담 없음**: 비활성화하면 키보드 이벤트 리스너가 전혀 동작하지 않아 페이지 성능에 영향을 주지 않습니다.
- **즉시 전환**: 설정에서 토글하면 페이지를 새로고침하지 않아도 바로 적용됩니다.
