# 전송 동작

::: info
**참고**: 이 기능은 버전 1.3.7 이상에서 지원됩니다.
:::

전송 단축키를 `Ctrl+Enter`(macOS에서는 `⌘+Enter`)로 변경하고, `Enter` 키는 줄바꿈으로 사용하여 여러 줄의 프롬프트를 여유롭게 작성할 수 있습니다.

## 이 기능이 필요한 이유

기본적으로 `Enter`를 누르면 메시지가 즉시 전송됩니다. 긴 프롬프트를 작성하거나, 여러 줄의 코드를 붙여넣거나, 입력을 세심하게 포맷할 때 오발송이 자주 발생합니다——줄만 바꾸려 했는데 메시지가 이미 전송되어 버리는 것입니다.

활성화하면:

- **Enter** → 줄바꿈 삽입
- **Ctrl+Enter** (macOS: **⌘+Enter**) → 메시지 전송

Shift+Enter와 IME 입력 조합은 사이트의 기본 동작을 그대로 유지하며, 첨부 파일이 아직 업로드 중이면 Ctrl/⌘+Enter는 업로드가 끝날 때까지 기다립니다.

## 활성화 방법

1. Voyager 설정 패널(팝업)을 엽니다.
2. **입력** → **Ctrl/Cmd+Enter 로 전송** 토글을 찾습니다.
3. 켜면 됩니다.

## 다른 사이트

- **AI Studio**는 반대 방식으로 작동합니다. **AI Studio에서 Enter로 전송**을 켜면 `Enter`로 전송하고 `Ctrl/⌘+Enter`로 줄바꿈합니다.
- **Claude, ChatGPT, DeepSeek**: 해당 사이트에서 Voyager 팝업을 열고 **플러그인** 카드에서 **Ctrl/⌘+Enter로 전송**을 켜세요. 사이트별 플러그인은 [플러그인 목록](/ko/guide/plugins)에서 볼 수 있습니다.
- **Safari**: Gemini에서 Enter를 두 번 눌러야 전송된다면 **Safari Enter 키 수정**을 켜세요.

## 기능 특징

- **제로 성능 오버헤드**: 비활성화 시 키보드 이벤트 리스너가 전혀 동작하지 않아 페이지 성능에 영향이 없습니다.
- **즉시 전환**: 설정에서 토글 후 즉시 반영되며 페이지 새로고침이 필요 없습니다.
