# 글꼴 크기

Gemini 채팅 영역의 글꼴 크기를 자유롭게 조절해 가장 편안한 읽기 환경을 만드세요.

## 소개

글꼴 크기 선호는 사람마다 다릅니다. 정보 밀도를 높이려고 작은 글씨를 선호하는 사람도 있고, 눈의 피로를 줄이려고 큰 글씨를 선호하는 사람도 있습니다. Voyager를 사용하면 채팅 글꼴 크기를 80%에서 150% 사이로 조절할 수 있습니다.

## 기능

- **넓은 범위**: 80%–150% 사이의 글꼴 크기 조절을 지원해 대부분의 읽기 요구를 충족합니다.
- **전체 적용**: 사용자 메시지와 모델 응답 모두에 적용되며, 본문, 목록, 표, 코드 블록을 포함합니다.
- **코드 블록 최적화**: 코드 블록 글꼴 크기는 본문 글꼴 크기의 0.875배로 자동 비례 조정되어, 코드와 본문 사이의 시각적 위계가 유지됩니다.
- **즉시 적용**: 변경 사항은 페이지를 새로고침하지 않아도 바로 반영됩니다.

## 사용 방법

1. Voyager 설정 패널(팝업)을 엽니다.
2. **대화 글꼴 크기**를 찾아 켭니다.
3. 슬라이더를 드래그해 글꼴 크기 비율을 조절합니다. 페이지에 변경 사항이 실시간으로 미리 보입니다.
