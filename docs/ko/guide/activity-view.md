# Activity: 진행 중인 대화에 주의를 두기

폴더는 "이 대화는 어디에 속하는가?"라는 질문에 답합니다. 보관함이 커질수록 "지금 무엇을 봐야 하는가?"라는 질문이 더 자주 생깁니다.

Activity는 폴더 위에 얹어 보는 시간 기반 화면입니다. **폴더** 옆의 종 아이콘을 클릭하면 폴더 트리 대신 실제 대화 활동순으로 정렬된 대화 목록이 나타납니다. 폴더, 대화의 폴더 배정, Star 상태는 바뀌지 않습니다.

**디자인 영감:** 이 화면은 OpenAI Codex / ChatGPT Desktop의 사이드바에서 영감을 받았습니다. Voyager는 아직 활동 중인 대화를 위로 올려 보여 준다는 아이디어를 가져와, Gemini 폴더에 맞춘 시간 기반 화면으로 바꿨습니다.

## 우선순위는 최근 활동을 따릅니다

**우선순위**에는 최근 **3시간** 안에 새 대화 턴이 생긴 대화가 들어갑니다. 대화를 열거나 확인한 시각이 아니라 실제 대화 시각을 기준으로 합니다.

우선순위에 있는 대화는 오늘 그룹에 중복으로 나타나지 않습니다. 3시간의 활동 구간이 끝나면 Activity가 자동으로 대화를 오늘이나 해당 날짜 그룹으로 되돌립니다. 페이지를 새로고침할 필요는 없습니다.

Star는 별도의 수동 표시로 계속 사용할 수 있습니다. 대화에 Star를 붙여도 우선순위로 옮겨지지 않으며, Star를 해제해도 활동 중인 대화가 우선순위에서 빠지지 않습니다.

## 최근 며칠만 짧게 보여 줍니다

우선순위 아래에는 **오늘**, **어제**, 그 이전 날들의 요일 제목이 이어집니다. 오늘과 그 전 4개 달력일까지만 다뤄서, 목록이 지금 하는 작업에 가깝게 유지됩니다.

그보다 오래된 대화나 활동 시각이 없는 이전 기록은 이 화면에 나타나지 않습니다. 숨겨지거나 삭제된 것은 아닙니다. 종 아이콘을 다시 클릭해 폴더 트리로 돌아가면 원래 위치에서 찾을 수 있습니다.

## 한 대화는 한 줄로 표시됩니다

한 대화가 여러 폴더에 속할 수 있습니다. Activity는 이런 항목을 한 줄로 합치고, 제목 아래에 폴더 이름을 유지합니다. 폴더 정보 위에 마우스를 올리면 전체 경로를 볼 수 있습니다.

이렇게 하면 한 대화가 우선순위나 오늘 그룹에서 여러 자리를 차지하지 않으면서도, 프로젝트 맥락은 그대로 남습니다.

## 세 가지 신호와 각각의 역할

| 신호     | 출처                        | 답하는 질문                           |
| -------- | --------------------------- | ------------------------------------- |
| 폴더     | 직접 정리한 프로젝트와 주제 | 이 대화는 어디에 속하는가?            |
| Activity | 가장 최근의 실제 대화 턴    | 최근에 움직이고 있는 작업은 무엇인가? |
| Star     | 수동 표시                   | 계속 표시해 둘 대화는 무엇인가?       |

폴더는 보관함에서 무언가를 다시 찾아야 할 때 유용합니다. Activity는 Gemini로 돌아올 때마다 고를 대화의 범위를 좁혀 줍니다. 우선순위에서 아직 진행 중인 대화부터 시작하고, 오늘이나 어제 그룹을 거친 뒤, 오래된 자료가 필요해지면 다시 전체 폴더 트리로 돌아가세요.

## 사용할 수 있는 곳

Activity는 Gemini의 폴더 사이드바와 ChatGPT의 폴더 영역(ChatGPT 폴더 내장 플러그인의 일부)에서 사용할 수 있습니다.
