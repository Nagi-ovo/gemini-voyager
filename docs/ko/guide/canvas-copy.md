# Canvas를 Markdown으로 복사

Voyager는 Gemini Canvas의 공유 메뉴에 **Markdown으로 복사**를 추가합니다. 문서를 클립보드에 복사한 뒤 노트나 Markdown 편집기에 붙여넣을 수 있습니다.

이 기능은 기본으로 켜져 있으며 별도 설정이 필요하지 않습니다.

## 사용 방법

1. Gemini Canvas에서 텍스트 문서를 엽니다.
2. Canvas 공유 메뉴를 열고 **Markdown으로 복사**를 클릭합니다.
3. 원하는 곳에 내용을 붙여넣습니다.

현재 Canvas 문서만 복사됩니다. 대화 전체를 내보내려면 [대화 내보내기](/ko/guide/export)를 사용하세요.
