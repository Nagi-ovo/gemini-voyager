# 나만의 것으로 만들기

기본 환경도 훌륭합니다. 하지만 당신은 완벽함을 원할 수도 있죠.
모든 세부 사항을 맞춤 설정하세요.

## 시네마 모드 (Cinema Mode)

왜 미래를 작은 바늘구멍을 통해 보나요?
Voyager를 사용하면 대화창 너비를 확장할 수 있습니다.

- **대화 너비**: 먼저 팝업에서 **페이지 레이아웃** → **대화 너비**를 켜세요. 기본값은 꺼짐이며, 켜면 해당 행 아래에 슬라이더가 나타납니다. 켜면 창 너비의 30%에서 100%까지 조절할 수 있습니다(기본값 70%). 코딩이나 복잡한 표를 볼 때는 넓게, 읽을 때는 좁게 설정하세요.
- **편집 입력창 너비**: 먼저 **페이지 레이아웃** → **편집 입력창 너비**를 켠 뒤, 보낸 메시지를 편집할 때 나타나는 입력창을 넓힙니다.

## 컨트롤 (Control)

확장 프로그램 아이콘을 클릭하여 컨트롤 센터에 접속하세요.

- **스크롤 모드**: **타임라인** → **타임라인 표시**에서 고릅니다. `플로우`는 메시지까지 부드럽게 스크롤하고, `점프`는 즉시 이동합니다.
- **타임라인 위치**: **타임라인** → **타임라인 표시**에서 **드래그 가능한 타임라인**을 켜고 당신이 편안하게 느끼는 곳에 두세요. **타임라인 위치 초기화**를 누르면 원래 자리로 돌아갑니다.
- **시각 효과**: Gemini와 AI Studio에서는 **페이지 레이아웃** → **시각 효과**를 켠 다음 그 행 아래에서 `눈`, `벚꽃`, `비` 중 하나를 고르세요. 끄면 효과도 꺼집니다. 다른 사이트(Claude, ChatGPT, DeepSeek, 사용자 지정 사이트)에서는 같은 행이 해당 사이트의 **플러그인** 카드에 표시되며, Voyager가 그 사이트에서 동작할 때(프롬프트 관리자 또는 해당 사이트에서 켠 플러그인이 있을 때) 나타납니다.

## 사용자 정의 순서

팝업에 설정 항목이 너무 많아 자주 쓰는 것이 아래에 묻혀 있나요?

설정 카드에 마우스를 올리면 오른쪽 상단에 ▲/▼ 버튼이 나타납니다. 클릭하면 카드가 위아래로 이동하며, 순서는 자동 저장됩니다.

기능은 주제별 카드(페이지 레이아웃, 사이드바, 타임라인, 답변 내용 등)로 나뉘어 있고, 켜면 해당 옵션이 스위치 바로 아래에 나타납니다. 스크롤해도 검색창과 그 아래 카드 이름 줄은 위에 고정되며, 이름을 누르면 해당 카드로 이동합니다. 스위치를 잘못 눌렀다면 아래에 뜨는 메시지에서 **실행 취소**를 누르세요.

## 분위기

Voyager는 효율 향상에만 그치지 않습니다. 페이지의 분위기도 바꿀 수 있습니다.

- **눈**: 부드러운 눈송이가 천천히 내려 차분한 겨울 느낌을 줍니다.
- **벚꽃**: 벚꽃 잎이 자연스럽게 흩날리며 가벼운 봄 분위기를 연출합니다.
- **비**: 비스듬한 빗줄기와 은은한 물방울이 시네마틱한 몰입감을 줍니다.
- **부드러운 전환**: 효과를 끄거나 전환하면 파티클이 자연스럽게 사라집니다.
