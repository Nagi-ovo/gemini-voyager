# 사이드바 자동 숨김

더 몰입감 있는 채팅 경험을 원하시나요?

우리는 **사이드바 자동 숨김** 기능을 제공합니다. 이 기능을 활성화하면 마우스가 사이드바 영역을 벗어날 때 사이드바가 자동으로 접히고, 마우스를 다시 사이드바 영역으로 가져가면 자동으로 펼쳐집니다.

### 활성화 방법

1. Voyager 팝업을 엽니다.
2. **플러그인** → **사이드바 자동 숨김**을 켭니다.
3. 접힌 레일까지 숨기려면 **플러그인** → **사이드바 완전히 숨김**을 켜세요(단독으로도 작동합니다).

_참고: 이 기능은 현재 Google Gemini만 지원합니다._
