# 사이드바의 최근 Gems

Gemini의 2026년 리디자인은 처음에 Gems를 설정 메뉴 뒤로 옮겼다가, 이후 사이드바에 내비게이션 항목을 조용히 되돌렸습니다. 하지만 그 항목은 `/gems/view`로 보내는 링크일 뿐입니다.

Voyager는 이 네이티브 Gems 항목을 사이드바 안에서 내 Gem 목록으로 "펼쳐지도록" 만듭니다. 고정한 Gem이 먼저 나오고, 그다음에 최근에 가장 많이 사용한 Gem이 이어집니다.

## 모습

- **네이티브 Gems 항목 아래에 붙습니다.** Gemini의 "Gems" 레이블에 맞춰 들여쓰기되므로, 덧붙인 패널이 아니라 그 항목의 하위 목록처럼 보입니다.
- **셰브론 토글.** Gems 항목 오른쪽의 작은 `›` 버튼은 펼치면 `⌄`로 바뀝니다. 클릭하면 접히고 펼쳐집니다. 상태는 로컬에 저장되며 탭 사이에서 동기화됩니다.
- **최근 사용순.** 내 Gem이든 Google이 제공한 기본 Gem이든, 연 Gem은 목록 맨 위로 올라갑니다.
- **고정한 Gem은 그대로 유지됩니다.** 고정한 Gem은 항상 먼저 나오며, 고정한 순서를 따릅니다. 또한 슬라이더 개수 제한에 포함되지 않습니다.
- **네트워크 트래픽 없음.** 모든 정보는 사용자가 연 페이지에서 Voyager가 확인한 내용에서 가져옵니다. API 호출, 폴링, 백그라운드 요청이 전혀 없습니다.

## 사용 방법

1. Voyager 팝업을 엽니다(툴바의 확장 프로그램 아이콘).
2. **사이드바의 최근 Gems** 슬라이더를 찾습니다. 기본값은 3개입니다.
3. 원하는 개수(1~10)까지 드래그하세요. **`0`으로 두면 섹션 전체가 숨겨집니다**. 이 기능이 필요 없다면 0으로 설정하세요.

내 Gem을 고정하려면 `gemini.google.com/gems/view`를 열고 해당 행의 고정 버튼(**Pin to sidebar**)을 클릭하세요. 다시 클릭하면 고정이 해제됩니다.

::: tip 처음 설정할 때
목록은 사용하면서 채워집니다. Gem을 열면 목록에 나타납니다. 최근에 열지 않은 Gem까지 보고 싶다면 `gemini.google.com/gems/view`를 한 번 방문하세요. Voyager가 그곳에서 Gem 목록을 조용히 저장합니다.
:::

## 목록이 갱신되는 시점

- **Gem 열기**(`/gem/<id>`)는 방금 사용한 것으로 기록됩니다.
- **`/gems/view` 방문**은 Gem 목록 스냅샷을 새로 고칩니다. 그곳에서 순서를 바꾸거나, 이름을 바꾸거나, 만들거나, 삭제하면 즉시 동기화됩니다.
- 다른 페이지에서는 아무것도 읽지 않습니다.

따라서 다른 기기에서 Gem을 추가해도 Voyager가 "마법처럼" 알아차리지는 못합니다. 이 컴퓨터에서 그 Gem을 열거나 `/gems/view`를 한 번 열어 주세요.

## 개인정보 보호

- Gem 목록 스냅샷과 최근 사용 기록은 **로컬 브라우저 저장소**(`chrome.storage.local`)에 남습니다.
- 슬라이더 값과 고정된 Gem의 ID는 다른 Voyager 설정과 함께 **브라우저 동기화 저장소**에 저장되므로, 같은 브라우저 프로필에 로그인한 기기 사이에서 따라갑니다. 이름과 아이콘은 동기화되지 않습니다.
- Gem의 대화 내용은 읽거나 저장하지 않습니다. 이름, 설명, 링크, 아바타용 첫 글자만 사용합니다.
- 기능을 끄면(개수 = 0) 로컬 데이터는 그대로 남아 있으므로, 다시 켜면 바로 적용됩니다.

## 플랫폼

Gemini(`gemini.google.com`)에서만 작동합니다. AI Studio의 Gem 항목은 형태가 달라서 다루지 않습니다.
