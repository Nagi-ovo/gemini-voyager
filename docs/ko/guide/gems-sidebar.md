# 사이드바의 최근 Gems

Gemini의 새 사이드바에서는 Gems가 더보기 메뉴로 옮겨졌고, 그곳에는 `/gems/view` 전체 페이지로 가는 링크만 있습니다. Voyager는 사이드바에 자체 Gems 섹션을 추가해 내 gems를 한 번의 클릭으로 열 수 있게 합니다. 고정한 gem이 먼저, 그다음에 최근에 사용한 gem이 나옵니다.

## 어떻게 보이나요

- **별도의 Gems 섹션.** 목록은 사이드바 상단 탐색(더보기가 있는 그룹) 아래에 **Gems** 제목과 함께 표시됩니다. Gemini에 네이티브 Gems 항목이 보이면 목록은 그 항목 아래에 붙습니다.
- **접기/펼치기.** **Gems** 제목(네이티브 항목에서는 오른쪽 셰브론)을 클릭하면 접거나 펼칠 수 있고, 열리면 `›`가 `⌄`로 회전합니다. 상태는 로컬에 저장되고 탭 간 동기화됩니다.
- **최근 사용순.** 내 gem이든 Google이 제공한 기본 gem이든, gem을 열면 목록 맨 위로 올라갑니다.
- **고정한 gem은 그대로.** 고정한 gem은 고정한 순서대로 항상 먼저 나오며, 슬라이더 개수 제한에 포함되지 않습니다.
- **네트워크 트래픽 없음.** 모든 정보는 사용자가 연 페이지에서 Voyager가 본 내용에서 가져옵니다. API 호출도, 폴링도, 백그라운드 페치도 없습니다.

## 사용법

1. Voyager 팝업을 엽니다 (툴바의 확장 프로그램 아이콘).
2. **사이드바** → **사이드바에 최근 Gem 표시**가 켜져 있는지 확인합니다(기본값은 켜짐). 켜져 있는 동안 행 아래에 개수 슬라이더가 표시되며, 기본값은 3개입니다.
3. 원하는 수(1–10)로 드래그합니다. **`0`은 최근 Gems 목록만 숨길 뿐** 기능을 끄지는 않습니다. 기능을 끄려면 행의 스위치를 끄세요.

내 gem을 고정하려면 `gemini.google.com/gems/view`를 열고 해당 행의 고정 버튼(**Pin to sidebar**)을 클릭하세요. 다시 클릭하면 고정이 해제됩니다.

::: tip 첫 사용 시
목록은 사용하면서 채워집니다. gem을 열면 목록에 나타납니다. 최근에 열지 않은 gems까지 보려면 `gemini.google.com/gems/view`를 한 번 방문하세요 — Voyager가 그곳에서 조용히 gems 목록을 스냅샷합니다.
:::

## 목록이 갱신되는 시점

- **gem 열기**(`/gem/<id>`)는 방금 사용한 것으로 기록됩니다.
- **`/gems/view` 방문**은 gems 목록 스냅샷을 갱신합니다. 그곳에서의 재정렬, 이름 변경, 생성, 삭제 — 모두 실시간으로 동기화됩니다.
- 다른 페이지에서는 아무것도 읽지 않습니다.

다른 기기에서 gem을 추가하면, Voyager가 "마법처럼" 알지는 못합니다. 이 컴퓨터에서 그 gem이나 `/gems/view`를 한 번 열면 됩니다.

## 개인정보

- gems 목록 스냅샷과 최근 사용 기록은 **로컬 브라우저 저장소** (`chrome.storage.local`)에 머뭅니다.
- 슬라이더 값과 고정한 gem의 ID는 다른 Voyager 설정과 함께 **브라우저 동기화 저장소**에 저장되므로, 같은 브라우저 프로필에 로그인한 기기 사이에서 따라갑니다. 이름과 아이콘은 동기화되지 않습니다.
- gem의 대화 내용은 읽지도 캐시하지도 않습니다 — 이름, 설명, 링크, 아바타의 첫 글자만입니다.
- 이 행을 꺼도 로컬 데이터는 그대로 남으므로 다시 켜면 즉시 반영됩니다.

## 플랫폼

Gemini만 (`gemini.google.com`). AI Studio의 gem 항목은 형태가 다르며 적용되지 않습니다.
