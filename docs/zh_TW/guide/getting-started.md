# 歡迎使用

恭喜，你的思考工具剛剛升級了。
Voyager 不只是一個小工具，它更是一套工作流程。以下說明如何在前五分鐘內充分使用它。

## 1. 安裝

如果你還沒有安裝，請前往[安裝指南](/zh_TW/guide/installation)。
安裝完成後，重新整理你的 Gemini 分頁，你會立刻感受到差異。

如果你也使用 Claude、ChatGPT 或 DeepSeek，請開啟 Voyager 彈出視窗，前往 **外掛**，然後為該網站開啟你想要的外掛。瀏覽器第一次會要求你授權存取該網站；如果沒有出現任何內容，請重新整理分頁。你可以在[外掛目錄](/zh_TW/plugins)中瀏覽所有外掛。

## 2. 時間軸

開始一段對話，最好是很長的一段。例如問問字體的歷史，或黑洞的物理學。
看向右側。
**那一排點，就是你的地圖。**

- **滑鼠停留**：窺看你說過的內容。
- **點擊**：立即跳轉到該處。
- **長按**（約 0.5 秒）：為想保留的時刻**加上星號**，就像替大腦做一個書籤。

不必再無止境地捲動。你現在可以隨著思緒快速導覽。

## 3. 整理

看看左側的對話列表，有沒有發現新東西？
**資料夾。**

拖曳一則對話，放進資料夾即可。
這樣很自然，不是嗎？正因為如此設計。你可以巢狀排列、重新命名，終於把雜亂從腦中清掉。

## 4. 寶庫

你剛寫好一段很棒的提示詞。別讓它消失在茫茫對話中。
點擊輸入框旁邊可拖曳的 **Voyager 懸浮球**，即可開啟提示詞管理器。
把它存下來，並加上標籤。

下次需要時，只要點擊懸浮球，搜尋並插入即可。
你不再只是聊天，而是在建立屬於自己的知識寶庫。
