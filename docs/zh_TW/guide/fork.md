# 對話分叉（實驗性）

思考不應該是單行道。在複雜的探索中，我們常常需要回到某個關鍵節點，嘗試不同的可能。

有了 **對話分叉** 功能，Voyager 讓你可以把思緒分岔出去，探索聊天中的平行宇宙。

## 運作方式

> **⚠️ 注意**：此功能為實驗性功能。你需要先點擊瀏覽器工具列的擴充功能圖示，開啟設定彈出視窗，並打開 **啟用對話分叉** 開關。

當你想走另一條路時，只要將滑鼠移到你的提問上，點擊 **Fork** 按鈕即可：

![對話分叉](/assets/branching.png)

Voyager 會擷取從開頭到該節點為止的完整上下文，並顯示確認對話框。請依上下文的長度選擇：

- **下載 MD**（大多數對話的建議選項）：Gemini 的輸入欄有長度限制，較長的上下文直接貼上可能無法完整放入。Voyager 會下載一份 Markdown 上下文檔案，並開啟新對話；請在右下角的 2 分鐘倒數結束前，把 `.md` 檔案拖入 Gemini。輸入框會預先填入一句話，說明附件是前一段對話的上下文，並保留 **新問題：** 讓你接著輸入下一則訊息。
- **Fork**（適合較短的對話）：當上下文較短時，Voyager 會開啟新對話，並直接把上下文填入輸入框；送出後即可建立分叉。

送出之後，Voyager 只會記錄分叉關係，不會刪除或改寫你原本的對話。

在這個新的分叉中，你可以自由修改提問、嘗試不同的方向，而不必擔心破壞原有的對話紀錄。盡情發揮你的創意與好奇心吧！
