# 訊息時間戳

::: info
**注意**：該功能在 1.3.7 及後續版本中支援。
:::

Voyager 會顯示每則訊息的傳送時間，幫助你回溯對話的完整脈絡。

## 功能介紹

當對話變長後，很難回憶某段討論發生在何時。

Voyager 在每則訊息上方標註精確的傳送時間戳（格式：`YYYY-MM-DD HH:mm:ss`），把滑鼠停在時間軸的圓點上也能看到同一時間。

## 如何開啟

1. 開啟 Voyager 設定面板（瀏覽器工具列上的擴充功能圖示）。
2. 打開 **外掛** → **訊息時間戳記**（標有 **實驗性**，預設關閉）。

在 ChatGPT 上：打開 **外掛** → **ChatGPT · 時間線**，再在其 **選項** 下打開 **顯示訊息時間**，與 Gemini 上的是同一個設定。

## 時間從哪裡來

- **Gemini**：Voyager 從 Gemini 自己的對話資料中讀取每則訊息真實的傳送時間，所以在其他裝置上、或安裝 Voyager 之前進行的對話也能顯示準確時間。只有取不到這個時間時，才退回到 Voyager 首次看到這則訊息的時間，保存在本機瀏覽器中。
- **ChatGPT**：開關打開期間，Voyager 會記錄你送出的每則訊息的時間，保存在本機瀏覽器中；先前傳送的、或在其他裝置上傳送的訊息沒有時間戳。

## 功能特點

- **精確到秒**：完整的日期與時間，適合複盤長對話。
- **零干擾**：時間資訊以簡潔的方式呈現，不影響對話閱讀體驗。

## 使用場景

- **工作記錄**：回顧某個決策是在什麼時間點達成的。
- **學習筆記**：標記某個知識點是何時討論的，方便後續複習。
- **長對話複盤**：在跨天的深度對話中，清晰區分不同時間段的討論內容。

## 平台

**Google Gemini**（`gemini.google.com`）和 **ChatGPT**（`chatgpt.com`）。Claude 和 DeepSeek 暫不支援。
