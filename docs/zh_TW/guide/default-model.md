# 預設模型

::: info
**注意**：此功能於 1.1.9 及之後的版本中提供。
:::

將你偏好的 Gemini™ 模型設為預設，避免每次開啟新對話都要手動切換。

## 功能特色

- **互動式設定**：在 Gemini 原生的模型選單中直接加入「星號」按鈕。
- **自動切換**：每次開始新對話時，都會自動切換到你偏好的模型。
- **思考等級也能設定**：為 **Extended thinking（延伸思考）** 選項加上星號後，新對話也會一併啟用它。
- **偏好持久保存**：你的選擇會被儲存，並在你的裝置之間同步。
- **針對單頁應用優化**：無論是點擊「新對話」按鈕、使用快捷鍵，或返回首頁，都能準確觸發。

## 如何使用

1. 點擊 Gemini 輸入框上方的 **模型選擇器**。
2. 將滑鼠移到你想設為預設的模型上，點擊 **星號圖示**。
3. 星號變為**實心**後，該模型即被設為預設。
4. 之後所有新對話都會自動選取此模型。
5. 若也希望新對話預設使用延伸思考，請在同一選單中點擊 **Extended thinking** 旁的星號。
6. 若要取消，再次點擊實心星號圖示即可。

若只想暫停此功能但保留你的選擇，請在 Voyager 彈出視窗中關閉 **新對話時自動套用預設模型**。
