# 你的智慧資產：提示詞庫

你精心寫出一則提示詞，它解決了複雜的程式問題，或寫出了一封漂亮的郵件。
你會把它丟掉嗎？
不會，你會把它存起來。

## 提示詞寶庫

這是你個人的寶庫，收藏著你的靈感與成果。

### 1. 收錄

寫出好的提示詞時，點擊預設位於輸入區旁邊的 Voyager 懸浮球（你可以把它拖到任何位置），開啟 **提示詞管理器**。
它就成為你寶庫的一部分了。

### 2. 分類

加上標籤，例如 `coding`、`email` 或 `research`（以逗號分隔）。
讓你的工具保持銳利且井然有序。

### 3. 使用

下次需要時，不必再重新輸入。
開啟管理器，依標籤或關鍵字搜尋，然後點擊插入。
一鍵完成，效益無窮。

![提示詞管理器](/assets/gemini-prompt-manager.png)

## 精簡列表與備註

提示詞越積越多，卡片列表無法一次放下時，面板會自動調整：

### 檢視切換

搜尋列右側的 `≡ / ▦` 按鈕可在 **精簡列表**（預設）與 **舒適檢視** 之間切換。

- **精簡列表**：每則提示詞佔一行，一次約可見 10 則；右側依序為標籤、展開、編輯與刪除按鈕。
- **舒適檢視**：完整的 Markdown 預覽，適合提示詞數量不多時使用。

### 必填名稱

新增或編輯提示詞表單頂端的 **備註名稱** 欄位，會為每則提示詞提供簡短標題，建立或編輯提示詞時為必填。沒有名稱的舊提示詞仍可使用，但下次編輯時需要補上名稱。

### 快速懸停預覽

在精簡模式下，將滑鼠停在任一列上約 **250 毫秒**，就會在浮動提示框中顯示完整內容。這會取代瀏覽器原生的 `title` 提示框（後者可能要等 1 到 3 秒才會出現）。

### 斜線快速插入

在對話輸入框中輸入 `/`，再輸入提示詞名稱的一部分。清單會顯示符合的名稱與標籤；將滑鼠停在項目上可預覽完整內容，然後點擊該項目，或按 `Tab` / `Enter` 選取。輸入框會把選取的名稱顯示為醒目的標記，送出時則會傳送完整的提示詞內容。

## 任何網站皆可使用

提示詞管理器現在可以在你選擇的任何網站上使用，不再只限於 Gemini™ 與 AI Studio。

### 如何啟用

在 Claude、ChatGPT 與 DeepSeek 上，請在該網站的頁面中開啟 Voyager 彈出視窗，然後開啟該網站的開關（例如 **在 Claude 上開啟提示詞管理器**）。系統會要求你授予存取權限。

對於其他任何網站：

1. 點擊瀏覽器擴充功能工具列中的 Voyager 圖示。
2. 捲動到 **提示詞管理器** 區段。
3. 輸入網站網址（例如 `chatgpt.com` 或 `claude.ai`）。
4. 點擊 **新增網站**，並授予權限。
5. **重新整理目標頁面**，即可看到懸浮按鈕。

### 常見的 AI 網站

- `chatgpt.com`：ChatGPT
- `claude.ai`：Claude
- `copilot.microsoft.com`：Microsoft Copilot
- `poe.com`：Poe

### 本機應用程式

本機位址同樣適用，只要以相同方式輸入 `localhost:3080` 或 `127.0.0.1:3080` 即可。例如，[DeepSeek Harness](/zh_TW/guide/deepseek-harness) 執行於 `localhost:3080`，提示詞管理器會像掛載在一般網站上一樣附著於它。

![在 DeepSeek Harness 中執行的提示詞管理器](/assets/prompt-manager-deepseek-harness.png)

::: tip
在你自行新增的網站上，**只會**啟用提示詞管理器。時間軸、資料夾等功能不會在那裡載入。Claude、ChatGPT 與 DeepSeek 則不同：它們有各自的官方外掛，你可以在[外掛市集](/zh_TW/plugins)中瀏覽。
:::
