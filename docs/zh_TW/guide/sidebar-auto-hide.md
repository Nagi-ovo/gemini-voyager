# 側邊欄自動收起

想要更加沉浸式的對話體驗？

我們提供了**自動收起側邊欄**的功能。開啟後，當您的滑鼠移出側邊欄區域時，它會自動收起；當您將滑鼠移入側邊欄區域時，它會自動展開。

### 如何開啟

1. 打開 Voyager 彈出視窗。
2. 打開 **側欄** → **自動隱藏側欄**。
3. 若想連收起後的側邊細欄也一併隱藏，再打開 **側欄** → **完全隱藏側欄**（它也可以單獨使用）。

_注意：此功能目前僅支援 Google Gemini。_
