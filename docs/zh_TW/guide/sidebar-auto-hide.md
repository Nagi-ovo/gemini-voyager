# 側邊欄自動收起

想要更沉浸的對話體驗？

我們提供 **側邊欄自動收起** 功能。開啟後，滑鼠移出側邊欄區域時，側邊欄會自動收起；滑鼠移回側邊欄區域時，則會自動展開。

### 如何開啟

1. 開啟 Voyager 彈出視窗。
2. 開啟 **側邊欄自動收起**，它位於 **側邊欄寬度** 滑桿的正下方。
3. 若還想把收起後的側邊軌道也一併隱藏，請開啟 **完全隱藏側邊欄**（單獨開啟也可以生效）。

_注意：此功能目前僅支援 Google Gemini。_
