# 防止自動捲動

在閱讀過去的對話時，如果你按下 Enter 送出新的提示詞，Gemini™ 會強制把頁面捲動到最底部，以追蹤新產生的回覆。這會打斷你的閱讀。

**防止自動捲動** 功能會攔截這種不必要的跳動：

- 當你向上捲動以閱讀歷史紀錄時，系統會阻止頁面跳回底部。
- 在你開啟或切換對話後，Gemini 仍然可以跳到最新訊息；防護只會在你於同一段對話中閱讀時生效。
- 此功能預設為 **關閉**。你可以在彈出視窗的 **時間軸選項** 中手動開啟。

## 如何開啟

1. 點擊瀏覽器工具列上的 Voyager 擴充功能圖示，開啟彈出視窗。
2. 找到 **時間軸選項** 區段。
3. 開啟 **防自動跳轉** 開關。
