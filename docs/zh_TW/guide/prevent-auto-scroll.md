# 防自動跳轉

在查看過往對話時，如果您輸入了新問題並按下 Enter 鍵，Gemini™ 預設會將頁面強制滾動到最底部以顯示最新生成的回答。這可能會打斷您的閱讀體驗。

**防自動跳轉** 功能可以攔截這種不必要的滾動行為：

- 當您向上滾動查看歷史紀錄時，系統會自動阻止頁面跳回底部。
- 剛開啟或切換對話時，Gemini 仍可跳到最新訊息；此防護只在您於同一段對話中閱讀時生效。
- 此功能預設**關閉**，您可以在擴充功能彈出視窗的 **外掛** → **防自動跳轉** 中手動開啟。

## 開啟方法

1. 點擊瀏覽器工具列的 Voyager 擴充功能圖示開啟彈出視窗。
2. 找到 **外掛** 卡片。
3. 開啟 **防自動跳轉** 開關即可生效。
