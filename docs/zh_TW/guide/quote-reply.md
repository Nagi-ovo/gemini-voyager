# 引用回覆

Voyager 提供便利的「引用回覆」功能，讓針對特定內容的回覆更精準、更有效率。

## 功能介紹

日常對話中，我們常需要針對 AI 輸出的某一段內容進行追問或反駁。傳統做法是複製那段文字，再在輸入框中手動輸入 `> ` 符號，相當繁瑣。

Voyager 簡化了這個流程：

1. **選取即引用**：用滑鼠選取對話頁面中的任意文字（無論是你的提問，或是 Gemini 的回答）。
2. **浮動按鈕**：選取的文字附近會自動出現「引用回覆」按鈕。
3. **一鍵插入**：點擊按鈕，選取的文字就會以標準的 Markdown 引用格式（`> 內容`）自動插入輸入框。

![引用回覆](/assets/quote-reply.png)

## 如何啟用

在 Gemini 上，引用回覆由 Voyager 彈出視窗中 **一般選項** 下的 **啟用引用回覆** 控制。

在 Claude、ChatGPT 與 DeepSeek 上，請從[外掛市集](/zh_TW/plugins)安裝該網站的 **引用回覆** 外掛。安裝後，當你在單一助理回覆中選取文字時，會出現 **引用** 按鈕，點擊後引用內容會加入你的草稿，且不會送出任何訊息。

## 功能特色

- **上下文感知**：智能辨識對話內容，避免在無關區域（例如輸入框本身）誤觸發。
- **標準格式**：採用通用的 Markdown 語法，Gemini 能完美理解這種引用結構，因而給出更精準的回應。
- **多行支援**：若選取了多行文字，Voyager 會自動為每一行加上引用符號，保持格式整齊。

## 使用技巧

- **追問細節**：選取 Gemini 回答中不清楚的概念，點擊引用，然後輸入「請詳細解釋這個概念」。
- **糾正錯誤**：選取回答中錯誤的程式碼或事實，引用後指出「這裡不對，應該是……」。
