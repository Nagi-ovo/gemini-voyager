# 時間旅行

Voyager 時間軸是為 Gemini、Claude 與 ChatGPT 設計的視覺化對話導覽系統。它會把聊天中的每則訊息對應到螢幕右側的互動節點，讓冗長的 AI 對話變成可以一跳即達的導覽地圖。

長對話是災難。上上下下，找不著北。
Voyager 把對話變成一條線。

在 Gemini 上，**外掛** → **顯示時間軸** 控制時間軸軌道及其導覽快捷鍵。關閉後會保留已儲存的星標與層級。訊息時間標籤獨立跟隨 **外掛** → **訊息時間戳記**，所以關閉時間軸後仍可顯示訊息時間。

## 看見節奏

看螢幕右側。
每個點都是一句話。那是你對話的脈搏。

## 導航，一步到位

- **瞬移**：點哪去哪，絕不拖泥帶水。
- **偷看**：滑鼠放上去，不用跳轉也能看內容。
- **插眼**：長按節點 **加星**。給大腦打個書籤。
- **層級 (實驗性)**：預設關閉。先在 **外掛** → **顯示時間軸** → **選項** 裡打開 **啟用節點層級**，再右鍵點擊節點，設置不同層級（1-3 級）或摺疊子節點。讓深度分支對話一目了然。層級只在 `節點` 樣式下顯示：打開後時間軸會切換到 `節點`，層級開著時無法選擇 `刻度` 和 `精簡索引`。
- **調寬窄**：拖動時間軸內側邊緣，自由調整寬度。
- **快捷鍵**：用鍵盤飛速穿梭。默認 `j`/`k` 上下跳轉，`gg`/`GG` 直達首尾，想改就改。

## 插眼：給靈感釘個釘

長對話裡藏著金子。用星標把重要時刻釘住。

**怎麼用**：長按（約 0.5 秒）時間軸上任意節點，看到它亮起來——這條訊息就被加星了。

- 再次長按取消星標。
- 加星的節點會保持高亮，一眼就能找到。
- 所有加星的訊息都在 **收藏庫** 裡：在 Voyager 彈窗的 **外掛** → **顯示時間軸** → **選項** 裡點 **檢視收藏庫**，或從提示詞管理器面板打開。

把它想像成在對話中插旗——靈感迸發的瞬間、完美的回答、或者下次要從這裡繼續的位置。

::: tip 小貼士
開啟[雲端同步](/zh_TW/guide/cloud-sync)後，星標會跨裝置同步。
:::

## 調個順眼的樣子

在 Voyager 彈窗的 **外掛** → **顯示時間軸** → **選項** 裡（該列打開後才會顯示）：

- **時間軸樣式**：`節點`、`刻度` 或 `精簡索引`。
- **固定預覽面板**：讓預覽面板常駐在時間軸旁。它的搜尋框邊打字邊篩選訊息。
- **可拖曳時間軸**：時間軸想放哪就拖到哪。點 **重設時間軸位置** 一鍵歸位。

## 鍵盤，更快

不想用滑鼠？用鍵盤。

**就像在 Gemini 裡開了 Vim Mode。**

### 默認快捷鍵

- `k` - 跳到上一個節點
- `j` - 跳到下一個節點
- `gg` - 跳到第一輪
- `GG` - 跳到最後一輪

### 自定義

打開擴充功能設置，點擊快捷鍵框，按下你想用的鍵。
任意鍵，任意組合。`n`/`p`？`,`/`.`？隨你。

**流動模式**下連按會排隊播放動畫。
**跳躍模式**下立即響應，速度拉滿。

## 何時使用時間軸

時間軸在超過 10 則訊息的長對話中最有價值，因為此時逐一捲動會變得沒有效率：

- **研究對話**：你請 Gemini 探討一個主題，來回超過 30 輪。時間軸可以讓你直接跳回關鍵見解，不必重讀全文。
- **程式除錯**：一段很長的除錯對話，解答出現在第 47 輪。把它加上星號，之後一鍵即可找回。
- **學習與指導**：逐步學習一個複雜主題。用層級收合你已經掌握的段落。
- **腦力激盪回顧**：回顧創意討論，挑出最好的點子。星號標記出值得保留的時刻。

## 時間軸與手動捲動的比較

| 功能                  | 沒有時間軸        | 使用 Voyager 時間軸                                     |
| --------------------- | ----------------- | ------------------------------------------------------- |
| 找到特定訊息          | 反覆上下捲動      | 點擊節點，或按 j／k                                     |
| 標記重要時刻          | 複製貼到外部筆記  | 長按加上星號，並同步到雲端                              |
| 看見對話結構          | 依序閱讀          | 視覺地圖一眼呈現整體形狀                                |
| 鍵盤導覽              | Gemini 原生不支援 | Vim 風格的 j／k、gg／GG，完全可自訂                     |
| 導覽 100 則以上的訊息 | 需要捲動好幾分鐘  | 瞬間跳到任何位置                                        |
| 整理長串對話          | 沒有內建工具      | 層級（1 到 3 級）與可收合的子項目（實驗性，需手動開啟） |

## 支援的瀏覽器

時間軸可用於 Google Gemini；Claude 與 ChatGPT 則透過內建外掛提供。支援 Chrome、Edge、Firefox、Safari、Opera 與 Brave。快捷鍵與星號標記在這三個平台上的行為一致。層級在各平台都是需要手動開啟的實驗性功能：在 Gemini 上，到 **外掛** → **顯示時間軸** → **選項** 裡打開 **啟用節點層級**；在 Claude 與 ChatGPT 上，到 **外掛** 裡 **Claude · 時間線** 或 **ChatGPT · 時間線** 的設定中打開同一個開關。啟用 [雲端同步](/zh_TW/guide/cloud-sync) 後，星號訊息會在不同裝置之間同步。

AI Studio 不提供時間軸。DeepSeek 在外掛目錄中有一個選用的時間軸外掛（預設為停用）。
