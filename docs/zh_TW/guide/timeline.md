# 時光穿梭

Voyager 時間軸是為 Gemini、Claude 與 ChatGPT 設計的視覺化對話導覽系統。它會把聊天中的每則訊息對應到螢幕右側的互動節點，讓冗長的 AI 對話變成可以一跳即達的導覽地圖。

長對話很容易雜亂。你上上下下地捲動，最後卻找不到剛才看到的位置。
Voyager 把你的對話變成一條時間軸。

在 Gemini 設定中，**顯示時間軸** 控制右側軌道及其導覽快捷鍵。關閉它不會清除已儲存的星號標記與層級。訊息時間標籤則獨立由 **顯示訊息時間** 控制，因此即使時間軸關閉，你仍可保留訊息時間的顯示。

## 看見對話的形狀

看看螢幕右側。
每個節點代表一則訊息。時間軸呈現了整段對話的節奏。

## 導覽，變得簡單

- **瞬間跳轉**：點擊節點，立即跳到該則訊息。
- **預覽**：滑鼠移到節點上，不必移動畫面就能看到內容。
- **加上星號**：長按節點即可 **加上星號**。就像替大腦做一個書籤。
- **層級（實驗性）**：右鍵點擊節點，可設定不同層級（1 到 3 級）或收合子項目。適合整理有分岔的對話。
- **調整寬度**：拖曳時間軸的內側邊緣，即可調整寬度。
- **快捷鍵**：用鍵盤快速導覽。預設為 `j`／`k`，`gg`／`GG` 則可跳到第一輪與最後一輪。

## 星號標記：標記重要的突破

長對話中藏著重要內容。用星號標記那些值得留下的時刻。

**運作方式**：在時間軸上長按（約 0.5 秒）任一節點，該節點就會亮起，表示這則訊息已加上星號。

- 再長按一次即可取消星號。
- 已加上星號的節點會保持高亮，方便一眼找到。
- 在 **收藏庫** 中查看所有星號訊息：點擊 Voyager 彈出視窗中的 **檢視收藏庫**，或從提示詞管理器面板開啟。

可以把它想成在對話中插上旗子，標記你有所突破的時刻、得到完美答案的時刻，或是之後想接續的地方。

::: tip 小提示
若已啟用 [雲端同步](/zh_TW/guide/cloud-sync)，星號標記會在不同裝置之間同步。
:::

## 外觀設定

在 Voyager 彈出視窗的 **時間軸選項** 下：

- **時間軸樣式**：`節點`、`刻度` 或 `精簡索引`。
- **固定預覽面板**：讓預覽面板常駐於時間軸旁。它的搜尋框會在你輸入時篩選訊息。
- **可拖曳時間軸**：可將時間軸移到頁面任意位置。點擊 **重設時間軸位置** 即可恢復原位。

## 用鍵盤操作更快

不想用滑鼠？直接用鍵盤。

**就像在 Gemini 中開啟了 Vim 模式。**

### 預設快捷鍵

- `k`：跳到上一個節點
- `j`：跳到下一個節點
- `gg`：跳到第一輪
- `GG`：跳到最後一輪

### 自訂快捷鍵

開啟擴充功能設定，點擊快捷鍵欄位，再按下你想要的按鍵即可。
任何按鍵或組合都可以。`n`／`p`？`,`／`.`？由你決定。

**流暢模式**：快速連按時，操作會依序排隊平滑執行。
**即時模式**：立即回應，速度最快。

## 何時使用時間軸

時間軸在超過 10 則訊息的長對話中最有價值，因為此時逐一捲動會變得沒有效率：

- **研究對話**：你請 Gemini 探討一個主題，來回超過 30 輪。時間軸可以讓你直接跳回關鍵見解，不必重讀全文。
- **程式除錯**：一段很長的除錯對話，解答出現在第 47 輪。把它加上星號，之後一鍵即可找回。
- **學習與指導**：逐步學習一個複雜主題。用層級收合你已經掌握的段落。
- **腦力激盪回顧**：回顧創意討論，挑出最好的點子。星號標記出值得保留的時刻。

## 時間軸與手動捲動的比較

| 功能                  | 沒有時間軸        | 使用 Voyager 時間軸                 |
| --------------------- | ----------------- | ----------------------------------- |
| 找到特定訊息          | 反覆上下捲動      | 點擊節點，或按 j／k                 |
| 標記重要時刻          | 複製貼到外部筆記  | 長按加上星號，並同步到雲端          |
| 看見對話結構          | 依序閱讀          | 視覺地圖一眼呈現整體形狀            |
| 鍵盤導覽              | Gemini 原生不支援 | Vim 風格的 j／k、gg／GG，完全可自訂 |
| 導覽 100 則以上的訊息 | 需要捲動好幾分鐘  | 瞬間跳到任何位置                    |
| 整理長串對話          | 沒有內建工具      | 層級（1 到 3 級）與可收合的子項目   |

## 支援的瀏覽器

時間軸可用於 Google Gemini；Claude 與 ChatGPT 則透過內建外掛提供。支援 Chrome、Edge、Firefox、Safari、Opera 與 Brave。快捷鍵、星號標記與層級在所有平台上的行為一致。啟用 [雲端同步](/zh_TW/guide/cloud-sync) 後，星號訊息會在不同裝置之間同步。

AI Studio 不提供時間軸。DeepSeek 在外掛目錄中有一個選用的時間軸外掛（預設為停用）。
