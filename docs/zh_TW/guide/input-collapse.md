# 輸入框摺疊

輸入框為空時將其摺疊，獲得更多閱讀空間。點擊摺疊後的長條按鈕即可展開並開始輸入。

</div>

## 如何使用

1. 當輸入框為空且失去焦點時，會自動摺疊成一個精簡的膠囊按鈕。
2. 點擊膠囊按鈕即可展開輸入框，開始輸入。
3. 你也可以按下 <kbd>Ctrl</kbd>／<kbd>⌘</kbd>+<kbd>I</kbd> 快速展開輸入框。
4. 在 Voyager 彈出視窗的 **輸入選項** 中，開啟或關閉 **啟用輸入框摺疊**（預設為關閉）。
5. 如果希望輸入框即使含有文字或附件也能摺疊，請一併開啟 **允許折疊有內容的輸入框**。
