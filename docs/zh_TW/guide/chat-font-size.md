# 字體大小

自由調整 Gemini 對話區域的字體大小，獲得最舒適的閱讀體驗。

## 功能介紹

每個人對字體大小的偏好都不同：有人喜歡緊湊的小字，好在同一畫面中容納更多資訊；有人則偏好大字，減少眼睛的疲勞。Voyager 讓你可以把對話字體大小調整在 80% 到 150% 之間。

## 功能特色

- **彈性範圍**：支援 80%–150% 的字體大小調整，涵蓋大多數閱讀需求。
- **全面套用**：同時作用於使用者訊息與模型回覆，包括內文、清單、表格與程式碼區塊。
- **程式碼區塊最佳化**：程式碼區塊的字體大小會依比例自動縮放（內文字體 × 0.875），維持程式碼與內文之間的視覺層次。
- **即時生效**：調整後立即生效，無需重新整理頁面。

## 如何使用

1. 開啟 Voyager 設定面板（彈出視窗）。
2. 找到 **對話字體大小** 設定項，並將其開啟。
3. 拖曳滑桿調整字體大小百分比，頁面會即時預覽變化。
