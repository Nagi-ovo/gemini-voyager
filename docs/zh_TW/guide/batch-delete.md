# 批次刪除

在 Gemini 與 AI Studio 上一次刪除多則對話，不必再逐一刪除。

## 功能特色

- **多選模式**：長按任一對話即可進入多選模式，勾選多則要刪除的對話。
- **一鍵清理**：選取完成後，點擊刪除按鈕，即可一次刪除所有已選取的對話。
- **進度回饋**：刪除過程中會顯示即時進度，讓你掌握目前狀態。
- **安全確認**：刪除前會出現確認對話框，避免誤操作。

## 如何使用

### Gemini

1. 在側邊欄的對話列表中，**長按**任一對話項目。
2. 進入多選模式後，每則對話的左側會出現核取方塊。
3. 勾選你想刪除的對話（一次最多 50 則）。
4. 點擊出現的 **刪除按鈕**。
5. 在**資料夾列表上方**出現的紅色確認區域中點擊「確定」，即開始批次刪除。

### AI Studio

1. 開啟 AI Studio 的 **Library** 頁面。
2. **長按**任一 prompt 列進入多選模式。
3. 選取你想刪除的 prompt（一次最多 50 個）。
4. 點擊浮動工具列上的 **刪除按鈕**，再於瀏覽器的確認視窗中確認。

::: tip 提示
在 Gemini 上，刪除確認面板會覆蓋在資料夾區域上方，以免遮住對話列表。批次刪除無法復原，請謹慎操作。
:::
