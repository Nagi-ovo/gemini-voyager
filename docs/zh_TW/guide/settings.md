# 打造你的專屬體驗

預設的體驗已經很好。但你可能希望它更完美。
每個像素都可以客製化。

## 影院模式

為什麼要從小小的鑰匙孔裡看世界？
Voyager 讓你擴大對話區域的寬度。

- **對話區域寬度**：可用滑桿調整，範圍為視窗寬度的 30% 到 100%（預設為 70%）。寫程式碼與複雜表格時可以拉寬，閱讀時則可以收窄。
- **編輯輸入框寬度**：加寬你編輯已送出訊息時所出現的輸入框。

## 控制

點擊擴充功能圖示，即可進入控制中心。

- **捲動模式**：`流動` 會平滑捲動到該則訊息；`跳躍` 則會立即跳到該處。
- **時間軸位置**：開啟 **可拖曳時間軸**，然後把它移到你覺得順手的位置。點擊 **重設時間軸位置** 即可恢復原位。
- **視覺特效**：可選擇 `飄雪`、`櫻花` 或 `雨`，為頁面營造季節氛圍。

## 自訂排序

彈出視窗的區塊太多，而你最常用的設定都被埋在最下面？

將滑鼠移到任一設定卡片上，右上角就會出現 ▲／▼ 箭頭。點擊即可將卡片往上或往下移動。你的版面配置會自動儲存，並在下次開啟時保留。

## 氛圍

Voyager 不只是功能上的微調，你也可以改變頁面的氣氛。

- **飄雪**：柔和飄落的雪花，帶來寧靜的冬日感受。
- **櫻花**：飄浮的櫻花花瓣，營造輕盈的春日氛圍。
- **雨**：電影感的雨幕，帶有傾斜的雨絲與細微的水花漣漪。
- **平滑切換**：關閉某個特效或切換到另一個特效時，既有的粒子會自然淡出。
