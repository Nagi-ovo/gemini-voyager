# 側邊欄的最近 Gems

Gemini 在 2026 年的改版先把 Gems 移到設定選單後面，之後又悄悄在側邊欄放回一個入口，但它只是一個連結，點擊後會把你導向 `/gems/view`。

Voyager 讓 Gemini 原生的 Gems 入口可以在側邊欄中展開，成為你的 Gems 清單：置頂的 Gems 排在最前面，接著是最近使用的 Gems。

## 外觀

- **附著於原生 Gems 入口**：與 Gemini 自帶的「Gems」標籤縮排對齊，看起來像是該入口的子清單，而不是硬加上去的面板。
- **箭頭切換**：Gems 入口右側有一個小的 `›` 按鈕，展開時會旋轉為 `⌄`。點擊即可收合或展開。此狀態會儲存在本機，並在各分頁之間同步。
- **最近使用者優先**：開啟任一 Gem（無論是你自己的，或 Google 提供的預設 Gem），它都會移到清單最上方。
- **置頂 Gems 固定不動**：置頂的 Gems 永遠排在最前面，順序依照你置頂的先後排列，且不計入滑桿的數量上限。
- **零網路流量**：所有資料都來自你開啟的頁面中 Voyager 能看到的內容。沒有 API 呼叫、沒有輪詢，也不會在背景擷取任何資料。

## 如何使用

1. 開啟 Voyager 彈出視窗（工具列中的擴充功能圖示）。
2. 找到 **側邊欄中顯示的最近 Gems** 滑桿。預設顯示 3 個 Gems。
3. 將滑桿拖到你想要的數量（1 到 10）。**`0` 會完全隱藏此區段**，如果你不需要此功能，請將它設為 0。

若要置頂你自己的 Gem，請開啟 `gemini.google.com/gems/view`，然後點擊該列上的置頂按鈕（**Pin to sidebar**）。再次點擊即可取消置頂。

::: tip 首次設定
清單會隨著你的使用逐漸填滿：開啟一個 Gem，它就會出現在清單中。若要看到你最近沒有開啟過的 Gems，請造訪一次 `gemini.google.com/gems/view`，Voyager 會在那裡悄悄為你的 Gems 清單建立快照。
:::

## 清單何時更新

- **開啟 Gem**（`/gem/<id>`）會將它記錄為剛剛使用過。
- **造訪 `/gems/view`** 會重新整理你的 Gems 清單快照；在該頁面上重新排序、重新命名、新增或刪除 Gem，都會立即同步。
- 不會從其他頁面讀取任何資料。

因此，如果你在其他裝置上新增了 Gem，Voyager 不會「自動」知道。請在這台電腦上開啟它，或造訪一次 `/gems/view`。

## 隱私

- Gems 清單快照與最近使用紀錄會儲存在**本機瀏覽器儲存空間**（`chrome.storage.local`）中。
- 滑桿數值與置頂 Gems 的 ID 會與其他 Voyager 設定一起儲存在**瀏覽器同步儲存空間**中，因此在登入同一瀏覽器設定檔的其他裝置上也會生效。名稱與圖示則不會同步。
- 我們不會讀取或快取 Gem 的對話內容，只保存名稱、描述、連結，以及頭像用的首字母。
- 停用此功能（數量設為 0）後，本機資料會保留，因此重新啟用時可立即恢復。

## 適用平台

僅支援 Gemini（`gemini.google.com`）。AI Studio 的 Gems 入口結構不同，不在適用範圍內。
