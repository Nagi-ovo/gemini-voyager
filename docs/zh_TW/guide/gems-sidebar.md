# 側欄 Gems 列表

Gemini 新版側欄已將 Gems 移到「更多」選單，那裡只是一個跳到 `/gems/view` 整頁的連結。Voyager 在側欄加了自己的 Gems 區塊，列出你的 gems，按一下就能打開：置頂的 gems 排最前，接著是最近用過的。

## 看起來像什麼

- **獨立的 Gems 區塊**：清單位於側欄頂部導覽（「更多」所在的那一組）下方，有自己的 **Gems** 標題。若 Gemini 仍顯示原生 Gems 入口，清單會改掛在該入口下方。
- **點標題折疊**：點 **Gems** 標題（原生入口則點右側箭頭）即可展開或收起，展開時 `›` 會轉成 `⌄`。狀態存在本機，並跨分頁同步。
- **最近用過的排前面**：打開任何一個 gem（你自己的，或 Google 預設的 gem），它就會跳到清單最上方。
- **置頂的 gems 不動**：置頂的 gems 永遠排在最前，按你置頂的先後排列，而且不佔滑桿的數量上限。
- **零網路開銷**:清單只來自 Voyager 在你打開的頁面上看到的內容。不呼叫任何 API、不輪詢、不背景擷取。

## 怎麼用

1. 開啟 Voyager 彈窗(工具列上的擴充功能圖示)。
2. 在 **側欄** → **側欄最近使用的 Gem** 確認該列已開啟（預設開啟）。開啟後，列下方會出現數量滑桿，預設顯示 3 個。
3. 拖到你想顯示的數量(1–10)。**`0` 只是隱藏最近 Gems 清單**，並不會關閉這項功能；想完全關閉，請把該列的開關關掉。

想置頂你自己的 gem，就到 `gemini.google.com/gems/view`，點那一列上的置頂按鈕（**Pin to sidebar**）。再點一次即可取消置頂。

::: tip 首次啟用
清單會邊用邊長：打開一個 gem，它就會出現。想看到最近沒打開過的 gems，造訪一次 `gemini.google.com/gems/view`,Voyager 會在那裡自動把你的 gems 清單快取下來。
:::

## 資料何時更新

- **打開 gem**（`/gem/<id>`）會把它記為剛用過。
- **造訪 `/gems/view`** 會重新整理 gems 清單快取；在那裡重排、改名、新增、刪除 gem，都會即時同步。
- 其他頁面不做任何擷取。

也就是說:如果你在別的裝置上新增了 gem,Voyager 不會「神奇地」知道。在這台機器上打開它一次，或造訪一次 `/gems/view` 即可。

## 關於隱私

- gems 清單快取與最近使用紀錄**只存在本機** (`chrome.storage.local`)。
- 滑桿數值和置頂 gems 的 ID 會跟其他 Voyager 設定一起存在**瀏覽器同步儲存空間**，登入同一瀏覽器設定檔的裝置都會跟著生效。名稱和圖示不會同步。
- 不讀取也不快取 gem 的對話內容——只是名稱、描述、跳轉連結和首字母。
- 關閉這一列後，本機資料仍然保留，再開啟時不必重新載入。

## 平台

僅支援 **Google Gemini**(`gemini.google.com`)。AI Studio 的 Gems 入口結構不同,不在適用範圍內。
