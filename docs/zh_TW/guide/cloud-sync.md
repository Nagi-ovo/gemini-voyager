# 雲同步

將您的資料夾、靈感庫（Prompts）、星標訊息及支援的設定等數據備份到雲端，在不同設備間保持一致。任何支援的瀏覽器都可以選 Google Drive，Safari 上還可以選 iCloud。數據直接在 Voyager 與您選擇的個人雲端帳戶之間傳輸，Voyager 不營運同步服務器。

## 同步內容

| 資料類型     | 是否同步 | 說明                                                     |
| ------------ | -------- | -------------------------------------------------------- |
| 資料夾結構   | 是       | 所有資料夾、巢狀層級、顏色與對話歸屬                     |
| 提示詞庫     | 是       | 所有已儲存的提示詞，包含標籤與資料夾分類                 |
| 星號標記訊息 | 是       | 來自任何對話的時間軸書籤                                 |
| 擴充功能設定 | 是       | 排序、顏色與輸入行為等跨裝置偏好設定                     |
| 外掛設定     | 是       | 安裝與啟用狀態及外掛設定；網站權限仍各自保存在每台裝置上 |
| 模型回答     | 否       | 星號標記備份只包含使用者的提示詞，不包含模型回答         |

## 功能特點

- **多端同步**：利用雲端存儲，在多台電腦上同步您的配置。
- **數據安全**：數據存儲在您自己的 Google Drive 空間或私人 iCloud 資料庫中，不經過 Voyager 服務器，確保隱私安全。
- **靈活同步**：支持手動上傳、下載合併數據。

::: info
裝置識別碼、存取權杖、快取、視窗座標與暫時的執行狀態，刻意不會作為個人化設定同步。
:::

## 星標資料與同步限制

上傳雲端備份時，星標訊息會包含您標記的**使用者提示詞全文**（每則最多 16 KiB UTF-8），並儲存到您自己的 Google Drive 或 iCloud；星標備份不儲存模型回答。舊版 v1 備份仍只保留預覽，新版 v2 備份包含提示詞全文及刪除記錄。

刪除記錄保留 180 天。舊版 Voyager 不識別這些記錄，可能顯示或重新上傳已刪除的星標；新版會攔截時間戳未更新的舊副本。明確重新加星或刪除記錄到期後，星標可能恢復。長期離線和裝置時鐘差異也會影響刪除傳播。

同步會合併並檢查寫入結果，最多嘗試三次，但不是跨裝置的原子交易；並行上傳仍可能覆蓋其他裝置的寫入。保留缺失資料的裝置再次同步可修復這種情況，否則無法保證恢復。部分上傳失敗不會撤銷已成功的寫入，請再次同步完成修復。

## 如何使用

1. 點擊瀏覽器工具列上的 Voyager 圖標，打開彈窗。
2. 找到 **雲端同步** 區域。
3. 在 Safari 上可選擇 **Google Drive** 或 **iCloud**；其他瀏覽器使用 Google Drive。
4. 使用 Google Drive 時，點擊 **使用 Google 登入** 並完成授權；使用 iCloud 時，請確認這台 Mac 已登入 iCloud。
5. 點擊 **上傳到雲端** 將本地數據同步到雲端，或點擊 **從雲端下載合併** 將雲端數據合併到這個瀏覽器。**覆蓋下載** 則會直接用雲端副本取代本地數據而不合併，尚未上傳的內容會遺失。

使用 iCloud 時，**刪除 iCloud 備份** 會移除 iCloud 中所有的 Voyager 備份；Mac 上的本地數據保持不變。

### 💡 極速同步

最簡單的方法是在左側側邊欄的**資料夾區域頂部**，直接點擊「上傳到雲端」或「從雲端同步」按鈕。

1. **資料夾**：打開資料夾區域的選單，選擇 **匯入/匯出資料夾** → **匯出資料夾**，備份所有資料夾及對話歸屬。
2. **提示詞**：在提示詞管理器中點擊 **匯出**，備份您的靈感庫。

## 雲端同步與手動備份

| 面向     | 手動備份（匯出/匯入） | 雲端同步                                 |
| -------- | --------------------- | ---------------------------------------- |
| 頻率     | 想到時再做            | 一鍵即可隨時執行                         |
| 資料位置 | 電腦上的本機檔案      | 您的 Google 雲端硬碟或私人 iCloud 資料庫 |
| 跨裝置   | 需要自行傳送檔案      | 登入同一個雲端帳戶的裝置即可取用         |
| 合併方式 | 取代，或需要手動合併  | 智慧合併，不會產生重複項目               |
| 隱私     | 檔案留在您的電腦上    | 儲存在您個人的雲端帳戶中                 |

## 運作方式

1. **提供者**：Google 雲端硬碟使用有限的 `drive.file` 權限，因此 Voyager 只能存取它自己建立的檔案。在 Safari 上，iCloud 使用 App 的私人 CloudKit 資料庫，不會把 Apple ID 權杖提供給 Voyager。
2. **上傳**：點擊 **上傳到雲端** 時，Voyager 會把資料夾、提示詞、星號標記、分叉、時間軸階層、個人化設定與外掛設定，分別寫成獨立的備份檔案，存到所選的提供者。啟用醒目標示雲端同步時，也會包含醒目標示資料。
3. **下載並合併**：在另一台裝置上點擊 **從雲端下載合併** 時，Voyager 會讀取這些檔案，並依資料類型分別合併。新的資料夾與提示詞會加入且不重複，雲端偏好設定會被還原，外掛項目則依外掛 ID 合併。
4. **沒有背景同步**：同步是手動、依需求執行的。沒有您明確操作，Voyager 絕不會進行同步。

切換提供者不會在兩者之間複製資料，也不會同時寫入兩邊。若您希望目前的本機資料也出現在新選的提供者中，切換後請上傳一次。

## 支援平台

Google 雲端硬碟同步可在 Chrome、Edge、Firefox 與 Safari 上使用。iCloud 同步僅適用於直接發布的 Safari App，並使用此 Mac 上登入的 iCloud 帳戶。
