# 雲端同步

Voyager 雲端同步會備份您的資料夾、提示詞庫、星號標記訊息，以及支援的設定。在任何支援的瀏覽器上都可以選擇 Google 雲端硬碟；在 Safari 上則可以選擇 iCloud。資料會直接在 Voyager 與您選擇的個人雲端帳戶之間傳輸，Voyager 不營運同步伺服器。

## 同步內容

| 資料類型     | 是否同步 | 說明                                                     |
| ------------ | -------- | -------------------------------------------------------- |
| 資料夾結構   | 是       | 所有資料夾、巢狀層級、顏色與對話歸屬                     |
| 提示詞庫     | 是       | 所有已儲存的提示詞，包含標籤與資料夾分類                 |
| 星號標記訊息 | 是       | 來自任何對話的時間軸書籤                                 |
| 擴充功能設定 | 是       | 排序、顏色與輸入行為等跨裝置偏好設定                     |
| 外掛設定     | 是       | 安裝與啟用狀態及外掛設定；網站權限仍各自保存在每台裝置上 |
| 模型回答     | 否       | 星號標記備份只包含使用者的提示詞，不包含模型回答         |

## 星號標記資料與同步限制

上傳到雲端時，您標記為星號的**使用者提示詞全文**（每則最多 16 KiB UTF-8）會存入您自己的 Google 雲端硬碟或 iCloud。星號標記備份不會儲存模型回答。舊版 v1 備份只保留預覽；新版 v2 備份則包含提示詞全文與刪除記錄。

刪除記錄會保留 180 天。舊版 Voyager 會忽略這些記錄，因此可能會再次顯示或上傳已刪除的星號標記；新版則會擋下時間戳記未更新的舊副本。若您明確重新加上星號，或刪除記錄已過期，星號標記就可能恢復。長時間離線與裝置時鐘不一致，也會影響刪除的同步傳播。

同步會合併並檢查寫入結果，最多嘗試三次，但它不是跨裝置的原子交易，同時進行的上傳仍可能覆寫另一台裝置的寫入。保有遺失資料的裝置之後再同步，就能修復這種情況；若該裝置之後都不再同步，則無法保證能夠恢復。部分上傳失敗時，已被接受的寫入會保留，請再同步一次以完成修復。

## 功能特色

- **多裝置同步**：在多台電腦之間保持設定一致。
- **資料隱私**：資料存放在您自己的 Google 雲端硬碟或私人 iCloud 資料庫中，不經過 Voyager 伺服器。
- **彈性同步**：支援手動上傳，以及下載並合併資料。

::: info
裝置識別碼、存取權杖、快取、視窗座標與暫時的執行狀態，刻意不會作為個人化設定同步。
:::

## 使用方式

1. 點擊瀏覽器工具列上的 Voyager 圖示，開啟彈出視窗。
2. 找到 **雲端同步** 區段。
3. 在 Safari 上，選擇 **Google Drive** 或 **iCloud**。其他瀏覽器使用 Google 雲端硬碟。
4. 使用 Google 雲端硬碟時，點擊 **使用 Google 登入** 並完成授權；使用 iCloud 時，請確認這台 Mac 已登入 iCloud。
5. 點擊 **上傳到雲端**，將本機資料傳送到雲端；或點擊 **從雲端下載合併**，把雲端資料合併到這個瀏覽器。**覆蓋下載** 會用雲端的副本取代本機資料，而不是合併；尚未上傳的內容會遺失。

使用 iCloud 時，**刪除 iCloud 備份** 會移除 iCloud 中所有的 Voyager 備份；Mac 上的本機資料會保持不變。

### 💡 快速同步

最快的方式是使用左側側邊欄資料夾區域頂端的 **上傳到雲端** 與 **從雲端同步** 按鈕。

2. **提示詞**：在提示詞管理器中點擊 **匯出**，儲存您的提示詞庫。

## 雲端同步與手動備份

| 面向     | 手動備份（匯出/匯入） | 雲端同步                                 |
| -------- | --------------------- | ---------------------------------------- |
| 頻率     | 想到時再做            | 一鍵即可隨時執行                         |
| 資料位置 | 電腦上的本機檔案      | 您的 Google 雲端硬碟或私人 iCloud 資料庫 |
| 跨裝置   | 需要自行傳送檔案      | 登入同一個雲端帳戶的裝置即可取用         |
| 合併方式 | 取代，或需要手動合併  | 智慧合併，不會產生重複項目               |
| 隱私     | 檔案留在您的電腦上    | 儲存在您個人的雲端帳戶中                 |

## 運作方式

1. **提供者**：Google 雲端硬碟使用有限的 `drive.file` 權限，因此 Voyager 只能存取它自己建立的檔案。在 Safari 上，iCloud 使用 App 的私人 CloudKit 資料庫，不會把 Apple ID 權杖提供給 Voyager。
2. **上傳**：點擊 **上傳到雲端** 時，Voyager 會把資料夾、提示詞、星號標記、分叉、時間軸階層、個人化設定與外掛設定，分別寫成獨立的備份檔案，存到所選的提供者。啟用醒目標示雲端同步時，也會包含醒目標示資料。
3. **下載並合併**：在另一台裝置上點擊 **從雲端下載合併** 時，Voyager 會讀取這些檔案，並依資料類型分別合併。新的資料夾與提示詞會加入且不重複，雲端偏好設定會被還原，外掛項目則依外掛 ID 合併。
4. **沒有背景同步**：同步是手動、依需求執行的。沒有您明確操作，Voyager 絕不會進行同步。

切換提供者不會在兩者之間複製資料，也不會同時寫入兩邊。若您希望目前的本機資料也出現在新選的提供者中，切換後請上傳一次。

## 支援平台

Google 雲端硬碟同步可在 Chrome、Edge、Firefox 與 Safari 上使用。iCloud 同步僅適用於直接發布的 Safari App，並使用此 Mac 上登入的 iCloud 帳戶。
