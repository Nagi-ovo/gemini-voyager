# 隱私權政策

最後更新：2026 年 10 月 14 日

## 概覽

Voyager 是一款本機優先的瀏覽器擴充功能，用來整理並強化支援的 AI 聊天工作區。它只會為了提供您要求的功能而處理有限的使用者資料。Voyager 不營運會接收對話、提示詞、瀏覽活動、圖片或帳戶識別碼的後端伺服器，也不使用廣告或分析追蹤器。

## 處理的資料

視您使用的功能而定，Voyager 可能會處理以下資料：

- **網站內容與個人通訊內容**：對話文字、提示詞、草稿、圖片、連結，以及其他受支援頁面的內容，用於資料夾、導覽、匯出、提示詞管理、研究與介面功能。
- **帳戶識別碼**：受支援的 Google 服務可能會提供已登入的電子郵件地址。Voyager 會將其轉換為本機帳戶識別碼，讓不同帳戶的資料保持分離。Voyager 不會把原始電子郵件地址傳送給我們。
- **網頁紀錄與使用者活動**：受支援網站的網址、對話路由，以及有限的頁面、互動與網路事件，用於導覽、快捷鍵、用量顯示、回應完成通知與其他您要求的功能。這些資料不會用於建立使用者輪廓或投放廣告。
- **驗證資訊**：僅在您明確啟用 Google Drive 同步時，才會取得具有 `drive.file` 範圍的 OAuth2 權杖。
- **擴充功能資料與設定**：資料夾、提示詞範本、草稿、星標訊息、用量快照、外掛狀態與介面偏好設定。

這些資料儲存在 `chrome.storage.local` 中；受支援的設定則儲存在 `chrome.storage.sync` 中。除非使用者明確使用下文所述的傳輸功能，資料會留在使用者的裝置或瀏覽器同步帳戶中。

## 使用者要求的傳輸

- **Google Drive 同步（選用）**：選定的備份資料會在使用者的裝置與**其本人的 Google Drive** 之間直接傳輸。Chrome、Edge 與 Firefox 使用瀏覽器的身分識別 API；Safari 直接安裝的 App 則使用原生 Google 登入，並將憑證存放在 macOS 鑰匙圈中。兩種方式都只要求有限的 `drive.file` 範圍，OAuth 權杖不會傳送到 Voyager 伺服器。
- **Safari 的 iCloud 同步（選用）**：選定的備份資料會由 Safari 原生擴充功能直接傳輸到使用者 iCloud 帳戶中的私有 CloudKit 資料庫。Voyager 不會接收使用者的 Apple ID 或 iCloud 驗證權杖，開發者也無法存取該私有資料庫中的記錄。
- **匯出與圖片**：使用者要求匯出時，Voyager 可能會從頁面既有的圖片來源擷取圖片，並可能要求臨時存取權限，以擷取生成的介面內容。產生的檔案是為使用者建立的，不會上傳到 Voyager 伺服器。
- **公開專案資源**：Voyager 可能會請求公開的發行版本、公告或說明文件資源。這些請求不包含對話或提示詞內容。
- **外掛目錄更新**：在您已啟用至少一個外掛的網站上，Voyager 可能會透過 HTTPS 從 `https://voyager.nagi.fun/catalog/hosts/<網站主機名稱>.json` 取得該網站更新後的目錄檔案，例如 `https://voyager.nagi.fun/catalog/hosts/chat.deepseek.com.json`。檢查會在開啟此類頁面時進行，或在此類頁面上開啟擴充功能彈出視窗時進行；而且只有在距離上次檢查已超過您選擇的間隔時才會執行（預設為 6 小時，可選 1 小時、6 小時、24 小時，或僅手動）。Gemini 與 AI Studio 只使用隨擴充功能打包的官方外掛，因此永遠不會觸發請求。該請求是一般的 GET 請求，不帶 Cookie、不帶帳戶或擴充功能識別碼，也不帶頁面或對話內容；和任何網路請求一樣，伺服器會看到請求端的 IP 位址與瀏覽器 User-Agent，以及網址路徑中的網站主機名稱。在有外掛的網站上，彈出視窗提供「外掛線上更新」開關與檢查間隔選擇器，兩者都儲存在瀏覽器同步儲存空間中，並包含在設定備份內。關閉該開關後，除非使用者按下「立即檢查外掛更新」，Voyager 不會連線到 voyager.nagi.fun。若請求失敗，或該網站沒有目錄檔案，會繼續使用擴充功能內附的外掛快照。取得的目錄只包含 CSS 與 JSON，使用前會經過驗證與清理；不會下載或執行任何 JavaScript。此檢查與公告檢查分開，後者有自己的設定。voyager.nagi.fun 是經由 Cloudflare 代理的靜態託管服務，Voyager 專案不記錄也不保存這些請求；連線中繼資料（IP 位址、User-Agent）由託管服務商依其各自的隱私權政策處理。

Voyager 不會出售使用者資料，也不會為了廣告、信用評估，或與擴充功能面向使用者的功能無關的目的而傳輸資料。

## 權限

- **Storage（儲存空間）**：在本機儲存擴充功能資料與偏好設定，並在支援的情況下透過瀏覽器同步。Chrome、Edge 與 Firefox 也會授予 `unlimitedStorage`，避免本機資料受預設的瀏覽器配額限制；Voyager 仍會套用自己的儲存上限。在 Safari 上此權限為選用。
- **Identity（身分識別）**：在使用者明確操作後，為選用的 Google Drive 同步進行驗證。Safari 的 iCloud 同步則使用 Mac 系統的 iCloud 帳戶，而不使用此瀏覽器權限。
- **Scripting（腳本注入）**：只在受支援的網站上注入擴充功能隨附的腳本；不會執行遠端 JavaScript 或 WebAssembly。
- **Active tab 與 declarative content**：辨識使用者開啟的受支援網站，並顯示對應的網站專用控制項。declarative content 僅用於 Chrome 與 Edge。
- **Alarms（定時器）**：定期檢查公開的相容性公告。
- **Notifications（通知，選用）**：只有在使用者開啟回應完成通知時才會請求。
- **Host permissions（主機權限）**：安裝時即授予 Gemini、Gemini Enterprise 與 AI Studio，以及使用者要求的 Google Drive 與圖片操作所需的 Google 網域。
- **選用主機權限**：Claude、ChatGPT、DeepSeek 與自訂網站，只有在使用者為該網站啟用 Voyager 或外掛，並核准瀏覽器的權限提示後，才會存取。使用者選擇會擷取生成介面內容的匯出時，可能會臨時請求 `<all_urls>`；若被拒絕，匯出會在沒有該擷取步驟的情況下繼續。

## 保留期限與使用者控制

本機與瀏覽器同步的資料會一直保留，直到使用者將其刪除、清除擴充功能儲存空間，或解除安裝擴充功能為止。雲端備份會保留在使用者選定的 Google Drive 或 iCloud 帳戶中，直到使用者自該帳戶中移除為止。使用者可以透過 Voyager 與瀏覽器設定停用選用功能，並撤銷選用的網站存取權限或 Google 授權。

## Google API 限制使用

Voyager 對從 Google API 取得的資訊之使用與傳輸，符合 Chrome 線上應用程式商店使用者資料政策，包括其中的限制使用要求。

## 政策變更

我們可能會隨 Voyager 的變動更新本隱私權政策。最新版本與其更新日期將發佈在本頁。
